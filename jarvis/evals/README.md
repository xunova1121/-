# 服务器评测的授权与结果

先在未央的设置→服务器→登录安全与评测授权中生成专用令牌。明文只显示一次，默认7天、每日模型/搜索合计200次；30题可能超过默认额度，请按实际需要在生成时设置。令牌不要发进聊天、日志或仓库，也不要写进命令历史。

在运行评测的终端私下输入并导出环境变量（输入不显示）：

```bash
read -rsp '评测专用令牌：' JARVIS_EVAL_TOKEN
echo
export JARVIS_EVAL_TOKEN
export JARVIS_EVAL_URL=http://127.0.0.1:8787
bash evals/run-joint.sh
unset JARVIS_EVAL_TOKEN
```

远程连接必须HTTPS。脚本不读取主访问密码或`jarvis.env`，也不把密码派生成永久令牌。不向旧服务器或主人授权退回；协议/授权不兼容就在模型请求前停止。

专用授权只能创建/读取自己的评测任务、会话和事件。设置、Key、正常对话、记忆、文件HTTP接口、代码仓库、更新、提醒和授权管理均不可访问。服务端强制评测编号、隔离文件和缓存，模型工具也不能绕路操作正式提醒/仓库/记忆。

因此原30题及五类重点题中的仓库、浏览器、正式提醒题会明确记为`not_ready`，需要主人独立验收，不降低标准、不计通过。默认两次与原评分尺度保持。调用结束、退出码0、产物文件名都不能代替质量通过。

需要文件证据时，只在服务器本机以有磁盘权限的管理员身份，从本次令牌、本轮服务器签发的评测空间收集；令牌本身仍不能下载任何文件。默认数据目录`/opt/jarvis/data`，不同安装可显式设置`JARVIS_EVAL_DATA`。不读取用户文件、模型配置或访问密码；无法取得证据就记未读回，不能通过文件验收。

评测启动器不自动调用旧的、直接读取模型配置的评审入口。原回答和文件保存在私有目录，先确认完整性，再单独安排独立模型评审与人工校准；未评审的结果保持待评审，不能当作已经合格。

额度在实际模型/搜索请求前计入，内部重试和换源也计数。服务商内置搜索先预留允许执行的最大次数，完整响应后按真实搜索事件释放未用额度；请求中断或进程重启无法确认的预留保守保留，不猜成零。超过上限返回429，过期或作废返回401，其他资源越权返回403。

`run-focus-server.sh 固定40位提交 [期望服务器版本]`只准备小型私有评测副本，不部署服务。运行保持当前默认模型，原30题与重点题独立统计。需要用户生成授权、配Key及真实模型的验收，以实际运行报告为准，开发环境演示任务不算用户服务器验收。
