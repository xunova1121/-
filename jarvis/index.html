              MCP 工具连接

              MCP 是大模型连接外部工具的通用标准：接上浏览器自动化、地图、GitHub、数据库、各类办公软件的 MCP 服务后，未央就能直接使用它们。技能教它“怎么做”，MCP 让它“能接触到”。

              MCP 服务要在本机启动程序，单文件版用不了。请使用桌面版，或双击 jarvis 文件夹里的 启动.bat 打开完整版。

                联网搜索 · 本机备用

                首选的 DeepSeek 搜索在上面“联网搜索 · DeepSeek”里开。这里是本机的备用：DeepSeek 没开或失败时才用；都不填也能搜（读必应、百度的结果），但不稳定，新闻、比分这类最新内容常常搜不到。云服务器用的备用 Key 在上面切到“云服务器”后填写。

                博查、Tavily 的 Key 在上面“服务商与 Key → 其他服务的 Key”里填。

                博查是国内的 AI 搜索接口，按次计费（价格以官网为准）。申请：打开 open.bochaai.com 注册、充值后在“API KEY 管理”里创建，复制粘贴到上面。填了以后中文搜索先走博查。

                更多：免密钥搜索范围、模型自带搜索

                国外资料多时用。免费申请：打开 app.tavily.com 注册（可用谷歌账号或邮箱），登录后首页就有以 tvly- 开头的 Key，复制粘贴到上面。免费版每月有一定次数，个人使用一般够用。

                声音

                识别 qwen3-asr-flash-realtime，朗读 qwen3-tts-flash-realtime。选择后在下方填写自己的百炼密钥，默认萌宝女声，可试听切换。

                      VAD 灵敏度

                      低 = 停顿 1.2 秒提交，中 = 0.8 秒，高 = 0.5 秒。

                      干长任务时屏幕可以灭，任务在后台继续，做完会通知你。

                      服务器

                      开启后，任务在你的服务器上从头做到尾，手机锁屏、关掉 App 都不影响，打开时能看到进度和结果。对话和生成的文件存在服务器上。服务器上不能控制电脑、运行代码。

                      高级

                      显示

                      减少动画和光效，每页显示最近 12 条消息；更早的对话可翻页查看。不会删除记录或中断正在执行的任务。
