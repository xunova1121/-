          已安装

            MCP 工具连接

            MCP 是大模型连接外部工具的通用标准：接上浏览器自动化、地图、GitHub、数据库、各类办公软件的 MCP 服务后，贾维斯就能直接使用它们。技能教它“怎么做”，MCP 让它“能接触到”。

            MCP 服务要在本机启动程序，单文件版用不了。请使用桌面版，或双击 jarvis 文件夹里的 启动.bat 打开完整版。

                    界面明暗

                    “按时间”：7:00–19:00 用白天的浅色界面，其他时间用夜间深色。中间的粒子舞台始终是深色显示屏。顶栏的 ☀/☾ 按钮可以随时切换。

                    离开 10 分钟以上再回来（桌面版看键盘鼠标；开了人脸跟随时也看摄像头；网页版看标签页），贾维斯会结合时间、今天的定时任务、上次没做完的事打个招呼。40 分钟内最多一次。

                    版本

                    把记忆、对话、模型设置放到你自己的阿里云 OSS 存储空间里，电脑和手机自动合并。上传前在本机用“同步密码”加密，阿里云和任何人都看不到内容。建议在阿里云 RAM 里单独建一个只能读写这个 Bucket 的子账号，用它的 AccessKey。

                    每 20 秒看一眼你在用哪个程序（只记程序名和时间，不记窗口内容、网址、按键），汇总成习惯写进记忆，问好时会用上。数据只在这台电脑上，随时可以清除。

                      多助手分工

                      复杂任务交给小团队：规划员拆步骤，研究员 / 工程师 / 撰稿人 / 分析师各干各的，审核员检查不合格就返工。“自动”在一句话里有多个先后步骤时启用；随时可以用“/团队 任务”强制分工。会多花一些调用次数。
