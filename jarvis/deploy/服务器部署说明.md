# 未央服务器版部署说明（宝塔面板）

装好以后：手机 / 电脑把任务交给服务器，服务器从头做到尾。手机锁屏、关掉 App 都不影响，打开时能看到进度和结果。

**需要：**
- 一台云服务器，装好 Node.js 20 以上（宝塔：软件商店 → Node.js 版本管理器）；
- 一个已备案的域名；本文以 `d.leing.top` 为例。

未央只占服务器内部的 8787 端口，外面通过 Nginx 转发访问，不影响服务器上的其他网站和应用。

---

## 一、域名解析

在域名服务商（如腾讯云 DNSPod）添加一条记录：

- 主机记录 `d`
- 记录类型 `A`
- 记录值：服务器公网 IP

## 二、安装未央

1. **下载安装包**
   - 打开仓库的 Releases 页面，下载最新版的 `jarvis-server-1.0.xxx.tar.gz`（约 17 MB）。
   - 用宝塔“文件”上传到服务器的 `/root` 目录。
   - 服务器能连 GitHub 的话，也可以直接在终端运行：
     ```
     cd /root
     curl -LO https://github.com/xunova1121/-/releases/download/desktop-v1.0.xxx/jarvis-server-1.0.xxx.tar.gz
     ```
     把 `1.0.xxx` 换成实际版本号。

2. **运行安装脚本**（宝塔 → 终端，root 身份）：
   ```
   cd /root
   tar -xzf jarvis-server-1.0.xxx.tar.gz jarvis-server/deploy/install.sh --strip-components=2
   bash install.sh jarvis-server-1.0.xxx.tar.gz
   ```
   - 第一次安装会让你设 **访问密码**：至少 8 位，输两次，输入时屏幕上不显示。手机和电脑登录都用它。
   - 装依赖走国内镜像，一般 1～3 分钟。
   - 最后看到“好了：未央 1.0.xxx 已在运行”就成功了。

   安装脚本会做这些事：
   - 程序装在 `/opt/jarvis`；
   - 你的对话、文件都在 `/opt/jarvis/data`；
   - 用单独的系统账号 `jarvis` 运行，最多用 1.2 GB 内存（生成文档后转 PDF 检查时 LibreOffice 也算在里面）；
   - 没装 LibreOffice 的话自动装上（带中文字体，只装一次、几百 MB），生成的 Word / PPT / Excel 会真实转成 PDF 逐页检查；装不上不影响使用。不想装：`JARVIS_NO_OFFICE=1 bash install.sh …`；
   - 开机自动启动，崩了自动重启。

## 三、宝塔里配置网站

1. **添加站点**：网站 → 添加站点
   - 域名填 `d.leing.top`；
   - PHP 版本选“纯静态”；
   - 不建数据库。

2. **申请证书**：网站设置 → SSL → Let's Encrypt
   - 申请证书；
   - 打开“强制 HTTPS”。

3. **反向代理**：网站设置 → 反向代理 → 添加反向代理
   - 代理名称：`jarvis`
   - 目标 URL：`http://127.0.0.1:8787`
   - 发送域名：`$host`

4. **调大上传大小、加长等待时间**：网站设置 → 配置文件
   - 在 `server {` 下面加一行：
     ```
     client_max_body_size 50m;
     ```
   - 再到反向代理那一行点“配置文件”，在 `location` 里面加：
     ```
     proxy_read_timeout 3600s;
     proxy_buffering off;
     ```
   - 保存。

## 四、手机和电脑连上服务器

1. 打开**已经配好模型**的未央，手机 App 或电脑版都行，进入：设置 → 服务器模式。
2. 网址填 `https://d.leing.top`，再填访问密码，点“**登录并开启**”。
3. 点“**把本机的模型设置传到服务器**”。服务器上没有你的模型密钥，这一步之后才能干活。密钥经 HTTPS 加密传输，只存在服务器上。
4. 发一个任务试试，比如“做一份三季度汇报 Word”。做的过程中锁屏、关掉 App，过一会儿再打开，结果应该已经在对话里了。

其他设备也一样：填网址和密码登录。浏览器直接打开 `https://d.leing.top` 也能用，第一次会提示登录。

## 五、更新

**自动更新**：用 1.0.139 以后的安装包装过一次，服务器就会每天凌晨 4 点左右（北京时间）自己检查新版本。有新版会自动下载、核对、安装，然后重启。

**立即更新**：手机 / 电脑上进入 设置 → 服务器模式，点“立即更新服务器”。下面一行会显示服务器版本和上次检查的结果。

**手动更新**（以前装的、还没有自动更新的，先这样更新一次）：

```
bash /opt/jarvis/current/deploy/install.sh jarvis-server-新版本号.tar.gz
```

- 你的对话、文件和密码都不会动。
- 旧版本保留最近 2 个。
- 更新时服务重启 1–3 分钟，那时正在做的任务会标成“没完成”。
- 看自动更新的记录：`journalctl -u jarvis-update -n 50`
- 不想自动更新：`systemctl disable --now jarvis-update.timer`（“立即更新”按钮照样能用）

## 六、常用命令

| 做什么 | 命令 |
|---|---|
| 看运行状态 | `systemctl status jarvis` |
| 看最近日志 | `journalctl -u jarvis -n 50` |
| 重启 | `systemctl restart jarvis` |
| 改访问密码 | 编辑 `/opt/jarvis/jarvis.env` 里的 `JARVIS_PASSWORD=`，再重启；所有设备要重新登录 |
| 同时做多个任务 | 把 `jarvis.env` 里的 `JARVIS_MAX_TASKS=1` 改大。内存紧时别改 |
| 备份 | 打包 `/opt/jarvis/data` 整个文件夹 |

## 七、服务器上有什么、没什么

服务器上和手机 / 电脑一样有：内置技能（做 PPT、Word、Excel 的步骤和规范）、画图做视频、联网搜索和读网页（不填搜索密钥也能搜）、看你发的图片、记忆整理（做完会记住你的偏好）、长对话自动压缩。

下面这些暂时没有，手机 / 电脑上关掉服务器模式就能照常用：
- **控制电脑、运行代码**：服务器上没有你的桌面，也不运行代码。
- **PPT 看图检查**：服务器上只做文字层面的排版检查。
- **PDF**：先生成可打印的网页版，要另存为 PDF。
- **定时任务、语音、知识库、MCP 工具、多助手分工**：还在手机 / 电脑上。
- **以前的对话**：可以在 设置 → 服务器模式 点“把本机的对话传上去”；本机的记忆不会传。

## 安全提醒

- 访问密码别告诉别人。连续猜错 5 次会锁 10 分钟。
- 建议在腾讯云安全组里关掉 MySQL（3306）、宝塔面板（8888）对所有 IP 的开放，只留 80、443 和 SSH（22）。
- SSH 最好改成密钥登录，因为日志里能看到有人在试密码。
