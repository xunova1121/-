# DeepSeek 官方联网问答与截图

基于未央 1.0.467 开发。模型设置的「服务商 → 联网搜索 · DeepSeek Search/Fetch」提供「用官方 Flash 联网回答问题并附来源」。在需要的位置保存，并选用 DeepSeek 官方的 `deepseek-flash`。该开关默认关闭。本机与服务器各自保存，原生问答使用该位置的聊天模型密钥。

| 输入 | 实际路线与验收点 |
| --- | --- |
| 今天有什么新闻 | 快速模式。返回的每个引用必须带有本次成功搜索或读取所得的网址和有效文字范围。今日新闻校验北京时间的发布日期。 |
| 深度搜索某个公开话题 | 使用支持思考的搜索请求。逐条核实、特定对象新闻和生成研究报告保留专门流程。 |
| 总结一个公开网页链接 | 仅声明读链接工具。指定网址须有成功读取的回执，回答须含该网页的引用。 |
| 查公司股东或跟踪招投标 | 继续由企业工具处理。有来源的搜索摘要和已核实的登记信息分别标示。 |
| 看海报截图 | Flash 接收原图。能直接看图时省去转述步骤。海报生成和导出继续由现有工作流处理。 |

官方流式协议在正文结束时提供引用范围，范围按 Unicode 码点计数。程序对照本轮成功工具回执生成链接后再展示答案。缺少证据、引用过期或范围越界时转回已有查询。工具开始、完成及最终汇总共用调用编号，进度只计一次。鉴权失败、内容过滤和用户停止有独立处理。云端受次数配额限制的评测身份继续使用可预留次数的工具。

## 复测

`npm test -- tests/deepseekNativeWeb.test.js tests/deepseekSearch.test.js tests/companyProfileFallback.test.js tests/imageSight.test.js tests/evaluationAccess.test.js` 覆盖协议回放、企业检索和截图路由。模拟的流尾 token 用量只验证记录与展示。

已配置官方密钥的环境可分别运行下面两次测量。它们会真实调用模型，各处理一次新闻、公司股东和示意海报。海报样例在本地绘制。计时从聊天入口开始，“首字”指用户能看到的第一个正文字，不含搜索进度。控制台逐条输出耗时、每次模型返回的 token、原生调用、应用工具、独立 Search/Fetch 的 HTTP 成功次数和引用数。服务商没返回的用量保留为空。延迟与计费应结合多轮同类样本及账单判断。

```shell
node scripts/measure-deepseek-web.mjs existing
node scripts/measure-deepseek-web.mjs native
```

按 2026 年 11 月 18 日官方价格页，北京时间当日 12 时起，随模型触发的搜索与网页抓取仅计模型 token。独立 Search/Fetch 每千次成功请求各 5 元。回退到已配置的独立服务时，适用该服务的价格。[官方工具协议](https://api-docs.deepseek.com/zh-cn/guides/web_tools/) · [官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

固定源码 `28bcf00`，1,023 个运行文件逐个核对哈希。全量初跑有漏同步的国内查询测试脚本、测试启动后仍在调整的用例和超时项。同步脚本后，网关外网测试使用环境代理，沿用原超时值。最终在固定源码上单次完整运行，498 个测试文件、4,409 项单测全部通过。

- 新增 28 项回归，覆盖新闻、直接阅读链接、显式深度搜索、来源失效回退、用户中止、企业股东工具、上传海报、两端配置隔离和评测配额。新闻协议回放从聊天入口发出 1 个模型请求，收到 1 次搜索进度，独立搜索调用 0 次。
- 模型设置在 1280 和 390 像素宽度下通过 58/58 项浏览器检查，含本机与云端的开关隔离。离线版检查 14/14。生产构建及代码检查通过。
- 浏览器冒烟测试初跑 172/174，两个失败项为启动形态和 WebGL 恢复时间。单独运行同一脚本通过 174/174，其中 WebGL 恢复总耗时 1030 毫秒，应用处理 39 毫秒。
- 本批工作区没有官方 API 密钥。真实端到端首字、付费模型 token、线上回答质量、实际账单以及手机真机仍待测。开发版的开关随之后的安装包交付。

## 文件、搜图、语音与对话增强（第二批开发）

在模型设置中选择「本机」或「云服务器」，配置该位置的 DeepSeek 官方服务商 Key。进入「服务商 → 联网搜索 · DeepSeek Search/Fetch」，根据需要勾选官方 Flash 联网和官方文件问答、OCR 与对话增强，点击「保存搜索设置」。独立网页检索仍有自己的开关。已有用户升级时保留原配置。

| 能力 | 使用方法 |
| --- | --- |
| 以图搜图 | 选择官方 deepseek-flash 并开启模型内联网。上传图片后输入“找这张图的出处”或“找同款”。点击返回的图片及来源页核对。普通看图仍可直接分析。 |
| 附件问答 | 开启文件能力，上传文件并提问，例如“这份 PDF 的图表显示了什么变化”。文本、电子书和 Excel 用 user_data。Word、PPT、PDF 可做文字或图文混排解析。模型读取已附附件时按需调用；逐页查原文、改稿继续走现有读取工具。 |
| OCR | 启用文件能力后可识别扫描件、照片、Word 或 PPT。可要求保留图文版式。手工选择智谱的用户继续使用原线路。独立 OCR 沿用应用的 10 MB 上限，文件问答上限 32 MB。 |
| 录音与朗读 | 在声音设置分别选择 DeepSeek 语音识别或官方朗读。录音切句后发送。朗读有海星、暗潮两种音色，支持整段 WAV 和 WebSocket 流式合成。在云服务器模式由已登录的未央服务器访问官方语音接口，密钥保留在服务器。 |
| 标题、日期与审核 | 官方 Flash 可在首轮随回答生成标题，已手工命名的会话保留其名称。请求带北京时间和中文提示，位置字段留空。高等级内容审核通过后才展示回答。 |

文件问答上传时先设置一小时有效期，结束或取消时请求删除本次文件。删除网络请求中断时依靠已设置的到期时间。启用服务后，附件、音频、朗读文本按所用功能传给 DeepSeek 并按官方规则计费。独立搜索 Key 仅供 Search、Fetch 使用。

官方发布清单与协议见 [11 月 13 日公告](https://api-docs.deepseek.com/zh-cn/news/news261113/) 和 [应用接入指南](https://api-docs.deepseek.com/zh-cn/guides/build_a_chatbot/)。
