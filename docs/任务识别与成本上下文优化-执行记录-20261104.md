## 问题与落地行为

用户上传的“你好.md”显示：SVG/HTML 动画的“重新做”“继续”反复进入查询超时，口语“你在这儿文件里面做一个电商项目”没有稳定识别为编程，未来起名计划有被写成既成事实的风险。这份材料是导出的对话，不包含完整模型调用轨迹，不能据此确认实际模型或计费。

1. 前后端共用任务识别。聊天、普通工作、代码按用户原话及本会话任务索引判断，不额外请求一个模型分类。裸 Python/JS、口语网页/电商创建进入代码能力；谈 API 费用不会仅因 API 名词进入代码。代码续做不再套普通查询的60秒硬截止，原代码总时限仍保留。
2. 短句“继续/重新做”沿用本对话目标；进度查询不启动编辑，取消后不续做。明确转查天气/新闻等新领域重新识别，普通闲聊回到配置的聊天模型。用户明确固定模型仍优先。仅识别类型不授予仓库、文件或外部操作权限。
3. 按当前任务先携带常用工具说明。天气、新闻、行情、计算、代码、文档各有适当集合；其余工具通过原目录和 tool_search 查找，按名称直接调用也能加载。看图、电脑操作、严格架构等保留原完整集合，权限检查不变。
4. 压缩同时看消息数量和保守文本容量估算。普通短消息沿用20条保留/10条一批；少量长消息超预算也可压缩，至少保留最近6条。摘要不再截断每条用户消息到1500字；一次摘要输入超过预算改成本地首尾索引，完整原话、需求账本和回读入口继续保留。摘要有损，不能把它当全文核验。
5. 工具结果缩短时优先留状态、失败码、来源、时间、单位、数值及文件路径；正文原件可按编号分段回读。缓冲最多256000字符，过期/超大结果需要重新读来源，不伪造缺失数据。假设/计划的原话索引标作 hypothetical，助手旧说法不升级为用户事实。
6. 后台摘要用聊天能力，最多一次在途、单次15秒、无联网及隐式重试；前台新问题取消摘要。服务器不再在会话写锁里等待摘要模型，写回前核对旧摘要版本及取消信号。桌面/网页等20秒空闲再摘要。原记忆反思功能保持，并未声称全部后台模型调用已移除。
7. 任务需要更多能力时，模型可以申请切换到用户明确配置的编程/推理线路；每轮至多一次，切换后最多4次主请求，原任务步骤/时间预算不重置，关闭额外备用与重试。无关工具成功不能清掉未恢复的接口故障；网络、权限、鉴权、空行情等失败不能靠升级解决。未配置能力线路、固定模型、关闭开关时不提供升级工具，不从普通模型库擅自挑型号。
   本批能力升级仅用于文字任务；已带图片、电脑操作或工具刚读出图片时保留现有线路，避免切给未验证看图能力的模型。工具的申请回执与真正生效的模型切换记录分开。
8. 设置 → 模型 → 任务费用控制新增能力切换开关，说明额外费用、次数边界和本机/云端作用范围；云端写入仍需要管理员身份。开关放在“手动连接诊断”之外，避免与后者“仅修改本机”的说明冲突。切换提示区分能力切换、超时和故障，避免把正常能力切换写成模型报错。

## 范围和限制

- 任务索引每会话最多2400字，仅为目标索引；原要求在原消息和独立需求账本，超长索引注明回读。不同用户/会话沿用原隔离存储。
- 本版以32K保守软预算估算文本容量，不是服务商计费 Token，也不是已经自动获取每个模型的真实上下文上限。大型附件仍需按需读取，不能宣称任意长输入都可塞进模型。
- 规则识别并非完整自然语言分类器；歧义任务仍可能需要澄清。能力切换是已有配置线路之间的选择，不保证该线路对每道题更优，也不按未知模型价格计算精确金额上限。
- 没有删减实际交付校验、真实工具回执、文档保真或代码执行权限。没有把模拟模型的毫秒耗时当作真实加速结果，也未承诺具体省费比例。
