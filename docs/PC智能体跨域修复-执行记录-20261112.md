# PC智能体跨域加载修复（2026-11-12，未发布）

用户在1.0.423 PC安装版看到“读不到智能体列表 / Failed to fetch”，并确认普通聊天正常。已同步最新分支387e05e；未读取或修改用户服务器配置、密码或Key。

## 原因与修复

- 电脑版从本机http://127.0.0.1页面调用另一地址的云服务器，受浏览器CORS约束。server/server.mjs的SERVER_CORS已覆盖/api/sessions、/api/tasks等普通聊天接口，却漏了/api/agent-profiles、/api/studio/...和/api/tenders/...。
- 带Authorization的请求先发OPTIONS；旧服务器对漏列路径把预检按未登录请求拒绝，实际响应也缺少允许跨域的响应头。浏览器只暴露Failed to fetch，不能据此认定Key错误。
- 仅补已实现的智能体资源路径：智能体列表/个人配置，作品库/偏好/团队操作，招投标目录/本人订阅/管理入口。预检不执行读写；实际请求继续原登录、成员、评测及账号隔离检查；本机网关与任意API不新增跨域权限。
- 此处修复在服务器程序中；后续统一发版需更新服务器，仅更新PC界面不能改变旧服务器的响应头。按用户“做完之后统一发版”要求，本次不触发发布。
