# 架构图升级需求（给 Codex，2026-10-26，用户确认由 Codex 做）

## 背景
用户拿同一份材料（长江十年禁捕 / 渔业执法监管项目）对比：GPT 画的“项目总体架构图”能直接放进方案汇报，
未央（`create_diagram`）画的只有三层方框，差距明显。用户会在 Codex 会话里把两张对比图发给你
（**不要把这两张图提交进仓库：仓库是公开的，图里有客户项目信息**）。

Claude 看过代码后的判断：**差距主要不在模型，而在画图程序只认一种结构**（层 → 节点{标题, 说明} → 连线，
每层最多 4 列、3 套单色主题、节点不能单独设颜色/图标）。模型想画丰富也没有零件可用。
结构化路线（程序算坐标、查重叠、四格式同稿导出）是对的，**不要改成让模型自由写 SVG/HTML**，在现有路线上加零件。

## 目标样例里有、未央没有的东西
1. 7 层而不是 3 层：界面展示层（大屏 / PC / 手机）→ 业务应用层（预警端 → 指挥端 → 执法端）→ 闭环反馈条 → 平台（业务模块网格 + 能力层 + 感知与协同层）→ 终端感知 / 网络传输 / 云基础设施三栏 → 安全保障通栏。
2. 具体内容：设备数量（双光谱云台 32 套、雷达 12 套、执法终端 74 台……）、系统名称、每个端 4 条要点；未央只写一句概括。
3. 视觉零件：带图标的卡片、每端一种强调色、卡片底部彩色标签（“智能识别研判”）、同层卡片之间带文字的箭头（“结构化线索”“任务工单”）、横贯全宽的通栏、十几个小方块的模块网格、层左侧标题 + 灰色副标题、主标题下一行蓝色口号。

## 要做的（按优先级）

### 1. 扩充零件（主要工作量）
在 `diagramModel.js` / `diagramScene.js` 的结构化模型上新增，坐标仍由程序算，`validateDiagramLayout` 照样查越界和重叠，SVG / PNG / PDF / PPT 仍从同一 scene 导出：
- **卡片节点**：`icon`（复用 PPT 已有的 Lucide 预渲染图标，见 `pptIcons.js`，不新增依赖）、`accent`（强调色，限定在主题色板内几种）、`bullets`（2～5 条要点，每条可带小图标）、`badge`（底部彩色标签文字）。
- **同层流程箭头**：边可以带 `label`，同一层相邻节点之间画水平箭头 + 文字（现在的边只有跨层连线、没有文字）。
- **通栏层**：`kind: 'band'`，一行全宽色条，放闭环说明、安全保障、标准规范这类贯穿内容；可放在层与层之间或最底部。
- **网格层**：`kind: 'grid'`，一层放 8～18 个只有标题的小方块（业务模块清单），自动多列（不受“最多 4 列”限制）。
- **分栏层**：一层分成 2～4 栏，每栏有标题、蓝色小标题和两三行说明（终端 / 网络 / 云三栏那种）。
- **层标题副标题**：已经支持 `标题 | 副标题`，保持。
- **主题**：新增一套“政企方案蓝”（主蓝 + 橙 / 蓝 / 绿三种强调色，浅蓝底），作为政企方案的默认主题；原 navy / jade / charcoal 保留。
- 限额照旧写清楚并有上限（节点数、要点条数、文字长度），超限报错让模型删减，不悄悄截断。

### 2. 画之前先规划内容（改动小，见效快）
- `create_diagram` 的工具说明和系统提示里加：总体架构图先按政企项目常见层次列提纲——用户 / 展示 → 业务应用 → 平台能力（模块、能力中心）→ 感知 / 数据 → 基础设施（终端、网络、算力 / 云）+ 安全保障、标准规范两条贯穿；材料里有的**数量、系统名、设备型号逐项填进去**，不要一句话概括。
- 材料里没有的层不硬编内容（不编数量），可以只写通用能力名称。

### 3. 画完自己看一遍
- 代码里已有视觉复核（`diagramReview.js`），用户没配看图模型时显示 `visual: not_checked`。保持如实显示；交付回执里提醒“配置看图模型后可自动复核”。

## 不能做的 / 要保留的
- 先读 `docs/已修问题清单-不许回退.md`；不改坏现有架构图的同稿导出、原生 PPT 对照门槛（差异超限要如实拦下，不调松阈值）。
- 旧的 `.diagram.json` 设计稿要能继续打开和导出（新字段都是可选的）。
- 不改文档写作角色（`src/app/doc/writingRoles.js`，Claude 今天做的）。
- 新增零件要加测试（布局不重叠、文字不溢出、四格式产物一致），以目标样例的结构做一个测试用例（用虚构内容，不放客户真实项目名）。

## 验收
用同一份材料重画一次，和 GPT 那张对比：层次完整、有具体数量、有图标卡片、流程箭头带文字、有闭环通栏和安全通栏、模块网格清楚。截图给用户看。
