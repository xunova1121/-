## 本批实现

### 分阶段诊断

`shared/taskTiming.js`仅保存数值计数，不复制用户问题、模型正文、URL或密钥。

| 字段 | 含义 |
| --- | --- |
| queueMs | 创建任务至开始执行；排队停止时为等待时长 |
| firstTextMs | 创建任务至首个非空白可见文字，包含排队；可能是过程说明而非最终答案 |
| contextMs | 执行器原有上下文计时累计，不包含所有服务端准备 |
| modelMs | 主执行器模型请求时间，包含接口内部等待、重试、原生搜索 |
| toolMs | 工具执行区间并集，并行工具不重复累计；可能包含工具内部辅助模型和子任务 |
| executionMs | 执行开始至生成/失败处理入口；未执行任务为null |
| totalMs | 创建至生成/失败处理入口；不包含最终写盘、下行网络和客户端显示 |
| modelCalls / retries / fallbacks | 主循环请求次数、重试通知和备用切换次数；不等于完整计费请求数 |
| toolCalls / failedTools / nativeSearchCalls | 工具开始、明确失败结束、原生搜索通知次数；取消中的工具不是已确认失败 |

分项范围不同，不能简单相加。无首字为null，不能填0。后台记忆整理独立于当前回复，不计入。数据随任务GET、最终task_state事件、助手消息和会话taskCheckpoint保存；没有输出就失败也有检查点诊断。既有摘要日志保留，追加`[任务耗时] taskId {JSON}`。

### 60题真实任务入口

`jarvis/evals/cases.mjs`包含日常10题、搜索15题、文档15题、编码10题、长任务10题。电视剧268秒原话、小说结局、新闻、天气、娱乐等均有覆盖。

`runner.mjs`调用已有真实服务器任务接口，不绕开任务执行器；每题独立会话和文件前缀，使用请求编号，不自动重发POST。长任务通过原任务notes接口补充，结束太快未补充会标记未覆盖，不能假装验证过插话。

默认只预览，显式`--live`才调用真实模型；默认选前三题，批量需指定题号。拒绝演示模型和繁忙服务器。测评会消耗已配置模型/搜索额度，并留下评测会话和文件，不自动清理用户工作区。

报告中执行成功仍为`quality: not_reviewed`，文档为`artifactReview: not_checked`。`verifiedPassed`只有实际人工审查并标记passed且没有协议问题才计入。费用暂为null，不是0；本批没有准确token/计费遥测。实时问题须按执行时间核实，不能固定旧答案。

### 使用

代码仓库在jarvis下；发布后的服务器安装目录也包含evals。

```bash
npm run eval:agent -- --ids=search-01,documents-01,long_task-01
```

以上仅预览。真实评测在服务器主机配置`JARVIS_EVAL_URL`、`JARVIS_EVAL_TOKEN`环境变量，再运行：

```bash
npm run eval:agent -- --live --ids=dialogue-01,search-01 --out=eval-result.json
```

本机地址可为http://127.0.0.1:8787；远端必须HTTPS。TOKEN是已有登录接口返回的访问令牌，不是模型密钥。不要把令牌粘到公开仓库、命令参数或聊天中。报告含真实回复和文件路径，保存在本机，分享前先检查隐私。

单题超时、协议失败或Ctrl+C会请求停止已知任务；停止请求失败会在报告提醒，不自动开下一题。提交响应丢失时标submission_unknown，不能假设未执行，不自动重发。强制杀进程、断电、未知提交仍需服务端按请求/任务编号检查，不承诺所有情况下取消成功。

查看慢任务可从任务GET的timing、会话taskCheckpoint.timing或journalctl日志定位。先区分queue/model/tool，再优化对应阶段，不把总预算退出当成成功提速。

## 验证与边界

新增标准Node测试覆盖计时并集、零时刻/空白首字、排队取消、认证HTTP、重定向、60题完整性、只预览、评测超时停止、未知提交不重试、插话绑定和取消。新增三个真实任务执行器集成回归，原有测试全部保留。CI增加eval:check，并保留Office真实渲染、隔离代码、手机/网页/服务器和Electron检查。

本地受限环境禁止HTTP监听，一项实际HTTP测试需在CI运行，不能跳过后宣称全过。没有用户模型密钥、服务器登录或鸿蒙设备，尚未产生60题真实通过率、真实模型提速百分比、声音流畅度或手机崩溃修复结论。

本批不改变模型选择/推理档位、不新建付费服务、不新增依赖、不改变用户配置与数据目录。服务器诊断要更新服务器才生效。独立验证分支不能发布正式包，正式发版以正式分支Actions成功和Release资产为准。
