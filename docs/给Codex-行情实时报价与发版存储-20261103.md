| 用途 | 地址 | 解析要点 |
|---|---|---|
| A/港/美股与指数报价 | `https://qt.gtimg.cn/q=<symbol>` | GBK 文本；`~` 分隔，[1]名称 [3]现价 [4]昨收 [5]今开 [30]时间 [31]涨跌 [32]涨跌幅 [33]最高 [34]最低 |

| 金价、离岸汇率、港美指数备用 | `https://push2.eastmoney.com/api/qt/stock/get?secid=...&fltt=2&fields=f43,f44,f45,f46,f58,f60,f86,f169,f170` | secid：上海金 `118.AU9999`、伦敦金 `122.XAU`、汇率 `133.<币种>CNH`、指数 `100.HSI` / `100.DJIA` / `100.NDX` / `100.SPX` / `100.N225` / `124.HSTECH` |
| 每日参考汇率（备用） | `https://open.er-api.com/v6/latest/<币种>` | `rates.CNY` |

- 任何一项解析不出来，代码都会当没取到，退回搜索，不会给错数。但那一项等于没生效，需要按真实返回修解析（测试只加不删）。
