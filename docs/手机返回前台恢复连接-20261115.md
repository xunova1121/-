# 手机返回前台恢复连接（2026-11-15）

用户反馈切去其他应用再返回未央后连接服务器缓慢，模型列表一直“正在读取配置”。截图原生错误为`Failed to connect to d.leing.top/118.195.157.190:443`。诊断时本环境访问该站health和首页HTTP 200，约2.3秒；这不能证明用户手机当时网络正常，443失败的手机路由原因仍待真机核对。用户已明确“开发吧然后发版”。

## 改动

- `src/core/serverResume.js`统一原生前台、网页可见性、焦点和网络恢复，同轮750ms合并；真正online可补一次前台失败探测。后台没有轮询保活。composer预热与conversations刷新改用该入口，不操作导航、队列或任务提交。
- `serverClient.followTask`返回前台立即取消旧观察/退避，从已收seq续接同一任务；前台主动续接不误判流式失败。真实失败仍最多连续5次，401/403/404仍终止；关闭/停止后卸载监听，迟到事件不能复活任务。不自动停止或重做服务器任务。
- 健康、配置、会话列表/正文、任务状态读取每次5秒、最多两次；预热仅一次且在途合并，新前台可绕过30秒节流。原生连接/读取层也接收期限，避免JS已放弃、原生仍按180秒挂起；通用原生默认、文件120秒、流/模型等原设定保持。
- 模型预览只白名单保留显示所需型号、线路名称、能力分工、只读状态。最近一个服务器/账号，24条常用、32000字符、24小时；不存密钥、token、URL、搜索配置或全目录。主人与成员分别隔离，评测身份/无可信用户ID不落盘。旧登录换发从已认证响应补userId/role，沿用原换发次数。
- 完整掩码配置仍只在内存；预览只供轻量选择器渲染，不给设置写回。模型切换每次重新读取实际配置、只写差量并回读确认。并发刷新合并；切账号后的旧读取/排队写入不能覆盖或修改新账号。

## 验证与限制

本批新增`tests/serverResume.test.js`、`tests/serverModelPreview.test.js`；正式mobile构建下`e2e/server-resume.mjs`使用真实本地HTTP、SSE、服务器账号和任务，模拟原生前台事件，验证立即续接、序号去重、不重复提交、配置挂起时重建后的预览和换账号隔离。新e2e加入原完整发布工作流，既有门禁未删除或降级。

开发初验：恢复/预览测试及原serverClient/serverObservation/modelLibrary/凭据/原生重定向回归通过；新浏览器9项通过。初次浏览器脚本误点手机收起状态的模型按钮，改为与原model-library门禁相同先聚焦输入框，再点模型入口；应用没有为测试调整显示条件。完整单测、完整CI与发布成品核对结果后续补记。

实际Android/Windows设备、微信、VPN与Wi-Fi/流量切换、用户服务器未实测。未新增常驻服务/权限，不保证安卓永久保持网络，不把缓存显示当作联网成功。服务器不承担其他安装包中转，沿用三端统一构建/原APK签名/固定更新索引；未获得用户服务器登录，不声称直接部署。
