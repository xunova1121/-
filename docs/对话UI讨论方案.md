# 未央陪伴感加强版：开发依据与验收

2026-10-16：用户先要求讨论方案，查看两版概念图后选择“未央更突出一些，增加表情和陪伴感”，随后明确授权按最后一版开发。以下为本轮实现范围，不再是待确认的开发权限。

## 手机

- 近白底色、淡紫点缀，正文便于阅读。输入区保留附件、拍照、语音、发送；模型与声音、技能可从“更多选项”进入。
- 最新短回复展示较大的未央和短状态回应，使用同一个角色节点表达思考、搓手、查找、开心等状态。旧消息与长回复缩小角色，避免持续占据阅读空间。长回复判定为超过 480 字符或 10 个换行。
- 工作进展加入小未央，默认一行，点开查看步骤；完成后停止执行状态并保留成果。
- 点击头像打开居中陪伴面板，大角色与六个常用动作按钮、更多表情、摸头互动、文字输入、语音与结束按钮。动作指令与正常任务分开处理，复合任务不能被动作匹配吞掉。
- 表情图集有十二个不同姿态：陪伴、眨眼、搓手、思考、挥手、比心、开心、害羞、睡觉、狂奔、转圈、跳舞。摸头有单独的互动反馈。
- 键盘弹出时缩小角色、收起动作按钮，保留输入与发送位置。阅读旧消息时不强制拉到底部，可一键回到最新回复。

## PC：用户截图指出的两项约束

- 左上角未央图标放大，点击仍可打开陪伴面板；折叠导航时保留合适尺寸。
- 每条回答只保留左侧一个可变表情头像，去掉名字和时间后面的第二个图标。PC 不在每条长回答中插入手机的大角色。

## 性能与可访问性

复用一张透明表情图集，避免为每条消息创建 WebGL。旧消息停止动画，后台暂停，尊重减少动画设置。可点击头像至少提供 44px 点击区域、键盘入口与明确的可访问名称。陪伴面板支持关闭、返回键与焦点返回。

界面概念图只是视觉依据，两侧宣传文案、海报装饰不进入实际 App。声音仍取决于实际服务，角色可爱不代表已获得真实女童音色。

## 验证

保留完整单元测试、网页版和单文件版检查；新增对真正 build:mobile 产物的自动化检查和截图，覆盖角色大小、键盘、长回复、进度折叠、摸头、动作、设置入口与滚动。浏览器模拟键盘和流程不能替代鸿蒙 4.2 真机语音与后台实测。
