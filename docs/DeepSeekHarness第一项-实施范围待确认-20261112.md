# dsh借鉴第一项：防原地打转（实施范围待确认）

依据《交接给Codex-DeepSeekHarness借鉴与联动-20261112.md》第一/四节及用户本轮要求，一次只做一项，确认后才修改。当前仅完成代码调查，未实施本项；PC跨域修复已验证并等待统一发布。

## 已有机制，不重复新建

- agentToolExecution.js已有seen（最多128项）：无状态同工具同参数最多执行2次；声明状态续接的最多4次。电脑动作和手机读屏另有专用规则。
- agent.js收到新的用户指令会清空seen；最近大量失败时已有停止与最大步数保护。
- tests/agent.test.js已有原地打转回归，保留。检索时间预算、文档验收、图形恢复、手机操作回执、失败冷却继续沿用。

## 拟做的增量

1. 规范化调用标识：对象字段顺序不同仍识别为同一参数；数组顺序、字符串内容保持语义，计数按当前任务隔离且有上限，不把参数原文新增到日志。
2. 保留现有最多2次规则和专用例外，给重复拦截固定错误码。发现连续轮次全部是已拦截重复调用时，提醒换方法或依据已有结果收尾；有真实新进展、状态续接或用户新指令时不能误停。避免继续耗到总步数上限。
3. 支持工具声明单独超时，不能超过已有整轮/检索预算；取消继续传播。对写入/操作类超时，只能标明执行结果未确认并停止重复执行，不能当作“肯定没做”自动重放；保留既有长文档和多步骤任务的时限。

## 文件与规模

- 新增src/agent/toolCallGuard.js：有界调用标识和重复/超时辅助逻辑。
- 修改src/agent/agentToolExecution.js：接入统一错误码、既有例外与超时策略。
- 修改src/agent/agent.js：连续无新进展时有界收尾；新指令重置；不改模型路由或工具加载架构。
- 新增tests/toolCallGuard.test.js、tests/agentRepeatGuard.test.js与相应合成模型e2e；保留全部旧测试。预计3个运行文件和2～3个测试文件，属于小到中等改动。

## 验收

- 参数键换序不能绕过；真正换查询、分页、改文件后重读不误判；状态续接、电脑/手机原规则不回退。
- 多个只读调用并发和两个会话互不串计数；用户补充指令恢复合理同参调用。
- 反复被拦后及时结束无效循环，记录改前/后实际工具执行次数和合成模型调用次数；不冒充真实模型token节省数据。token实测属于第二项。
- 超时可取消、迟到结果不得作为成功回执；有副作用的未知结果不自动重试。
- 合并本批已授权改动后跑lint、全量vitest、构建和新旧e2e，独立提交运行清单，再统一发三端。当前尚未实施或承诺通过。

本项只在未央内部补强现有保护，不安装/运行dsh，不建立MCP联动。后续任何dsh联动按交接要求先说明并明确禁用默认会话上传；不改插件架构，不引用未核实的网络数字。
