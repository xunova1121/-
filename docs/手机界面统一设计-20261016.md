# 手机界面统一设计与故障排查

本轮用户授权：六项反馈直接开发、测试和发布；无需再次等待确认。

设计方法：[frontend-design SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)，已核对同目录 Apache-2.0 LICENSE。仅采用统一视觉规范、先规划后实现与截图自检的方法，自行编写代码。

## 设计规范

- 角色是视觉重点，正文与操作保持安静；不通过放大所有头像制造陪伴感。
- 日间：云白 #FCFBFF、纸白 #FFFFFF、正文 #2B2B43、次要文字 #76718C、未央紫 #8567CB、边界 #E9E4F2。系统状态栏、顶部栏、面板使用同一个云白基底。
- 夜间：深靛 #191923，卡片 #242332，正文 #F0EDF7；所有表面都跟随主题，避免白顶栏与深色文字混用。
- 字体使用设备中文无衬线，正文 15–16px，标题 21px、字重 650；不额外下载字体。
- 顶栏 64px，角色容器 48×52px、角色自身 48px；标志与“未央”间距 8px，垂直居中，不侵入对话。
- 手机正文在屏幕两侧各保留 20px（极窄屏至少 16px），长回复保持单栏阅读；输入框外侧 12px。
- 陪伴面板中角色区域与标题是独立行，角色尺寸不超过区域高度；动作缩放在留白内发生。键盘出现时退让。
- 输入区第一行输入，第二行附件、拍照、当前模型、通话、发送；忙碌时停止按钮独立显示。声音设置留在设置页，模型菜单就地展开并直接切换。

```text
菜单   [未央角色] 未央                     明暗

    未央 · 时间
    正文 / 工作进展 / 成果
    左右保留固定阅读留白

  ┌ 输入消息                               ┐
  │ 附件 拍照  当前模型⌄       通话 发送    │
  └───────────────────────────────────────┘
```

审阅：沿用未央的角色和紫色品牌，不套用通用仪表盘卡片。上一版“2px 正文边距”“容器矮于角色”“面板残留旧紫底”均不符合上述规范，直接替换规则而非继续局部放大。

## 稳定性边界

用户已确认在 1.0.94 仍崩溃，最新诊断尚未补充。不能把旧 1.0.88 的记录当成新版本故障结论。继续保留连续崩溃保护、历史分页和兼容模式；新增可复制的版本、WebView、渲染事件和界面规模诊断，避免只依赖旧截图。没有真机原生日志时不宣称已找到或永久解决新的触发点。

## PC 追加反馈

- 粗滚动条与上下箭头：侧栏外层固定，不再与最近对话形成嵌套滚动；记录列表独立滚动，使用 6px 细轨道、隐藏箭头，悬停/键盘聚焦才显示滑块。
- 常用入口（文件、技能、定时）单列，资料工具（连接、记忆、知识库、实验室）双列；窗口高度不足时缩减导航间距，为最近对话保留空间。
- 陪伴模式“更多表情”在相同区域换页，避免把整个弹窗拉长。关闭后恢复默认的语音/动作布局；窄高度窗口缩小角色，关闭和操作按钮仍可见。
- Windows 原生窗口按钮位于网页遮罩上方，不能靠网页 CSS 自动变暗；使用已有的受限 `setTitleBar` 接口，把原生按钮底色与弹窗遮罩混色同步。关闭恢复；原有定时主题逻辑交给同一控制器，防止过一会又刷回白色。

PC 新增 768px / 600px 窗口高度检查，表情换页不增高检查，以及原生标题栏混色、开关恢复和失败重试单元测试。没有直接操控用户 Windows 桌面，原生窗口按钮的最终视觉效果仍需实机确认。
