# 安卓分享返回与原图复核

## 用户现象与定位边界

用户反馈分享到微信后停在微信或未央退出，再次打开不顺利；另有“分析这个图”连续六次区域参数错误。两项均纳入此次海报与Demo批次，完成验证后统一发布，当前尚未发布。

核对历史代码发现，旧版仅修复“下载不自动跳分享”，主动分享依旧调用系统选择器并提示从最近任务返回。没有分享返回指针、专用返回入口及相应恢复测试；不能说已证明任务栈配置回退，也不能在没有手机日志时认定退出的唯一原因。

原图复核的截图报错来自本地参数校验：单区/多区冲突、坐标不在0～1。原执行器只按完整参数计重复，换问题文字或键顺序可避开，同类参数失败没有独立上限。六次失败不构成本轮复核成功；最终分析可能另有前置看图信息，不能凭该截图断言全部来自猜测。

## 实施边界

- 保留下载只存到文档目录、失败才分享的旧行为。主动分享使用共享互斥与独立缓存名，回执仅称“已请求打开”，不称微信发送成功。
- Android 8及以上、系统和频道通知均允许时，提供30分钟静默“返回未央”通知；仅用户点击时打开原任务。不自动拉回前台、不改launchMode、不增加权限/常驻服务。
- Android 7或通知不可用仍可正常分享，明确没有通知入口。原生按单条随机标识与期限管理，旧回调不能清新状态。
- 分享前只保存账号/服务器摘要、会话及可选文件路径指针，不保存Key、正文或图片。稳定返回只清理状态；进程重建恢复原会话，不自动重发、反思或重做任务。用户主动新建、输入草稿、切账号后不能被迟到恢复覆盖。
- 原图复核默认使用path/question整图输入。合法数字字符串与明确具名坐标归一化后再裁剪；非空冲突、越界、无格式四元数组、像素或百分制不猜。旧空regions数组拒绝规则保留，错误给出一次可执行纠正方法。
- 同图最多连续两次参数错误；首次可纠正一次，第二次停止本轮空转。成功、不同轮次和用户明确新指令按规则重置；网络/API/取消错误不误算输入错误，不新增全局冷却。
