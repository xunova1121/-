# App 浅蓝紫统一界面

## 用户确认的方向

以用户上传的两张手机界面截图及最终浅蓝紫设计稿为视觉基线；不采用此前奶油白、杏色或32px大标题。未央沿用已确认的水蓝金色小精灵，不引入参考软件的人物形象、代码、商标或模型标签栏。

## 设计与范围

- 手机浅色：背景 `#eef0ff → #eeecfc → #e8edfc`；半透明白面板；紫色主操作。
- 手机夜间：保留用户主题选择，使用配套深蓝紫背景与浅文字；不会强制白天。
- 正文以1rem为基准；首页问候18px、顶部17px、辅助12—13px。不下载未知许可字体，优先系统 HarmonyOS Sans / MiSans / PingFang / Noto Sans SC 等；实际使用取决于设备。支持根字号放大。
- 首页保留真实定位天气及详情，天气整体归拢右上角；点击天气图标进入详情，独立倒三角切换位置，日期在左侧。改为居中角色和三条可轮换建议；点击建议先填写草稿，明确发送后才请求模型。原文件空间入口保留。
- 对话使用小头像、正文阅读面板和轻进度卡；文本和表格仍按原流程渲染。空输入保留听写与电话；有草稿显示发送；生成中停止和补充入口保留。
- 陪伴采用完整手机页面，保留原dialog焦点/关闭/语音生命周期和全部动作。键盘出现时让出动作区，优先保证输入和发送可见。
- 对话、文件、知识库、记忆、技能、模型、定时任务、设置、天气详情及模型选择器统一使用主题令牌。
- 新形象是批准的12格透明图集，手机各状态对应到相应格。动作是轻量CSS，不冒充逐帧骨骼动画或精细口型同步。
- 启动页新增独立8帧透明图集，眨眼、挥手而不旋转。原生启动底色、系统栏、网页启动页统一浅蓝紫；加载完成即退出，不强制等待两秒。主界面夜间设置保留。减少动效和安全渲染时立即退出启动动画。
- 常规电脑版工作台与mount顺序不变；main.js原启动业务搬到UI模块；不修改模型/语音协议、任务执行和生产服务器配置。

## 验证口径

新e2e/mobile-theme.mjs基于真正build:mobile产物，在320/390/412宽度检查首页、八个内页、夜间、完整陪伴、摸头响应、大字体、输入区和横向溢出，保存截图。使用假天气，无真实模型或收费API。

mobile-ui.mjs只更新与旧设计绑定的视觉断言：横排改居中、32px大标题改18px、旧近白/夜间颜色改新令牌、陪伴标题移至角色上方。原功能断言不删除、不跳过。新形象没有独立眨眼帧，因此原来的“眨眼动画名”断言调整为实际漂浮和点击变换验证，不宣称已制作精细眨眼。

没有鸿蒙/Android或Windows真机测试时，应在交付中明确。自动构建、截图和浏览器E2E不等于真机通过。

启动退出单测使用假DOM与假定时器，覆盖立即退出、过渡/兜底去重、减少动效、安全模式、桌面及缺失节点。鸿蒙和安卓原生冷启动仍需真机检查，浏览器不能证明无原生黑帧。
