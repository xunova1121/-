# 架构图第4块：候选预览、视觉比较与有界间距修复

范围：create_diagram可选quality=compare，默认standard保留旧路线。先生成原版与纵向舒展12%的版本，均从相同结构化scene推导；不改文字、颜色、拓扑、图标尺寸，不让模型写SVG/HTML。它是两种间距方案，尚不是任意版式搜索。

配置看图模型后送实际PNG比较，最多8条、每条240字结构化意见。最多一次间距修复（8%），只处理全为spacing的问题，再次真实渲染和审查；其他问题保留failed，不删除内容、不无限重试。两次请求各45秒、发前扣预算、禁原生搜索/隐藏重试，停止和预算上抛。未配模型或非法结果是not_checked，不虚报通过。实际PNG失败不作为候选。

每次最多3份候选、2份审查；SVG、源scene、PNG及workflow.json只保存在工作区文档检查/架构候选，检查点只保存文件路径，状态与数量保存在工作流文件。失败带statePath，尚未实现自动断点续跑。源稿/PNG摘要核对后复用选中图导出四种格式，不重复重画或复审。原生PPT仍走原实际对照门槛，没有放宽。

新增单测7项（虚构示范素材、不联网、不用真实模型）：语义/图标保持、无视觉降级、预算先扣及修复重审、不可修问题不空转、非法返回、停止预算留指针、预览被改禁止导出。新增E2E使用真实SVG渲染与PNG读回、四格式同稿；视觉接口为假接口，不代表真实模型审美或客户材料验收。

1. 大场景和图片只在工作区，检查点仅指针。
2. 2候选+1修复、2审查、意见8条/240字、响应6000字，画布原上限不变。
3. 每个候选/审查结束保存状态，不对流事件逐条写盘。
4. 本流程独立UUID路径，不读取界面当前会话。
5. 停止/预算上抛，失败状态可追溯，不吞控制信号。
6. 没有自动重试；一次确定性修复，每次视觉45秒可取消。
7. 视觉请求前consume(model)。
8. 使用code/name，不按错误文案分支。
9. 新diagramCandidates模块131行，原入口小范围接线；main/mount/writingRoles不变，无依赖。
