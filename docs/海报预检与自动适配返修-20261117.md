# 海报预检与自动适配返修（2026-11-17）

用户反馈1.0.451之后仍无法完成海报，附件《帮我写一个网页.md》末尾记录了北京时间11月17日05:43和05:48两轮失败。当前为修复与验收记录，正式发布结果随后填写。

## 根因与上一批遗漏

日志中的行为是：缺顶层标题、英文标签溢出、数字标签高度不足、页脚多一行依次出现，4次参数纠正耗尽，最后没有PNG/PPTX。451分开了参数纠正和实际渲染次数，但严格图层归一化仍遇到首个错误即返回；自由构图仍让模型自己猜高度；超过2000字符的发送回执会丢失presentation.failed里的具体位置/最小值。实际模型选择自由图层时会走进这条失败链，上一批人工准备好的合规样张和受控调用不能证明它可靠。

不把它归因为“新渲染引擎还没装”：日志只能证明预排失败。公开健康接口可达，但不返回版本；本轮没有用户服务器后台或实际模型服务配置，无法确认其安装版本。附件没有原design.json或最终PNG，当前复现是同题材、同错误类型的独立稿，不能冒称原文件复现。

## 修改

1. 全部独立图层错误一次收集，报告图层ID、失败字段、最小高度/字号。原始完整诊断受160图层上限约束，发送副本仍不超过2000字符；展开不足明确omitted，按原receiptId回读，不能把删掉细节后的failed当可执行反馈。
2. 新自由稿和明确完整重新构图默认安全适配。仅在既有空白或承载卡片内调整字号和文字框高度，使用原手机阅读阈值；不改文字、数值精度、x/y/w、画幅、图片、其它图层。图片区域和后续内容是阻挡边界，空间不足仍集中报错。text_fit=strict保留严格布局；source_path+changes局部编辑和原图Canvas路线不启用自动重排。
3. 没有顶层title但有唯一id=title文字层时复用其准确原文；没有明确标题或有歧义仍拒绝，不从主题/文件名猜。原稿和图片摘要继续校验，修改另存。
4. 真实手机预览发现英文被拦腰截断、中文尾行残留碎词，分层稿追加按单词/中文词组折行、标识符下划线处换行和短尾行匀排。保留所有字符、数字与单位，实际字体/像素检查不变。原图Canvas及旧上下/左右海报使用原折行方式，不改变其行数、字号与像素位置。
5. 专项方法优先栏目配图的语义输入，确需精确构图才提交自由坐标。模型先处理全部诊断，不换工具绕预算、不让用户反复回“继续”。原4次纠正、3次实际渲染、原视觉/检索/费用/图片像素预算不扩大。
