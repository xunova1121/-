- 检索收尾不掩盖鉴权、网络或真实付费额度错误；不能把未读网页写成已核实，原查询预算不增加，失败预查不能复用成功缓存。
- 队列最多10条、每条8000字/12文件路径，不存图片数据；仅本次运行内保留，关闭不自动恢复发送，不是服务器持久队列。准备附件中切账号/会话、停止、失联不得串发/重发。任务内补充仍走原inbox。
- 人像仅使用当前画图线路，无文生图降级、无编辑内部重提。双图检查最多一次25秒，发请求前扣预算、无网络搜索与辅助重试；六字段任一未知/失败、问题列表异常不得写已通过。其判断仅是可见外观对照，不能承诺绝对保真。
- 修图候选已保存后遇预算：向上抛带有界partialEvidence/partialResult的控制信号，执行器关闭预算并留诊断，将已读回候选记一次真实部分交付；停止/评测退出照旧。请重点查该接缝不会重新编辑或虚报未执行。
