# 代码仓库改私密：操作步骤（2026-11-02）

目标：代码仓库 `xunova1121/-` 改成私密；安装包放在新的公开仓库 `xunova1121/weiyang-release`。
服务器、手机、电脑的自动更新不中断，Claude 和 Codex 照常访问代码。

## 已经做好的（1.0.383 起）

- **服务器更新脚本**：原仓库回“找不到”（改私密后就是这样）时，自动改从 `weiyang-release` 下载。网络超时不换仓库。
- **安卓 App**：先试原仓库，读不到再试 `weiyang-release`，镜像照旧。
- **Windows 电脑版**：原仓库检查更新失败时，改用 `weiyang-release` 再查一次。
- **发布流程**：代码仓库 Secrets 里有 `RELEASE_REPO_TOKEN` 时，每次发版把同一批安装包和发布说明同步到 `weiyang-release`；没配就跳过，不影响原发布。

## 需要你在 GitHub 网页上做的（顺序不能乱）

1. **建安装包仓库**
   - GitHub 右上角 “+” → New repository。
   - 名字填 `weiyang-release`，选 **Public**，勾选 “Add a README file”。
   - 必须勾选 README：仓库里至少要有一个提交，否则建不了发布。
2. **生成只能写这个仓库的令牌**
   - 头像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token。
   - Repository access：Only select repositories，只选 `weiyang-release`。
   - Permissions → Repository permissions → **Contents：Read and write**，其他都不给。
   - 有效期按你的习惯，比如 1 年；到期前要换新的。
   - 生成后复制令牌。**不要发给 Claude 或 Codex，也不要贴进聊天。**
3. **把令牌放进代码仓库的 Secrets**
   - 打开 `xunova1121/-` → Settings → Secrets and variables → Actions → New repository secret。
   - 名称填 `RELEASE_REPO_TOKEN`，值粘贴令牌，保存。
4. **再发一版，确认同步成功**：告诉 Claude，Claude 会触发发版并检查 `weiyang-release` 里出现同版本的安装包。
5. **确认所有设备都升到 1.0.383 或更新**
   - 服务器：设置里看服务器版本；
   - 手机、电脑：设置里看版本号。
6. **改私密**
   - `xunova1121/-` → Settings → 最底部 Danger Zone → Change visibility → **Make private**。
7. **确认 Claude 和 Codex 的访问**
   - Claude：GitHub 头像 → Settings → Applications → Installed GitHub Apps → Claude，确认包含 `xunova1121/-`。
   - Codex：在 ChatGPT/Codex 的 GitHub 连接设置里，确认勾选了 `xunova1121/-`。
8. **改私密后验证**
   - 服务器点一次“立即更新服务器”，应显示“已是最新版”或正常更新；
   - 手机设置里点检查更新，应正常。
   - 有问题告诉 Claude。临时可以先把仓库改回公开，更新马上恢复。

## 安全设置（建议一起做）

- GitHub 账号开启两步验证（Settings → Password and authentication）。
- 代码仓库 Settings → Code security → 开启 **Secret scanning** 和 **Push protection**：不小心提交了密钥会被拦住。
- 代码仓库 Settings → Actions → General → Workflow permissions 选 **Read repository contents**。发布那一步用的是工作流里单独声明的写权限，不受影响；改完后如果发版报权限错误，告诉 Claude。

## 已知限制

- 改私密后，旧版发布页链接（`github.com/xunova1121/-/releases`）别人打不开了。安装包下载请用 `github.com/xunova1121/weiyang-release/releases`。
- 免安装版（zip）和 Mac 版只提示有新版本，点开的下载页还是原仓库的地址。等改完私密，下一版会把这个链接也换成安装包仓库。
