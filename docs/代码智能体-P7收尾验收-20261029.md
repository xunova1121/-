## 改了什么

1. **技能启停同步服务器**：原技能页开关只改本机，服务器仍可用已停用技能。新增鉴权 PATCH 接口；先保存服务器再保存本机，失败恢复开关并提示。服务器已卸载时返回 404，不自动重装。停用、卸载、预置和刷新组合走真实浏览器检查。
2. **代码任务必须真的连接仓库**：服务器总会创建仓库管理器，不能把它存在当作已连接。未连接时保留普通任务预算；已有连接才开启代码工作模式。原默认步数、期限和固定模型规则不变。
3. **实际浏览器回归**：新增 `e2e/code-work.mjs`，桌面 1280px / 手机 390px，真实 UI、服务器、任务运行器、Git 工作副本和本地假模型 HTTP 接口。覆盖用户编程模型、输入框固定模型、普通与代码预算、停止后续做、检查点压缩后找回脏副本、带真实 PNG 续做走看图线路并保留原副本。上游为虚构本地 Git，不是实际 GitHub/真实模型验收。
4. **固定运行版本**：源码先提交，生成器只读取该 Git 提交中的运行文件及哈希，再单独提交 `code-runtime-manifest.json`。准备器本身也从固定提交下载并先校验大小和 SHA256；独立目录逐文件核对、拒绝旧文件混入、真实导入评测入口及依赖，但不执行模型主流程。`--from-source` 不能联网补文件冒充当前源码通过。
5. **服务器评测预检**：只读现有模型设置，尊重编程线路和固定模型；要求已连接指定 sandbox 的有效 GitHub 凭据，不再伪造连接状态或静默改匿名。缺 Docker、镜像/离线 Node/npm/tar 不可用、配置错或 GitHub 预检失败时提前停止。正式配置不改，输出只能放独立新 `/tmp` 目录，父目录符号链接不能绕入生产数据。停止或异常时清理运行任务。
6. **测试接入 CI**：原打包 verify 追加 code-work，不放宽现有测试；另加手动 `p7_only` 测试入口，仅测试、只读仓库权限，无打包/发布步骤。
