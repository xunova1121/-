## 实现

1. `get_today_news`：新华财经要闻、央广国内滚动、中新网滚动三个固定公开索引并发；每路含正文读取8秒/800KB，无收费接口。程序提取真实标题、摘要（来源提供时）、发布时间、链接与栏目；北京时间当天且非未来才保留。栏目轮流选取，最多24条；每源解析最多36条。不存在的栏目不凑数，体育娱乐不冒充国内栏目。
2. 普通对话/每日新闻定时任务共用预查入口；模型直接整理，明确要求原文核实时仍提供并发 fetch_url，已选多条报道不能借一条原文充数。全源失败不计取得检索资料；普通汇总页成功不冒充原文阅读。
3. 普通查询45秒从首次联网计时，搜索12/读取10/工具调用22为防失控兜底；新闻读取8次。连续失败3次、普通模型3次保护、逐项20搜16读/3分钟及长任务8分钟保持。原生搜索请求先传剩余上限，真实搜索事件扣除余额。明确续查新建预算，不续用旧对象。
4. 短状态抱怨不启用工具或原生搜索；中途追加实际查询恢复原工具。仅当前查询执行期保留最多12条短来源，空答/笼统说无结果时交付已有标题及摘要，未读原文标待核实；新指令清掉旧备用结果。普通查询继续流式显示，既有禁止时间/禁用词检查保留。
5. `fetch_json`：HTTPS GET，精确可信域名、无凭据/自定义鉴权、无重定向，8秒/200KB，长JSON16000字预览明确截断。服务器及PC本机网关复用DNS公网检查；没有可校验DNS的网关时不借安卓原生请求绕过，提示使用服务器模式。模型中心可按本机/云端分别增删域名，空清单关闭；不提供模型改域名的工具。默认实测公开源 push2.eastmoney.com、api.github.com；统计局403不标可用。
6. 现有推理能力档参与首轮检索规划和已读原文后的取舍/收尾；新闻预查已有资料直接收尾，不加一次专门规划。中间搜索后补读仍主模型；若中间主模型直接写出候选答案，最多转交推理档一次作最终取舍（新闻预查直接用推理档收尾不加此轮），不能提前展示两份答案；具体渠道/计算等验收尚缺时保留原补做路径。固定型号/未配/不可用回主模型。调用明细按真实用途、模型、耗时/用量记录，未知Token不补0。新工具耗时归读取阶段。
