## 范围与设计实现

从c8f4fca同步，远端无新增提交。只修改既有productRefresh.css及相应浏览器验收，不改导航JS、agent、服务端、模型配置、会话、存储键、文件处理、天气来源或Git操作。

- 背景采用CSS矢量的雾蓝/浅青/淡紫大范围渐变，顶栏、首页与底栏透明共用整页绘制；不将效果图当背景、不引入模糊滤镜或背景动画。面板按同一视口坐标对齐渐变，返回栏不再另画色块。
- 保留批准的原始角色素材和SVG图标；字号/行高/深浅层级调整，首页问候在常规屏幕26px、320窄屏21px、矮屏20px。三条建议、轮换、文件入口与继续真实对话均保留，短屏尺寸约束不放宽。
- 输入区和必要卡片用透白表面，文件列表改轻分隔。模型配置分组、设置和项目统一表面；浮层、模型选择器、确认窗口与粘性筛选保持实底，防止透出下方文字。暗色模式保留原背景与对比层级。
- 正文、次要文字与操作色对渐变端点的对比度至少4.5:1；首轮发现强调蓝色在淡紫端点只有4.33，调整为更深蓝后再次验收，不放宽检查。
