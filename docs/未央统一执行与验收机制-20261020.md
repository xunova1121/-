# 未央统一执行与验收机制

本批在1.0.201基础上接入公共机制，目标是各类任务按实际回执工作，不等于所有能力达到同一水平。

| 环节 | 既有基础 | 本批接入 | 边界 |
|---|---|---|---|
| 需求理解 | 原话账本、项目规则、摘要纠错 | 明确交付类型的任务合约、补充版本与取消 | 不靠规则理解全部自然语言 |
| 规划执行 | 清单、分身、只读并行 | 真实执行回执核对 | 计划勾选不代表验收通过 |
| 工具能力 | 按需加载、PC桥 | execution_capabilities、可选项目执行器 | 未配置不能假装已安装 |
| 搜索 | 多源搜索、证据库、预算 | 原话实体保护、360/百度线索降级 | 保护引号实体/证券代码或显式提供的词，不猜人名 |
| 错误 | 类型、取消、退避 | 429不推断欠费、网络读取最多重试一次、跨端传类型 | 余额依服务商明确错误码确认 |
| 金融 | 网页查证 | 腾讯日K与未复权新浪备用、JS算极值 | 明确范围、复权与来源，不承诺实时和完整历史 |
| 数字 | 盈亏、孕周、T+1 | 日期加减/自然日差、百分比、金额按分合计、费用 | 计算正确不等于输入属实 |
| 文档 | 六类自有模板、公式/排版核对、PDF转换 | 结构/读回/转换回执与剩余错误 | 转PDF不等于人工视觉验收，未复制未授权模板 |
| 编码 | 浏览器隔离、Pyodide、PC命令 | 服务器可选多文件JS隔离测试 | 不安装npm包，不是完整远程开发机 |
| 恢复 | 草稿、证据、检查点、原任务重接 | 产物验收摘要恢复、控制信号传播、Python取消 | 外部操作不盲目重放 |
| 对话与语音 | 补充、打断、Qwen接口、流式朗读 | 补充纳入回执，错误不误报余额 | 未重做语音UI或验证鸿蒙声学效果 |
| 评测 | 60+30题真实任务入口、耗时 | 机制回归、报告对照与评审覆盖 | 无模型凭据，不能宣称真实准确率已提高 |

## 服务器隔离执行器

不默认安装或拉取镜像，不回退到宿主机运行。管理员须安装Docker、预先准备包含Node.js和coreutils timeout的可信本地镜像，在systemd服务环境配置：

    JARVIS_CODE_SANDBOX_IMAGE=<本地可信镜像，生产建议固定摘要>

可预先拉取官方Node 22 bookworm-slim镜像，再配置并重启。未配置时run_project_tests不出现在工具列表。

只复制指定工作区项目，最多40文件、2MB、16入口，不带服务器变量或密钥。容器无网络、只读项目、非root、无capabilities，限制CPU/内存/PID；PID1 timeout限制生命周期。成功自动删除，停止/失败强制清理，不确定时报告。只运行给定JS入口，不安装依赖。用户确认规则与PC命令保护保留。

## 验收与数据

每轮回执64条、代码文件状态32条、文档验收摘要16条。修改后旧运行记录失效，打开预览不算测试通过。调研搜索/读页/模型请求先扣预算；停止和预算不是空结果。聚合摘要不存到原站正文名下，新增回执与检查点不保存原始网页、代码或文件内容。

日K最多返回120条，极值只针对返回记录；复权口径不一致不降级。接口上限、停牌和上市日期可能影响覆盖；成交量沿用来源单位、不跨源混算。公开接口持续可用性和使用条件仍需核对，不等于购买授权金融数据服务。

## 评测

保留真实任务入口，默认仅预览，显式--live才请求已配置模型。新增：

    node evals/quality-report.mjs 基线报告.json 新报告.json

区分执行完成、已语义评审正确率和评审覆盖率。未评审不算正确，未知Token不当零。不同题集、模型和网络条件不当严格提速对照。生产服务器、鸿蒙/Windows真机、真实付费模型尚未实测。
