# Canvas 原图填字与卡槽定位（2026-11-15）

本批来自用户“不要 SVG，直接往底图卡槽放文字，开发完跑测试”的授权。仅开发和测试，**未发布**；公开稳定版仍为 1.0.442，不手改版本、不触发 Actions，不更新用户服务器。本批仍需 Claude 独立审核，本文不冒称已获审核通过。

## 行为与使用

在 `make_poster` 增加独立 `canvas` 参数，在 `create_visual_demo` 复用同一流程；旧 `design`、`.design.json`、`.poster.json`、`.visual.json` 和 SVG/渐变路径保留。

已有无字底图：`background_path` 指向工作区真实 PNG/JPEG/WebP，`canvas.entries` 按卡槽顺序给标题/正文。作品名用根级 `title`；**要出现在图上的主标题用 `canvas.header`，底注用 `canvas.footer`**。不混用旧 `lines`、`design`、`text_style`、`changes` 或指标数据参数。

```json
{
  "title": "七卡槽原图填字",
  "background_path": "图片/无字底图.png",
  "canvas": {
    "entries": [
      {"title": "城市观察", "body": "让信息清楚地进入卡槽"},
      {"title": "绿色发展", "body": "保留原图的光影与装饰"},
      {"title": "服务升级", "body": "中文保持真实字体"},
      {"title": "产业协作", "body": "每段文案完整保留"},
      {"title": "数字生活", "body": "手机整图仍然可读"},
      {"title": "开放交流", "body": "图标不会被文字覆盖"},
      {"title": "未来视角", "body": "改字继续复用原底图"}
    ]
  }
}
```

上述仅为七槽测试文案，不是新闻事实或通用固定模板。文案 1–20 组、全文不超过 6000 字；卡槽并非写死七个位置。

交付 PNG、原生可编辑文字 PPTX、可拖动/缩放文字框的离线 HTML、含原图原字节的 ZIP、绑定原图 SHA-256 与位置的 `.canvas.json`。不生成 SVG、不绘制覆盖面板、不重新生图、不裁切原图。默认原图尺寸；显式宽高必须保持原图比例，最长边不超过 4096。

改字：`source_path` 复用 `.canvas.json`，`canvas.entries` 给完整新文案；默认保留原标题/底注、原图摘要与位置，未提供 ID 时沿用原对应关系。不重新识别、不覆盖原片/原稿。补 Demo 直接 `create_visual_demo(source_path)`；这里的 HTML 是保持原图构图的文字编辑预览，不冒称接入实时数据的业务系统。

## 定位、排字与模型费用

1. 规则明显的重复浅色卡槽按真实解码像素检测：位置、数量、宽高来自本次图片，不复用示例坐标。卡槽内侧排除图标/圆角，必须与文案数量吻合。
2. 缺少明确文字区、单框或复杂/深色样式时，如果已配置 `visionLlm`，最多一次、25 秒有界视觉定位。没有视觉能力或定位不确定时保留待排版源稿与编辑器，不猜位置交成品。
3. 可通过 `canvas.regions` 明确指定原图 0–1 比例的 `x/y/w/h`，通过 `protected` 提供人物/图标保护区。HTML 支持拖框/缩放、改文字、保存源稿再导入未央；手动调整的位置会随稿保存。
4. Canvas 用实际字体字形测量、换行和排字，全文逐字核对；按 390px 整图宽正文至少 12px、卡槽标题至少 14px。全文放不下、重叠、进入保护区、对比不足或缺字时禁止标记成品，不截字、不把字缩到不可读、不加遮挡面板。
5. 检查原图绘制基准与填字后的实际 RGBA：文字边界框以外、保护区的改动必须为 0。保存后读回核对文件摘要、PNG 真实像素与数据完整性；原图字节始终另存保留。
6. 已配置视觉模型且有实际成品/阅读预览时，另做至多一次原图、成品和整图缩小文件的对照核验。定位和核验都在请求前扣预算，不自动重试/重画、不联网搜索；预算/取消控制信号向上传递。

**所以不是强制需要视觉模型。** 规则卡槽可由程序定位，复杂图需要视觉辅助或人工定位；最终视觉核验也可能产生一次模型费用。模型是否通过核验、技术检查是否通过、文案事实/错字编辑和审美满意是不同结论。程序排字不能保证用户原文或模型文案本身绝对正确。

4K 指实际输出画布，不证明底图原生细节。源图放大会单独记录。微信的图片传输仍可能压缩；本批不改变原有分享、会话恢复或原字节保存流程。

## 工程接缝

- `src/agent/imageText*.js`：独立输入/源稿、定位、纯排字引擎、字体检查、浏览器栅格、PPTX、编辑器、成品核验和交付。工厂自包含，打包压缩后的离线 HTML 也必须实测。
- 原 `make_poster`、`create_visual_demo` 和任务回执/收尾规则只增加 Canvas 分支；Canvas 交付不被旧三格式规则反向强制补 SVG，普通旧海报仍要求原三格式。
- `server/canvasImageText*.mjs`：独立可杀死的子进程处理原生 Canvas，最多两个并发、20 秒有界、取消后回收容量。**不要改回同进程工作线程**：专项测试发现原生库在线程间反复注册字体可能导致整个父进程段错误，故已隔离并连续导出复核。
- `server/canvasFontFile.mjs`：按 fontconfig 实际选择的 TTC 字面索引提取简中字体，避免原生库只加载集合首个 JP 字面。保留字体表，不修改系统字体，也不向成品嵌入系统字体。
- `@napi-rs/canvas` 固定 0.1.80，MIT，npm 发布时间 2025-09-13，已满两周。此前它是 PDF 依赖的可选间接模块，本批固定为直接依赖；不改其他依赖版本。原生库/许可证随桌面包携带。
- 桌面 prepare 增加实际渲染入口、当前平台原生模块，ASAR 解包对应 server/node_modules；Electron 仅在渲染子进程设置 `ELECTRON_RUN_AS_NODE=1`，不能误启动第二个客户端窗口。
- 原文件预览仅对固定 Canvas 编辑器标识增加 `allow-downloads`，让用户点击导出可用；不增加 `allow-same-origin`，普通 HTML 的策略保持。
- 新 E2E 追加至原 verify，未删/弱化任何旧测试、超时、提示词长度或既有门槛。海报技能当前不超过 1200 字符；未改智能体主循环、搜索、排队或分享逻辑。
