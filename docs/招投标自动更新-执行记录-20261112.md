# 招投标自动更新执行记录（2026-11-12）

用户同意把“对话查招标”升级为自动更新的资源中心。本次基线为 Claude 的 ef95e5e（1.0.420 三端发布核验），动手前已 fetch 并 fast-forward 合并，未修改环境凭据、应用标识、签名、安装权限和草稿直传发布流程。

## 实现

- 独立 `server/tenderCenter.mjs` 定时采集：生产服务器启动即恢复，每30分钟尝试一次，手机/电脑关闭仍运行。不通过定时对话、不调用模型或付费搜索/企百科，不下载公告附件。查询/筛选页面只读缓存。
- 两个固定官方公开来源：中国政府采购网采购公告列表（只跟页面明示的静态分页，每轮最多3页）、全国公共资源交易平台首页交易公告。独立来源健康状态，单源失败保留目录和最近成功时间。不是全网数据库；首页截取、刷新间隔和来源限制可能漏项。
- 全局5000条/90天目录；每周期最多16篇正文、并发2、单请求10秒、周期120秒；正文只保存不超过1800字的相关摘要。近期新公告与收藏分别预留复查名额，复查间隔至少6小时；收藏公告在90天保留期内继续跟踪，按实际核验时间展示。目录保留预算、截止、编号、类型和官方原文，不把中标金额当预算、发布时间不从URL或抓取时间推测。
- 界面“最新公告 / 我的收藏 / 自动订阅 / 提醒”，支持关键词、地区、公告类型、发布日期、预算（万元）筛选；未知预算不冒充0。云端入口省去宣传大图，优先呈现公告。原有企业查询与解读入口保留。
- 个人最多20条订阅、100个收藏、200条提醒。公共目录淘汰不删除私人收藏，最多100份小快照标为归档，可继续打开原文或取消收藏，不宣称归档后仍在自动更新。订阅从保存后开始跟踪；日期仅用于浏览历史，不把固定日期保存为永久订阅。暂停/恢复不补发历史洪水；收藏跟踪该原文更新。
- 公告按规范URL去重，相似标题、不同包件、更正/中标链接不合并。相同修订命中多个订阅/收藏只提醒一次；预算和截止变化保留前后值。没有可靠项目身份时不猜测两个公告属于同一项目。
- 公共目录共享，订阅、收藏、提醒和已读状态按服务端登录身份保存。普通成员不能暂停全局采集或强制刷新；匿名、评测凭证无权访问。切换账号/服务器/草稿后丢弃迟到UI结果，不改写新的页面。
- 游标与收件箱原子保存，服务重启、重复采集不会重复通知。提醒沿用既有客户端通知轮询；App完全关闭时服务器继续匹配，下次打开可查看收件箱，不宣称已经实现操作系统离线推送。

## 来源实测（当前开发环境，非用户服务器）

- 2026-11-12 curl读取全国公共资源交易平台首页成功，67985字节，实际解析24条公告，首条为陕西“长武县污水处理厂事故应急池建设项目”，发布日期2026-11-12，保留官方链接。
- 同日中国政府采购网地方公开招标分类列表返回HTTP403；不绕验证，不写成已全量可用。
- 当前云环境要求继承HTTP代理；启用Node的NODE_USE_ENV_PROXY=1后，生产publicFetch→列表/正文链路实测成功：全国公共资源平台24条，中国政府采购网明确返回403。没有改SSRF校验或用户配置；这不是用户服务器实测。
- 真实公告“衡南县人民医院高清胃肠镜系统及配套设施壹套采购项目”暴露聚合站把预算表格压成单行的格式。新增精确字段解析：结构化单包表格按列读取，压平文本仅在明确相邻列头和单对金额时读取；多包/缺列仍未知。再次实际请求核对：项目编号CGXM2026430422000078，预算1776000.00元，最高限价1776000.00元，投标截止2026年12月03日10点00分（北京时间）。保存公开HTML夹具及3条解析守护，未把字段解析成功说成真实模型业务验收。
- 企业股权完整变更、全国全量招标库、企百科授权数据没有接入自动采集；目前可以以企业名称关键词订阅已接入公告中的相关信息，不能冒充完整工商动态库。
