## 动手前必读（项目规矩）

1. `CLAUDE.md`
2. `docs/已修问题清单-不许回退.md`：先拉最新代码合并，不整文件覆盖。**测试只许加不许删**，修了新问题要写进这份清单。
3. `docs/代码规范.md`：
   - 前端功能放 `src/app/`、`src/ui/` 各模块，`main.js` 只做组装；
   - 文件尽量 ≤500 行、函数 ≤80 行，新功能放新模块；
   - 中文注释，写法跟周围代码一致。
4. 借鉴只学**开源**项目的思路，先看 LICENSE，按未央的结构重写，不整段复制。
   - 可参考：Langflow（MIT）、Flowise（Apache-2.0）、Dify / Coze Studio / LobeChat 的智能体配置思路。动手前自己核对许可证，n8n 不参考。

5. 网页、Windows、安卓三端都要能用；App 不引入 Python。
6. 新依赖要发布满两周以上。
7. 每一步单独提交，提交信息带 `[skip ci]`。**测试全过、用户同意后才发版**。发版流程见 `CLAUDE.md`“提交与发布”：

## 第 0 步 · 智能体配置格式与注册表（不依赖设计稿，先做）

新模块 `src/agent/agentProfiles.js`：

```js
/** 一个智能体 = 一份配置；内置的写在代码里，用户自建的存起来 */
{
  id: 'ppt-maker',            // 小写短横线，唯一
  name: 'PPT 制作',
  icon: 'ppt',                // 图标名，对应 src/ui/agentIcons/ 里的 SVG（设计稿给）
  category: 'office',         // office | gongwen | image | research | life | mine
  intro: '给我主题或资料，帮你做成可编辑的 PPT。',
  starters: ['…', '…', '…'],  // 3 条推荐问题：点了填进输入框，不直接发送
  prompt: '…',                // 附加到系统提示里的角色说明（≤600 字）
  tools: ['create_document', 'check_document', 'web_search', …], // 工具白名单，空 = 不限制
  form: [ { key: 'pages', label: '页数', type: 'select', options: ['3-5','6-10','10-20','20-30'] }, … ],
  output: 'pptx',             // 默认产出：text | docx | pptx | xlsx | image
  source: 'builtin'           // builtin | user | github
}
```

- `BUILTIN_AGENTS`：首批 8 个，按设计需求文档第 3 节 P2：PPT 制作、公文写作、深度研究、海报设计、图片转文字、健康顾问、出行天气、行情查询。
- `validateProfile(p)`：校验字段、id 唯一、`tools` 都是存在的工具名、`prompt` 长度、`form` 选项。不合格就抛 `ValidationError`，并写清哪一项错。
- `listAgents({ category, query })`、`getAgent(id)`。
- 用户自建智能体的存储：照 `sessions.js` 的本地 / 远端双路写法。服务器模式下存服务器，换设备也在。
- **测试** `tests/agentProfiles.test.js`：
  - 内置 8 个全部通过校验；
  - 工具名全部存在于 `CORE` 或工具目录；
  - 非法配置报错带字段名；
  - 搜索和分类筛选正确。

## 第 1 步 · 用智能体开对话（主循环接入）

- `sessions.create({ agentId })`：对话上记住 `agentId`，旧对话没有这个字段，按普通对话处理。
- `runAgent` 新增可选参数 `agent`（profile）：
  - 系统提示末尾追加 `agent.prompt`；
  - 工具在 `taskToolCore` 的结果上**再按白名单收窄**。不能放宽权限，原来的审批、只读并行、联网预算都不变；
  - 表单值拼成一段“用户选择：页数 6-10；场景 政企汇报；语言 简体中文”放进本轮要求，不改用户原话。
- 对话历史显示智能体图标：`drawer.js` 的历史项按 `agentId` 取图标，没有就用小精灵。
- **测试**：
  - 带 agent 时工具被收窄、没在白名单里的工具调不到；
  - 不带 agent 时行为和现在完全一样（跑全量测试证明）；
  - 表单值进入要求文本；
  - 旧对话没有 `agentId` 不报错。

## 第 3 步 · PPT 模板库（设计稿 P4、P5）

- 新模块 `src/agent/pptTemplates.js`：模板 = `{ id, name, style, theme, scene, outline, sampleContent }`。从现有 5 种风格 × 常用配色组合出首批约 12 个模板。`outline` 可以复用 `documentTemplates.js` 里的 PPT 大纲。
- **缩略图**：
  - 写脚本 `scripts/make-ppt-thumbs.mjs`，用 `makePptx` 渲染样例内容，再用 LibreOffice 转 PDF → PNG（e2e 已有这条路），产出 `public/ppt-thumbs/*.webp`；
  - 每个模板 3–4 页样张；
  - **不用网上的模板图**。
- 起始页：
  - 选模板 → 填主题 → 选页数、场景、语言 → 调 `create_document`，带上 `style`、`theme`、`template_id`、页数要求；
  - “从链接生成”：先 `fetch_url` 再生成；
  - “上传 Word 转 PPT”：走现有 `source_path`。
- 完成卡片：
  - 只突出最终文件，过程稿折叠成“其他文件（n）”；
  - 快捷按钮：改一页 / 换风格 / 加演讲备注。
  - 用户这次就是被三版 PPT 搞糊涂的，见已修问题清单 11-05 两条。
- **测试**：
  - 每个模板都能生成、`layoutIssues` 里没有 error；
  - 选了模板，生成的风格和配色与模板一致；
  - 页数下拉生效。

## 第 4 步 · 公文写作智能体（设计稿 P6）

- 文种配置 `src/agent/gongwenKinds.js`：每个文种有字段表单、结构大纲和格式要求。
  - 机关：通知、请示、批复、报告、函、纪要、简报、领导讲话、述职报告、工作总结、心得体会；
  - 职场：方案、周报、邮件、致辞。
- Word 排版按《党政机关公文格式》（GB/T 9704）：版头、发文字号、标题、主送、正文层级（一、（一）1.（1））、落款、成文日期。在现有 Word 文种排版（`docWriter` 一带）上扩展，不另写一套。
- “批复 / 审核意见”：上传来文（拍照走现有文字识别，文件走 `read_file`），先提炼来文要点，再按批复结构写。
- 小工具：校对润色、提纲、扩写、续写、改写、缩写。就是带不同 `prompt` 的轻量智能体，作用于选中的文字或上传的文件。**不做“降重”**。
- **测试**：
  - 每个文种的大纲和字段完整；
  - 批复样例的 Word 有发文字号、主送、落款、日期，层级编号正确；
  - 用 `check_document` 读回验证。

## 第 5 步 · 图片处理智能体（设计稿 P7）

- 海报：`generate_image` 出底图，再叠标题和要点排版（复用 PPT 的文字排版和防一个字单独成行的逻辑），一次出 4 张候选。
- 图片转文字：已有，只包装成智能体。
- 抠图去背景、证件照换底色、老照片修复：
  - **优先接服务商图像编辑接口**（如百炼万相），放进“模型 → 能力表”新的一项，Key 只填在服务器设置里；
  - 本地开源模型（如 RMBG、rembg）多数是非商用或 AGPL 许可，**接入前先跟用户确认许可证**。
- 处理前后对比条、保存 / 分享：按设计稿。
- **测试**：用假接口验证调用参数和结果落盘；没配 Key 时给明确提示，不静默失败。

## 第 6 步 · 自建智能体与步骤编排（设计稿 P8）

- 创建表单：写入第 0 步的用户智能体存储，`validateProfile` 校验。
- 步骤编排：`steps: [{ do: 'search'|'summarize'|'document'|'image'|'remind', args }]`。
  - 执行时把步骤翻成一段明确的分步要求，交给 `runAgent`（复用 `team.js` 的分工思路）。**不写第二套执行引擎**。
  - 定时触发：接 `scheduler.upsert`，`prompt` 里带智能体 id。
- 第一版只做竖向步骤列表，可排序、删除，**不做拖拽连线画布**。
- **测试**：
  - 步骤翻译成要求文本正确；
  - 定时任务能带着智能体触发；
  - 非法步骤报错。

## 第 7 步 · 导入导出

- 导出：智能体配置导出成 `.weiyang-agent.json`（只含配置，不含任何 Key）。
- 导入：先 `validateProfile` 校验，`tools` 里有本机没有的工具就提示并去掉。
- 兼容从 GitHub 技能导入：`SKILL.md` 的 name / description → 生成一个只带说明的智能体。
