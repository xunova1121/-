# 百炼实时语音接入

本批只接入 qwen3-asr-flash-realtime 与 qwen3-tts-flash-realtime；聊天、工具和服务器任务仍由现有智能体处理。

## 使用

1. 安装包含此功能的新安卓/Windows版；云服务器更新到同批正式版。
2. 模型 → 声音 → “使用百炼实时对话”。
3. 选择北京或新加坡，填写对应地域的百炼API Key（与千问聊天模型共用keys.qwen）。不要把密钥发到聊天或仓库。
4. 默认Bella，可选Mia、Serena、Cherry。先点击试听，再点击语音通话说一句话。
5. 语音自检分别检查麦克风、实时会话配置和实际声音试听；不把连接成功称作识别准确率实测。

安卓使用原生WSS请求头连接固定百炼域名；PC和网页通过自己的网关连接。
服务器模式通过已有登录令牌验证，服务器可复用服务端keys.qwen或DASHSCOPE_API_KEY。浏览器不把密钥放进URL。
使用服务器网页/远程网关时，反向代理需要转发WebSocket Upgrade（Nginx的proxy_http_version 1.1、Upgrade和Connection头），同时保留已有SSE配置。

## 行为与边界

- 开启通话才采集并上传16kHz单声道PCM；服务端断句，实时展示text+stash，仅completed提交任务。忽略情绪字段。
- 44.1/48kHz麦克风音频真正重采样，不只修改采样率标签。不开启ONNX/WASM识别模型。
- 24kHz PCM返回即排队播放；句子按现有分句器处理。取消或切后台会关闭连接、麦克风和已排队的全部音源，后台任务继续使用现有机制。
- 朗读时传静音并抑制转写，防止扬声器内容变成新任务；可用界面停止按钮打断。
- 网络中断最多连续重试两次，不重放未确认音频；界面提示未识别完的一句需重说，避免重复执行。
- 显式选择的百炼音色失败会报告，不把系统声音回退当成目标音色成功。音色名称表示风格，不承诺真实女童。
- 结束通话是取消，不把取消前尚未确认的半句在后台提交。

## 验证

测试使用模拟服务验证协议、认证、音频转换、取消/后台静音，以及App真实WebAudio流程。
没有百炼凭据，不调用收费接口；未做华为HarmonyOS4.2真机/真实服务时延或音色听感验收。
