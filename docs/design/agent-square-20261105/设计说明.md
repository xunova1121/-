# 未央智能体广场 · 设计稿第一版

2026-11-05，按用户最新要求由Codex设计。用户提供的灵犀·晓伴截图仅用于理解入口与页面层次；图标、文案、模板示意均为本次原创，角色使用未央仓库现有小精灵。未使用对方素材、品牌或模板图，也未引入外部字体、CDN、图标库或收费接口。

## 打开和查看

`index.html` 为单文件可交互预览，资源全部内联。顶部设计导航可切换页面与浅色/夜间。该导航属于设计查看器，不进入正式App。

支持手机390px、320px、412px；桌面断点880px，1280px提供广场与对话布局。`capture.mjs`通过本地回环服务器渲染设计文件，生成2×PNG并检查窄屏、大字和主要交互；不等于正式App端到端验收。

设计页：P1抽屉；P2广场、加载态及搜索空状态；P3通用起始页、对话；P4 PPT制作、制作中、完成；P5模板库、三页样张预览；P6公文种类、批复和述职表单；P7图片对比、海报四候选；P8自建与步骤编排。P1—P5为主流程稿，P6—P8为结构和交互稿，等待用户确认后细化并接真实能力。

模板图是原创SVG版式示意，不是已经由PPT引擎生成的实际Office成品。后续第3步必须按交接计划由真实引擎生成、LibreOffice渲染替换；图片处理候选、示例文件和示例回答也明确为设计演示，不虚构处理回执。

## 页面与返回路径

| 入口 | 到达 | 返回 |
|---|---|---|
| 抽屉“发现智能体” | 广场 | 抽屉/原对话 |
| 广场卡片 | 对应智能体起始页 | 广场，保留分类和搜索 |
| 推荐问题 | 只填输入框 | 留在原页，用户可编辑后发送 |
| PPT模板卡 | 预览封面/数据/内容样张 | 模板库 |
| “用这个模板” | PPT制作页，带回选中模板 | 保留主题和表单（正式接入时实现） |
| 生成中 | 进度卡，支持离开/停止 | 原对话/任务列表；真实进度沿用现有任务事件 |
| 完成卡 | 一个主文件，其他文件默认折叠 | 原对话 |
| 文种 | 短表单，可上传来文 | 文种选择 |
| 图片功能 | 上传/前后对比/候选 | 功能页 |

设计稿未把“选择模板/推荐问题”当作生成授权；实际发送、停止、付费图像调用、文件覆盖与原有确认机制在正式接入时继续执行。旧功能入口保留在工作区、知识库、更多工具和设置，不删除模型/记忆/技能/定时任务等功能。

输入框沿用单行样式，模型名默认不展示。手机键盘弹出时正式实现需沿用当前App的visualViewport/安全区处理，不靠设计稿固定定位证明真机可用；本次未测试安卓/Windows真机键盘。
