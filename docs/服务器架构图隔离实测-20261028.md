# 未发布架构修复的服务器隔离实测

用户授权直接在服务器上测试并抓结果。当前执行环境没有用户服务器登录凭据或SSH连接，不能绕过鉴权；对受保护HTTP接口的未授权请求未发起模型任务。联网探测/测试脚本自测不等于真实模型实测。

`jarvis/evals/run-architecture-server.sh`在用户服务器终端执行：读取开发分支中固定的已验证运行时清单，逐文件校验SHA-256，复用正式安装中相同的程序文件，仅下载新增/变更小文件到/tmp目录；不下载整个仓库。锁文件相同则只链接已安装依赖，否则只在测试目录安装生产依赖。它不更新/重启正式服务，不修改正式配置和数据。源码提交号随报告登记，不以已发布旧服务器冒充最新修复。

`architecture-server.mjs`只读生产config.json，保留其当前服务商、型号、辅助模型/分工/回退设置，不硬编码模型。只读指定DOCX对应的确切工作区元数据/二进制，不枚举正式会话；防记录错配和二进制路径越界。原件复制进独立store，初始化内置技能，使用真实createTaskRunner发起一个evaluationId隔离任务。模型自己读原文、规划并出图，不注入人工整理的对象/关系、不模拟审查通过。不开放额外监听端口。

测试与正式服务共用服务器算力和模型账号额度，但测试会话、记忆、文件互相隔离；不复制生产长期记忆、历史或自定义技能。这是同服务器/当前模型的隔离任务引擎测试，不冒充正式HTTP入口或手机端全链路验收。

## 在服务器终端启动

默认安装位置为/opt/jarvis/current，数据为/opt/jarvis/data，原件为工作区“上传/重点水域禁捕项目正式招标文件.docx”。可用JARVIS_PRODUCTION_APP、JARVIS_PRODUCTION_DATA、JARVIS_ARCHITECTURE_SOURCE指定非默认位置；不要把密码/Key写进命令。

```bash
curl -fsSL 'https://raw.githubusercontent.com/xunova1121/-/refs/heads/claude/jolly-darwin-tijh97/jarvis/evals/run-architecture-server.sh?v=delta1' -o /tmp/weiyang-architecture-test.sh && bash /tmp/weiyang-architecture-test.sh
```

仅有服务器本地原件才可启动；如果文件只上传给Codex，需先把原件放进未央服务器工作区。脚本不会把公开旧稿或其他文件当替代材料。需Node20+与原服务器Office/SVG依赖；不自动安装系统级渲染工具。

## 结果

- 单次最多20分钟；用户停止或超时调用stop，未确认停止最多等30秒，后台收尾最多20秒；不自动重发任务。
- 每5秒且进度变化才保存私有报告；最多3000个原任务事件，运行日志最多400万字符；不会按每个事件重写全文。
- 保存真实回答、当前任务/分工/耗时/工具事件、生成文件。最多200文件，每文件20MB、合计100MB，超限保留隔离store并明确标记未导出。
- 自动打包report.json、artifacts/和runtime-private.log为architecture-results.tar.gz；生产配置/Key和原件store不放进结果包。报告和产物含客户内容，只私下交付，不提交公开GitHub。
- done不等于质量通过，semantic固定not_reviewed直到人工/实际复核；必须检查原文覆盖、对象/关系、数量、视觉效果及PPT可编辑一致性。未成功会保留失败状态/错误码，不能当通过。

测试入口：`node --test evals/checks.mjs`，新增只读/型号分工保留/目录越界/非live模式检查。未取得服务器结果前，不宣布架构图整体完成，不触发发版。

补充边界：隔离进程不能继承正式HTTP会话中的电脑模型桥连接；依赖该连接或自定义技能时，需要在正式连接环境复验。不要把缺连接/缺技能导致的失败归为绘图算法失败。此入口自身已通过34项评测协议检查、208文件1777项应用回归及lint；真实服务器任务尚待执行。


## 整库下载超时修正

清单当前固定为已验证运行时9e005b4，包含此前全部绘图修复与隔离测试入口；清单不含客户文件、凭据或未跟踪草稿。以后更新运行时代码时须重新生成固定版本清单，不能把新旧源码拼装。最多1000文件/单文件20MB/总100MB，重复/越界路径拒绝；生产目录不可作为写入目标。仅复制经过清单哈希验证的程序文件，不链接会被覆盖的源码。

以正式1.0.319源码模拟：复用413文件，仅下载31文件/237752字节。可设置JARVIS_ARCHITECTURE_CODE_DIR复用已有下载目录；有results目录则拒绝再次提交任务，避免误重复收费。已有完整哈希正确的测试文件也复用；网络失败的.part文件不当作完成。
