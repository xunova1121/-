# 写作偏好（2026-10-21）

## 范围

当前实现保守提炼用户明确的长期文档要求，例如“以后Word用宋体”“以后文档简洁一些”。识别8类：篇幅、语气、字体、封面、目录、来源、结论顺序、配色；按通用/Word/PPT/Excel范围保存。临时“这份文档改一下”和引用材料不自动变成长期偏好；复杂且未识别的意见仍保留在当前对话，不宣称能够理解任意修改意见。

doc_style记录复用现有memories集合，不改数据库版本；最多30条、同范围同维度新值覆盖旧值，不额外积累历史；其他事实/身份与任务原话不删除。每条偏好短内容，来源原话最多240字，面板与模型只读有界短内容；导入备份后也执行该类别上限。删除仍可用原记忆页；新增模型工作台本机/服务器分别查看删除入口。

## 使用与隔离

自动整理记忆时提炼，沿用用户原有自动记忆开关；关闭后不会暗中另开学习模型。写作、长文、专业文档与审查调用才附带偏好，普通聊天上下文排除此类别；当前明确任务要求优先，特定文种优先通用偏好。没有新增模型请求，但偏好会增加实际写作/审查请求字符，最多约30×180字符加说明。

仅接受直接用户语句，常见凭据/外链及现有记忆注入检查命中不记录；同句后面的新要求优先，保留否定词。该识别不是通用语义理解，也不承诺覆盖所有隐私格式或矛盾措辞。

评测反思入口evaluationId/session.evaluationId直接跳过。服务器原有评测工具写隔离、后台评测跳过仍保留。前端reflectNow同时检查服务器模式与评测标记，修复pagehide绕过scheduleReflect运行位置检查的路径，避免服务器对话再次整理到本机。

前后端共用同一偏好服务。服务器仅提供受现有登录保护的GET列表与DELETE短编号，删除前再次检查类别，不新增远程写任意记忆接口。UI请求固定发起时的配置位置，切换页签不把另一端删掉；不复制凭据或正文。
