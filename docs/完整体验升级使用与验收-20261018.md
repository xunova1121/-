# 本轮使用与验收说明（2026-10-18）

## 输入与电话

空白时显示＋、模型、语音转文字、电话。文字或附件输入后出现发送；生成时停止独立显示，输入框始终可编辑和发送补充。拍照、相册、文件、常用指令在＋菜单。麦克风只把结果填进输入框，需确认发送；电话连续提交并朗读。

百炼设置沿用“模型→声音→使用百炼实时对话”，选择与密钥相同地域。Bella是默认可选音色，不保证等于固定女童声。“我来说”停止朗读并继续收音，不取消任务；“停止”才停止任务。切到其他App停止收音与播放，后台任务保留。诊断记录中的audioScheduledMs是软件调度时间，不是实测物理扬声器延迟。

## 服务器与恢复

安装新APK后，还要通过应用内“立即更新服务器”更新自己的服务器，才能使用绑定原任务的补充、提交去重、持久检查点和Office服务。旧服务器不支持新补充接口时，文字会保留回输入框，明确提示更新，不假装已经送达。

同一提交的去重保留两小时；服务器重启后旧提交不重放。检查点保存完整要求、补充、成功/失败步骤、文件、执行中但结果未知的操作。未知副作用需要核对；不宣称任意任务可在进程被杀后精确续跑。手机设置→查看未完成任务可查看其他记录，取消继续不会删除原会话文件。

## 文档与代码

内置模板可通过get_document_template列出/读取；Word、PPT、Excel生成后读回实际文件。服务器安装LibreOffice后生成“原文件名.预览.pdf”，实际渲染不等于已人工检查每页视觉质量。

Ubuntu/Debian服务器可按其系统管理方式安装发行版软件：

    apt-get install libreoffice-writer libreoffice-impress libreoffice-calc fonts-noto-cjk

安装后重启未央服务器。自定义安装路径可设JARVIS_SOFFICE为本机可执行文件；App不会自动在用户服务器安装系统软件。没有LibreOffice时保留生成器/结构检查并明确说明缺少真实渲染。

JavaScript隔离计算不再允许fetch和应用存储访问；读网页用fetch_url，处理项目遵守工作区规则，通过桌面已有命令工具运行项目验证。生成文件会继续使用现有改动历史，不改变用户数据目录和签名。
