# 智能体广场 · UI 设计需求（给 Claude 出设计稿）

> 2026-11-05。用户要做“智能体广场 + PPT 模板库 + 公文 / 图片 / 编排智能体”。这一步**只出 UI 设计稿**，开发由我们按设计稿做。
> 参考了用户手机上“灵犀·晓伴”的截图，只借鉴排版思路：广场分类、模板卡片、开场问题、页数和场景下拉框。
> 它是闭源产品，**不搬它的图标、模板图、文案、配色、人物形象和名字**。

## 1. 产品背景（设计前先读）

- 产品名叫“未央”（WEIYANG AI），是个人 AI 智能体，三端：网页、Windows 电脑版、安卓手机版。手机是主要使用场景。
- 形象是已确认的**水蓝金色小精灵**（`jarvis/src/ui/logo.svg`）。不要换成机器人、真人头像或参考软件的形象。
- 已有的能力：
  - 对话、联网查询、深度调研；
  - 生成 Word / PPT / Excel / PDF（PPT 有 5 种风格：稳重商务、数据报告、极简、故事、政企汇报）；
  - 生成图片、文字识别、天气、行情、定时任务、技能、多助手分工。
- 这次要做的是把这些能力包装成一个个“智能体”，放进一个广场供人挑着用。

## 2. 视觉基线（必须沿用现有界面，不另起一套）

| 项目 | 值 |
|---|---|
| 浅色背景 | `#eef0ff → #eeecfc → #e8edfc` 渐变 |
| 面板 | 半透明白 `rgba(255,255,255,.72)`，次级面 `#f7f7ff` |
| 主色 | 紫 `#7550e6`，浅主色 `#e6e0fd` |
| 文字 | 主 `#252730`，次 `#676b82`，弱 `#797d95` |
| 分隔线 | `rgba(126,119,181,.18)` |
| 圆角 | 20px（卡片），小控件 12px |
| 字体 | 系统字体：HarmonyOS Sans SC / MiSans / PingFang SC / Noto Sans SC / 微软雅黑。不引入未知许可的字体 |
| 字号 | 正文 1rem（手机 16px），顶栏 17px，辅助 12–13px。**不要 32px 大标题** |
| 夜间 | 必须同时出夜间稿：深蓝紫底、浅文字，所有颜色用令牌 |

细节见 `docs/App浅蓝紫统一界面.md` 和 `docs/App真机密度与启动首帧修复.md`。

## 3. 要出的页面

手机优先，宽度按 **390px**，并检查 320px 和 412px 下不横向溢出。电脑版出一张 1280px 的广场页和一张对话页即可。

### P1 侧边抽屉（改现有的）
- 顶部：“开启新对话”主按钮。
- 新增“发现智能体”卡片：显示 3 个常用智能体图标，点卡片进广场。
- 历史对话按“最近一周 / 更早”分组。用智能体开的对话显示该智能体的图标，普通对话显示小精灵。
- 底部：头像 + 用户名 + 设置。

### P2 智能体广场
- 顶部：返回、标题“发现智能体”、搜索框。
- 一条横幅位，用来推荐一个智能体或模板。不要做成广告感。
- 分类标签（可横滑）：**全部 / 办公创作 / 公文写作 / 图片处理 / 查询研究 / 生活服务 / 我的**。
- 列表卡片包含：图标、名字、一句话简介、标签（“内置”“我创建的”“来自 GitHub”）。
- 空状态（搜不到）和加载状态也要画出来。
- 首批 8 个智能体，图标请原创，统一一套线性或面性风格：
  1. PPT 制作
  2. 公文写作
  3. 深度研究
  4. 海报设计
  5. 图片转文字
  6. 健康顾问
  7. 出行天气
  8. 行情查询

### P3 智能体详情 / 对话起始页（通用模板）
- 大图标、名字、开场白（1–2 句）、3 个推荐问题卡片（点了先填进输入框，不直接发送）。
- 底部输入框沿用现有对话输入框：加号、听写、发送 / 电话。
- 标注一句“内容由 AI 生成”。
- 进入对话后顶栏显示智能体名字，消息样式沿用现有对话页。

### P4 PPT 制作智能体（专属起始页）
- 主题输入区（最多 1000 字），带上传附件（Word / PDF / 图片）的加号。
- 三个下拉：**页数**（3–5 / 6–10 / 10–20 / 20–30）、**场景**（通用 / 政企汇报 / 工作总结 / 路演 / 教学 / 节日活动）、**语言**。
- 三个入口：“从链接生成”“上传 Word 转 PPT”“用我的 PPT 当模板”。
- **模板库**：两列缩略图卡片，含标题和风格标签，“查看更多”进 P5。
  - 缩略图的位置和比例按 16:9 画；内容先用占位，开发时用未央自己的排版引擎渲染真实缩略图。
- 生成中的进度卡、生成完成的文件卡要单独出图：
  - 只突出最终文件一个；
  - 过程稿默认折叠成“其他文件（n）”；
  - 带“改一页”“换风格”“加演讲备注”快捷按钮。

### P5 PPT 模板库（全部模板）
- 筛选：风格（5 种）× 配色（科技蓝 / 政务红 / 生态绿 / 商务蓝 / …）× 场景。
- 点模板进入预览，可左右滑看 3–4 页样张，底部按钮“用这个模板”，点了回到 P4 并选中该模板。

### P6 公文写作智能体（专属起始页）
- 文种宫格，两组：
  - 机关单位：通知、请示、批复、报告、函、纪要、简报、领导讲话、述职报告、工作总结、心得体会；
  - 职场办公：方案、周报、邮件、致辞。
- 选文种后出一个**短表单**：发文单位、主送单位、事由 / 要点、字数、语气（正式 / 简洁），每个文种字段不同。只画“批复”和“述职报告”两个例子。
- 小工具横条：校对润色、提纲、扩写、续写、改写、缩写。不用“降重”这个词。
- “批复 / 审核意见”要能上传来文（拍照或文件），再生成批复。画出上传后的状态。

### P7 图片处理智能体（专属起始页）
- 功能宫格：海报设计、抠图去背景、证件照换底色、老照片修复、图片转文字、图片配说明。
- 上传区 + 处理前后对比（左右滑动对比条）+ 保存 / 分享按钮。
- 海报设计：选尺寸（竖版 / 横版 / 方形 / 朋友圈封面）、输入标题和要点、出 4 张候选图。

### P8 我的智能体 / 编排（可以先出低保真）
- “创建智能体”表单：名字、图标（从图标库选）、开场白、推荐问题、能用的能力（勾选：联网、生成文档、生成图片、读文件……）。
- **步骤编排**：竖向步骤列表，每一步选“做什么”（搜索 / 整理 / 出文档 / 出图片 / 发提醒），可上下拖动排序、删除。
  - **不做拖拽连线画布**，手机上不好用。
  - 例子：“每天 8 点：查本地新闻 → 整理 5 条要点 → 出一页 Word 简报”。
- 触发方式：手动 / 定时（接现有定时任务）。
- 导出 / 导入智能体（分享给别人）。

## 4. 交付物

1. **每个页面一张手机稿（浅色 + 夜间）**，P2、P3 再加电脑版 1280px。
   - 格式：可直接在浏览器打开的单文件 HTML（内联 CSS，不依赖外部图片）。
   - 也可以是 Artifact 页面。
   - 每页另附一张 2× 截图 PNG。
2. **组件清单**：智能体卡片、分类标签、推荐问题卡、模板卡、下拉选择、文种宫格、上传区、前后对比条、步骤条、文件卡（主文件 + 折叠过程稿）。写清尺寸、间距、圆角、颜色令牌、各状态（默认 / 按下 / 选中 / 禁用 / 加载）。
3. **新增的设计令牌**：如有新增颜色或阴影，按 `--名字: 值` 列出，浅色和夜间各一份。
4. **8 个智能体图标**和 6 个功能宫格图标：原创 SVG，单色可换主题色。
5. **一页交互说明**，写清：
   - 从哪点到哪；
   - 推荐问题点了是填进输入框，不是直接发送；
   - 返回回到哪里；
   - 键盘弹起时输入框和发送按钮必须可见。

## 5. 不要做的

- 不照搬晓伴 / 灵犀或其他闭源产品的图标、模板图、横幅图、文案，也不仿写它们的名字。
- 不出现“福利”“晓伴值 / 剩余字数”这类积分、额度元素。未央没有这套机制。
- 不用 32px 以上的大标题，不做满屏渐变横幅，不加装饰性动画。
- 不画模型名标签栏，也不把“DeepSeek / 通义”等服务商名字放在界面上做卖点。
- 不引入新字体、图标库或 CDN 依赖。图标请直接给 SVG。

## 6. 设计完成后的验收（我们开发前会对照）

- 320 / 390 / 412 三个宽度都不横向溢出，大字体（系统放大 1.3 倍）不重叠。
- 浅色和夜间每个颜色都来自令牌，没有写死在组件里。
- 所有可点元素在手机上不小于 44×44px。
- 广场到智能体到对话最多 2 次点击，返回路径清楚。
- PPT 完成页只有一个主文件醒目，过程稿折叠。

## 7. 之后的开发顺序（供设计参考优先级）

1. 智能体框架 + 广场（P1、P2、P3）
2. PPT 模板库（P4、P5）
3. 公文写作（P6）
4. 图片处理（P7）
5. 编排与自建智能体（P8）
6. 导入导出

请按这个顺序出稿。P1–P5 先出高保真，P6–P8 可以先低保真，确认后再细化。
