## 题集与运行

固定题集 `jarvis/evals/baseline-cases.mjs`，版本 `baseline-30-v1`，30题。保留原有60题与可靠性30题；新题涵盖闲聊、常识、天气、新闻、比分、股票、政务机构、确定性计算、改写翻译、短文档、长方案、Excel、PPT、同会话纠正和代码。题面不把某一天天气或股价写死。

在已登录的自有服务器环境中运行：

```bash
cd /opt/jarvis/当前应用目录
node evals/baseline.mjs
# 默认只预览，无模型调用。登录令牌通过环境变量安全设置，不在命令行写入。
# JARVIS_EVAL_URL 使用自己的服务器HTTPS地址，JARVIS_EVAL_TOKEN 使用已登录会话令牌。
bash evals/run-baseline.sh
# 或已设置登录令牌时：
node evals/baseline.mjs --live --out-dir=/tmp/weiyang-baseline-一个全新目录
```

脚本不自动登录、不改服务配置、不打印凭据。预检要求官方DeepSeek服务商、明确型号、关闭分工与第三方搜索；启动时拒绝服务器已有排队或执行任务。独占目录权限700、报告600；报告含回答和产物路径，属于私有材料，不上传公开仓库。全部串行，最多30题及3次纠正续轮；文件题可能较久，明确调用真实模型并产生费用。每题按任务超时清理，不自动重新提交POST。

纠正题第二轮使用第一轮返回的sessionId，不能新开会话。每完成一题保存报告；Ctrl+C停止已知任务，提交不确定或清理未确认时中止整套，避免反复付费。

## 指标口径与质量检查

- 首字来自服务器任务计时，包含过程说明；另留多轮各轮首字，不能等同于最终结论到达。
- 总耗时包含失败任务，纠正题累加两轮；不把超时剔掉使均值变好看。
- `mainModelCalls` 是主循环逻辑调用；`mainInputChars` 累计主循环消息正文字符，不含系统提示、工具说明、图片、辅助模型与协议重试，缺样本为null。`helperModelCalls`和`helperInputChars`记录工具内部辅助模型；新版计时接口的`allModelCalls`为主循环加工具辅助调用，旧服务器为null，均不包含后台记忆或协议内部HTTP重试，不等同于计费请求。
- `inputTextChars`累计系统提示、消息内容和工具名称/说明/schema字符，包含工具辅助调用；另留`systemChars`及`toolSchemaChars`。只存数字，不存提示原文；适配器还会转换协议，故这是字符估计，不是线上请求字节或Token。缺完整样本为null。
- `userInputChars` 统计实际提交题面字符；不等同于模型上下文字符。未知Token不是零。
- 每题有固定检查点与机械检查。执行done、含网址、存在文件名均不足以证明正确；机械通过仍是`not_reviewed`。实时题核对执行日期、来源原文及数字；Word需打开核对内容；Excel核对实际公式与结果；PPT核对页数和遮挡。

审查文件为JSON数组，每条包含`id`、`quality: passed|failed`和与rubric一一对应的`checkpoints: [{passed: true|false, evidence: "具体核对依据"}]`。每项依据8至2000字，不能只写“已完成”。机械失败不能盖章通过；审查保存成新文件：

```bash
node evals/baseline-review.mjs review 私有目录/report.json 审查.json 私有目录/reviewed.json
node evals/baseline-review.mjs compare 旧/reviewed.json 新/reviewed.json 对比.json
```

型号、地点、题集不一致，发生模型回退，或未完整审查30题时，对比状态为阻塞；已通过题退步或通过率下降为拒收。对比工具不自动回滚生产代码，开发者根据退步原因回退当前项。未测鸿蒙与Windows真机，服务器基线不代表客户端或语音体验。
