# 新闻海报与三端发布交接

2026 年 11 月 18 日，正式版 1.0.465 已在源码仓库和公开下载仓库发布。冻结提交为 `a4c6ee9`，对应 `9b7d412` 的运行清单。公开下载七项资源均已实际下载并核对 SHA256。[公开版](https://github.com/xunova1121/weiyang-release/releases/tag/desktop-v1.0.465) · [正式构建](https://github.com/xunova1121/-/actions/runs/44264383490)

## 海报变化

- 多条新闻在 `make_poster.template` 中使用 `news_brief`。传入 2 至 8 条，`content.lead` 是从 1 开始的头条序号。带话题、图片、图表或超过六条时也能进入新版式。早期只含少量标题和说明的模板仍能按原样重绘。
- 头条、简讯和图表共享同一份文字源稿。图片与出处随所属报道排版，头条可生成带标识的示意插画。图表需要来源和数值，跨报道的不同口径百分比各自展示。
- 视觉验收需要最终 PNG 和 390 像素预览。图文任务还需核对头条和配图与报道的对应关系。缺少证据的视觉项目会标为未核验。
- 半透明层覆盖的图片可参与图文结构检查，整图模型出字时的校对能区分小数点、负号、时间分隔符和号码边界。

## 验收与范围

- 正式构建通过 495 个测试文件、4,371 项单元测试，Office 实际渲染、手机界面及原签名验证通过。
- 随包运行清单含 1,020 项。服务器的发行版 package.json 单独核对版本，其余 1,019 项逐项核对实际字节。公开 Windows 安装包匹配更新清单的 SHA512；公开 APK 的 v2 证书与原证书一致。两个固定更新入口都指向 1.0.465。
- 用三张 NASA 档案照片和七条内容从正常海报工具入口导出 1080 × 2778 的样张，并人工检查 390 × 1004 的整图预览。样张使用工作区照片，栏目和资料由测试者提供。真实服务商选图、付费视觉模型审美、用户真机和生产服务器安装情况仍待实测。
- 1.0.464 在临时构建机安装 LibreOffice 时两次超时，保留为草稿。1.0.465 将构建机的区域 Ubuntu 镜像及镜像列表引用改为官方 HTTPS 仓库，完整测试照常运行。用户服务器未参与构建或安装包分发。
