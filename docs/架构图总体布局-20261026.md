# 架构图升级第3块：总体布局与政企蓝主题

本块对应用户确认的顺序：在前两块之上补模块网格、反馈/安全通栏、分栏及共同平台容器。保持结构化内容→程序布局→唯一scene→四格式，不让模型自由写SVG/HTML，不触碰文档writingRoles。自动候选比较和视觉定点修复仍是第4块。

## 通用能力

- layer.kind可选cards/band/grid/columns：普通卡片仍最多12节点，grid需8～18个纯标题模块，自动6列/2～3行；band需一个内容节点，完整文字横贯全宽，emphasis=true用于深色安全条；columns需2～4栏，支持title/subtitle/detail、可选图标与限定强调色。超过容量明确失败，不填空白凑数、不悄悄丢字段。
- 分栏副标题独立蓝色，说明用较浅文字；每段按实际行数测高。紧凑展示栏适合大屏/PC/手机，内部不叠白块遮掉外侧边框；较长标题自动增高。网格最多两行文字，单行居中，双行也完整保留。
- 连续层可带相同group，形成同一个平台容器和共同标题；最多3个分组，不连续重复须报错，避免画出两个同名平台。标题和结构都来自输入，不自动补造业务能力或数量。
- gov-blue使用浅蓝画布、居中深蓝标题/蓝色口号、白色业务卡片、三色业务端、模块网格和浅蓝能力块。新组合未显式选主题时默认gov-blue，默认从上到下；显式方向仍尊重。旧普通层/旧三主题默认布局和自下而上方向不变，旧scene可直接读回导出。
- gov-blue中的卡片按内容收紧行距，同时保证主图标和第一条要点分开；43字标题按32px实际换行预留第二行，不把口号叠在标题上。总体图不因密集就截字或缩成小字。
- 新组合不在无边时擅画“支撑”关系。明确跨层边走外侧通道，不穿平台共同标题；旧相邻行/右侧通道保留，带字流程仍仅同层相邻cards。右侧仍最多16条跨行通道，过密明确拆图。

- 新布局只生成既有rect/text/path/icon元素，SVG安全子集、元素数量、画布、源稿、PNG大小门槛不动。SVG/PPT/PDF仍引用同一scene和同一PNG，原生PPT真实对照门槛不放宽；旧设计稿不需要迁移。
