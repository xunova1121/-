# 高清海报与同设计交互 Demo

本次范围是把同一份设计用于图片与可操作展示页，不重做未央架构，也不涉及 DeepSeek Harness 联动。

## 使用方式

- “做一张 3840×2160 气象监测大屏，同时给我可点城市、切图层的 Demo，使用演示数据。”
- “用这张无字底图制作沉浸式中文海报，底部 35% 深咖色渐变，标题居中，1080×1440，不要硬色块。”
- “沿用刚才海报的设计稿，补一份交互展示页，不重新生图。”
- “沿用刚才的设计稿，只改标题和我提供的数据，保留底图。”

普通海报继续由 `make_poster` 交付 PNG、可编辑 SVG 和可编辑 PPTX；数据大屏及同稿 Demo 使用 `create_visual_demo` 交付 PNG、SVG、离线 HTML、ZIP 和 `.visual.json`。海报已有 `.poster.json` 可以直接补 Demo。模型明确需要此任务时才加载新增长参数，其他对话不增加整套 Schema。

## 制作与质量边界

图片模型负责无字背景、质感与素材；中文、数值、趋势图和地图标注由程序生成。HTML直接使用同一份 SVG，并为图元添加选择、键盘、详情、图层和趋势点交互。选择时段只查看已有数据点，不伪造新的天气或业务结果。

图像模型请求的型号、尺寸、质量参数与实际返回文件的尺寸/格式分开记录。未知尺寸明确标为未核实；尺寸不符保存原字节，不自动付费重试。型号中含 `4k` 或 `upscale` 不构成实际4K证据。图片模型输出与程序导出后的像素也不是同一概念。

程序 PNG 按指定原尺寸渲染，逐字节读回，并检查字形覆盖和实际像素。底图单独记录原尺寸、放置范围、cover放大倍率；4K画布不等于素材有原生4K细节。场景在渲染前还会实际解码内嵌底图，损坏图片不能被静默省略后称完成。

渐变海报使用独立的透明度渐变与文字层，避免在图片下方拼接实色矩形；不会承诺所有背景下的审美、对比度或文案都绝对正确。`visual:not_checked` 和 `interaction:not_checked` 保留在正常工具回执中：文件交付成功不能冒充每份客户作品已经被看图模型和真实点击验收。

HTML可离线打开，不依赖CDN、外链字体或模型API。下载初始PNG保留原文件字节，导出当前SVG保留当前图层和选中状态。使用者切换了视图后，下载按钮仍明确注明“初始PNG”，不把不同状态混为一份截图。

## 数据与源稿

默认数据明确标为演示。`dataMode=provided` 只表示使用提供的数据，不证明已联网接入真实数据源；没有提供的指标、点位和时间不以示例填补。把旧演示稿切换为提供数据时，未明确替换的数据集合清空，避免仅改来源标签就把演示值变成事实。

地图来自固定版本 Natural Earth 公共领域数据；许可、原始SHA256和简化说明在 `jarvis/licenses/natural-earth-LICENSE.txt`。这是局部地理示意，不是官方审定的完整全国行政地图。点位按经纬度投影，不让图片模型生成城市拼写或位置。

源稿保存设计参数和底图摘要。改稿默认另存；底图变化会拒绝静默复用，路径别名也不能绕过指纹。已有海报转Demo保留原主题、版式、渐变和准确文案。最终交付文件列表、ZIP说明、失败阶段均以实际写入读回结果为准。

## 针对最新对话记录的改进

用户上传的《江苏供销合作总社.md》最后两轮反映：先在本机Python交付后用户称没字，随后工作区重做又恢复硬边色块；指定型号与调用型号、实际像素也曾混在说明里。该导出记录不包含完整工具原始回执，不能据此复核图片实际质量或确定缺字根因。

本次落实的处理原则：优先在未央内复用同一底图与设计；渐变由合成器完成；按最终保存文件而非脚本运行成功判断交付；未满足核心版式要求就标部分完成；工具失败不自动再次收费画底图；原尺寸、字体、视觉和交互的验收各自记录。
