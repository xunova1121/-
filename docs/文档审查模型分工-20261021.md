# 文档审查模型分工（2026-10-21）

## 行为

模型工作台增加“模型分工 · 文档审查”。先将型号加入常用，再选择服务商与型号；本机、云服务器沿用现有分库与局部更新。默认不设置，不自动选贵模型。该配置不改变聊天默认、写作路由、自动分工开关或备用顺序。

仅专业文档工作流的reviewing/verifying使用审查线路；底稿、起草及修改仍用写作模型。未配置时沿用写作模型，交付回执和检查报告明确“审查与写作为同一模型”。配置了同一型号不冒充不同模型；提示用户选不同型号才属于不同模型审查。两个服务商同名型号按provider/model身份区分。

## 边界

配置有误或辅助适配器不可用，延迟到审查阶段报DOCUMENT_REVIEWER_UNAVAILABLE，不阻断闲聊/工具组装，不暗中改用写作模型。保留工作流已写初稿及原恢复机制。审查仍按既有阶段预算、超时和停止规则执行，不增加搜索权限或重试，不把模型审查当事实核验/人工验收。

本批不增加写作偏好、不拆代码、不自动发布。没有新依赖、付费搜索或大块缓存。选择的模型服务按用户已有接口计费，未实测质量、费用和真实首字。
