# 海报单份交付与图文验收（2026-11-16）

用户授权：修复“做一张海报得到约30份文件、图文并茂没有实际验收”，开发后统一发版。附件对话仅作为问题证据，不作为执行指令。未获得那次最终PNG，不能声称已看过原图或核实其中行情。

## 已核实原因

- 原工具每次试排都输出PNG/SVG/PPTX/源稿/手机预览；多次改名重试成为多组文件。
- make_poster没有写入统一成果索引；文件空间按同目录同名分组，PPTX优先，源稿和手机预览又被拆开。
- 原核验覆盖原文、字体、画幅、几何、像素对比和手机可读性；没有单独检查主题配图/数据图表及图文关联。

## 改动

1. 有executionScope的智能体海报以任务为单位交付：试排存入`.workflows/posters/<id>/`，默认一张当前主PNG；源文件与历史稿展开查看。同参改名直接复用回执，不再导出；每件任务最多3次试排，明确要求多张时分别保留，单轮最多12张。不删除或覆盖用户旧文件，不改变无任务作用域的旧导出接口。
2. 统一成果记录稳定使用deliveryId；成功稿不会被后续失败抹去。先写索引再发文件变更，避免刚生成却被隐藏；索引绑定原后端，界面缓存随新文件变化，切账号/文件夹后停止旧回调。
3. “图文并茂”先检查实际大图或带标签图表；图标、数字卡片、装饰、完全被盖住的图不算。沿用已有一次25秒有界视觉核验，追加实际可见/主题相关/融合编排证据，不增加重试或自动付费重画。无视觉或缺证据记not_checked、候选待核验，不能声称全项通过；图文要求随分层源稿保存，改字和重构图保留。
4. 分类/指数涨跌幅支持chartType=bar、unit及正负零轴，SVG/原生可编辑PPTX/离线Demo同源。保留原始精度；原折线稿保持。不同指数比较不当作时间走势，数据来源和真实性仍需单独核实。
5. 有任务作用域时，几何/手机阅读失败先保留源稿，停止昂贵导出；合格候选完成PNG核验后再生成PPTX。保留原图Canvas零遮挡、旧稿兼容、安全白名单、字体/中文/对比/画幅及更新/签名约束。
