## 功能与入口

- PC 设置 → 全息陪伴桌面：远景、最新角色、摸头/连续点击害羞、文字聊天、拖动顶部移动、设置调整大小。透明背景与点击区域分别验证；锁屏和休眠隐藏。模型请求由主窗口完成，完整记录继续保存。
- 手机点击未央头像 → 全息陪伴：全屏二维角色、摸头光效、比心、文字动作指令、模型文字回复；键盘弹出让出空间。完整对话按钮返回原会话。原有语音/表情面板保留。
- 手机全息陪伴右上角设置 → 设为手机动态壁纸：系统预览确认后生效。原生壁纸点击角色有反馈，闲置睡觉；不启动 WebView，不申请悬浮窗/麦克风权限。壁纸“聊一会”打开应用内全息对话，没有系统浮窗输入。
- 1.0.98 的滚动条完全隐藏、最近四条记录与“查看更多”继续保留。
