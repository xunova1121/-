# DeepSeek Search/Fetch接入

官方协议核对日期：2026-10-21（北京时间）。

## 使用

先更新服务器，再更新电脑/手机。在“模型”页选择“本机”或“云服务器”，展开“联网搜索 · DeepSeek Search/Fetch”。填独立官方Key，或留空复用该位置DeepSeek官方服务商的Key；保存并启用后再测试。不会读取中转商Key，也不改变聊天默认模型。本机/云服务器分别保存，复制模型配置不会自动启用该搜索开关。

“测试Search”和“测试Fetch”只访问固定公开内容，不使用模型；每个按钮最多两次请求，可点停止。返回耗时、次数和结果条数/字符数，接口成功不等于事实核验通过。独立Key留空保存会保留旧值；关闭开关后停止使用新服务，恢复原线路。

## 费用

[官方说明](https://api-docs.deepseek.com/zh-cn/guides/search/)与[价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)列明：Search、Fetch各每1000次成功请求5元，按是否成功返回结果计费，不按结果条数计费。普通直接API调用不能套用指定Harness/Claude Code/Codex服务端工具的临时免费条款。按该价格，一次搜索加一次抓取为0.01元；测试/重试可能分别计费，实际扣费以平台账单为准。默认关闭，不擅自修改服务器生产配置。

## 实现边界

- 固定官方POST端点/v1/tools/search与/v1/tools/fetch，Bearer鉴权；搜索最多返回10条，查询最长128 Unicode字符。freshness转after日期；超过长度明确报错并可回免费源，不静默截断原问题。
- 搜索只要摘要与元数据，不索要整页正文；保留发布时间及服务商评分，但评分不等于独立核实。非空官方结果直接使用，避免多查免费源。失败/空结果使用原搜索线路，保留停止和预算信号。
- Fetch优先使用官方抓取，失败可直接读取及沿用原代读；重试/备用物理读取前扣预算。原PDF读取、证据缓存和有界页面缓存保留。私有和含账号密码的地址不转给公共代读。
- 单请求10秒、网络/超时最多重试一次，沿用随机可取消等待；每次重试前扣预算，HTTP鉴权/余额/限流不盲重试。响应正文最多2MB，抓取文本最多60000字符；不新增无界缓存或把正文塞进会话。
- 同源网页网关分离登录令牌与官方Key；固定端点代理不转发用户令牌，禁止重定向，断开和超时取消。服务器测试接口要求登录，最多两个并发，只用服务器保存的设置。

## 验证边界

自动化验证使用假Key、假响应和本机假服务商，不会发真实付费API请求。官方文档已核对；本环境无生产登录或官方Key，shell代理连接失败，直连试验未到达上游。没有真实Key的搜索成功率/耗时对照，不能以模拟测试冒充真实效果；Windows/鸿蒙真机尚未测试。正式发布与完整CI结果在交接记录中补充。
