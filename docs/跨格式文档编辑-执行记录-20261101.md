# 跨格式文档编辑（2026-11-01）

用户授权：自然语言理解后修改已有文档，不局限Word；完成修改后发布。模板仅为新建可选起点，不代替原文件编辑。本记录不把确定性工具测试冒充真实模型理解验收。

## 实现

- `read_document_structure`：读取真实DOCX/PPTX/XLSX/PDF结构，返回分页对象摘要、当前SHA256和实际支持操作；最多100条/次，文本摘要240字。
- `edit_office_document`新增可组合operations。模型基于要求选择对象和属性，执行器核当前摘要、明确范围及上限；默认另存，拒绝结构编辑覆盖原件。旧Word/PPT文字替换、Excel数据/公式编辑和文本文件编辑保持。
- Word：标题/正文/精确段落选择，字体字号、加粗、下划线、对齐、段间距、行距、标题层级、段前分页；标题线同时处理直接边框、样式继承和相邻空段落装饰，表格边框不动；正文批量编辑保留空白分页/分节控制，新增属性按OOXML顺序插入；表格行不拆/重复表头/连接行、各节页边距。
- 目录：从真实标题层级与Office PDF书签定位取实际页码，只回填目录缓存，不通过Office重存整份源DOCX。最多4轮，目录占页变化后再计算，连续相同才通过。可定位的连续阿拉伯页码/标题起始分节重启支持；自定义域、多目录、非阿拉伯编号、无法定位的重启节明确拒绝。域范围夹带正文/图表/分节拒绝替换。目录外XML及关联保持；新增标题层级后可建目录。
- PPT：按真实页序与元素ID修改文本格式或位置尺寸；媒体、关系、其他页不重建，旧底稿摘要失配后不能覆盖修改。
- Excel：按真实工作表及已有范围修改字号/字体/颜色/对齐/换行/数字格式，独立样式不影响范围外；横纵打印与分页缩放。数值、公式缓存、图表关系不改。数据/公式修改仍用原edit_spreadsheet。
- PDF：页面旋转、全页重排、可视区域裁切，保留所有页面。裁切不删除底层信息，不可用于脱敏。扫描件OCR和任意正文重排不在本版支持范围，不用白块覆盖伪称编辑成功。
- 真实PDF及全页总览复用现有服务器能力；结构、内容、渲染、视觉状态分别记录。生成截图不等于已经模型/人工视觉审核。缺Office或截图工具明确告知，不伪造截图或页码。
- 新依赖固定：@xmldom/xmldom 0.9.12（2026-08-21）、pdf-lib 1.17.1（2021-11-06）。未新增Python运行时；原件最多20MB，XML8MB，PDF120页，单批30操作，Excel范围2000格。
