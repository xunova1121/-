# 指前镇水产集散交易与智慧养殖综合平台建设方案（初稿 V0.1）

> 说明：本稿根据与需求方的初步沟通整理，标注 **【待确认】** 的内容需进一步与业主确认。末尾附《待确认事项清单》。

---

## 一、项目背景

1. **资源基础**：指前镇业主自营养殖区约 7000 亩，周边分布大量散养农户，水产品产量大、上市集中。
2. **现状痛点**（推测，【待确认】）：
   - 出塘交易以人工过磅、手写单据为主，效率低、易出错、易起纠纷；
   - 规格分级、质量检测结果无法随货流转，买方信任成本高；
   - 资金结算靠现金/个人转账，对账难、资金风险高，财务无法实时掌握经营数据；
   - 核心养殖区“业主出设备和生产资料、合作户出人力和技术”的合作模式，缺乏数字化手段进行过程管理、投入核算和产出分成。
3. **建设目标**：打造一个集 **“产—检—称—存—卖—结—算”** 于一体的综合平台，前端以 **微信小程序** 服务交易各方和合作户，后端以 **管理平台（PC Web）** 服务业主运营管理，实现：
   - **交易快**：电子秤自动采集，扫码即开单，快进快出；
   - **质量可信**：快检报告随批次上传、随单可查，形成可追溯链条；
   - **资金安全**：与银行合作实现交易资金清分结算，钱款直达、自动分账；
   - **业财一体**：交易、库存、生产投入、结算数据自动生成财务凭证；
   - **养殖智能**：450 亩核心区设备集中监控、AI 辅助决策，生产资料全流程管控。

---

## 二、建设原则

| 原则 | 说明 |
|---|---|
| 一个平台、统一底座 | 交易、仓储、结算、养殖、物资共用一套用户、主体、商品、批次和账户体系，避免数据孤岛 |
| 现场优先、操作极简 | 过磅、入池、出库等现场环节以“扫码 + 自动采集 + 一键确认”为主，适应农户和散户的使用习惯 |
| 资金合规 | 资金不进平台自有账户，通过银行清分（见证宝/资金监管/分账类产品）完成结算，规避“二清”风险 |
| 分期建设、快速见效 | 一期先上线交易集散 + 结算核心闭环，二期深化智慧养殖与 AI 分析 |
| 开放可扩展 | 预留对接政府监管平台、食品安全追溯平台、金融机构信贷产品的接口 |

## 五、功能设计

### 5.1 交易集散子系统（核心）

#### 5.1.1 货源登记与到场
- 供货方（自营塘口/周边农户/合作户）在小程序**预约出货**：品种、预估重量、预计到场时间、塘口信息；
- 到场后扫码**签到排队**，系统生成入场批次号，叫号过磅，减少现场拥堵；
- 农户档案：身份信息、塘口位置、养殖品种、银行收款账户（绑卡实名）。

#### 5.1.2 快检管理
- 质检员按批次抽样快检（如孔雀石绿、硝基呋喃类、氯霉素等药残，项目【待确认】）；
- 小程序/管理平台**上传快检报告**（拍照 + OCR 识别结果，或快检仪器数据直接对接）；
- 检测结果与批次绑定：**合格方可进入过磅交易**，不合格自动拦截并记录、预警；
- 采购方扫描溯源码即可查看对应批次快检报告。

#### 5.1.3 分级与电子秤过磅（快进快出）
- **电子秤联网**：过磅终端自动读取重量，杜绝手工录入，支持去皮（筐/箱/水）；
- **规格分级**：按品种预设规格档（如“2–3 两/尾”“3–5 两/尾”），过磅时选择规格，或按抽样尾数自动计算规格；
- **一车多规格**：同一批次可连续多次过磅，自动累计各规格重量；
- **自动开单**：确认后实时生成交易单（品种、规格、毛重、皮重、净重、单价、金额、快检状态），供需双方小程序同步收到，现场打印小票/标签（含溯源二维码）；
- **定价方式**：支持平台挂牌价、供需议价、合作经营户协议价【待确认是否需要竞价】；
- 异常处理：复磅、改单需双人审核并留痕，防止作弊。

#### 5.1.4 采购与成交
- **合作经营户**：提前下采购单/预订，享协议价、账期或授信额度【待确认】；
- **散户**：扫码即可下单，现场付款提货，降低使用门槛；
- 成交后支付完成即放行出场，**出场扫码核验**，交易闭环。

#### 5.1.5 行情与信息发布
- 每日品种价格行情、到货量、库存量发布；
- 小程序推送到货通知给关注该品种的采购方，提升成交速度。

### 5.2 暂养池管理
- 暂养池档案：池号、容量、水质监测设备绑定；
- **入池**：交易批次或业主收购批次过磅入池，记录品种、规格、重量、来源；
- **池内管理**：水质监控（复用智慧养殖 IoT 能力）、损耗登记（死亡、掉秤）；
- **出池**：销售出池过磅，自动扣减池存；
- 暂养费用计算（按天/按重量），可在结算时自动扣收【待确认：暂养池是对外收费服务，还是只用于业主自营周转】。

### 5.3 冷鲜库管理
- 库位管理、温度实时监控与超温告警；
- 入库（过磅、加工规格、包装、批次）、出库、移库、盘点；
- 先进先出与保质期预警；
- 冷库租赁/仓储费用计费【待确认是否对外提供仓储服务】。

### 5.4 清分结算（银行合作）
- **账户体系**：依托合作银行为供货方、采购方开立子账户/虚拟账户（或绑定个人银行卡），平台不触碰资金；
- **支付方式**：采购方通过小程序在线支付（银行聚合支付/微信支付通道）、对公转账、POS 刷卡；合作经营户可预存保证金/预付款；
- **自动清分**：交易成交后按规则自动拆分：
  - 货款 → 供货方（农户/自营/合作户）；
  - 交易服务费、检测费、暂养费、冷库费 → 平台（业主）；
  - 合作户分成 → 按合作协议比例分账（见 5.7）；
- **结算周期**：支持 T+0 实时到账 / T+1 批量结算，可配置；
- **对账**：每日与银行自动对账，差错处理，生成对账单；
- **金融延伸**（二期）：基于交易流水为农户/经营户提供供应链金融、信用贷款对接。

> 合规提示：结算模式需由银行出具方案（如资金存管、见证宝、电子账簿分账等），确保平台不形成资金池，避免“二清”合规风险。

### 5.5 业财一体
- 交易单、入出库单、生产资料领用单、结算单 **自动生成财务凭证**；
- 对接财务软件（用友/金蝶等【待确认现用财务软件】）；
- 电子发票开具（对接税务开票系统），农产品收购发票处理；
- 经营报表：交易额、交易量、品种结构、客户排行、收入构成、毛利、应收应付、资金流水；
- 成本核算：自营养殖区和核心区按塘口/合作户核算投入成本（苗种、饲料、药品、电费、人工）与产出收益。

### 5.6 智慧养殖子系统（450 亩核心区，可逐步扩展到 7000 亩）

#### 5.6.1 设备管理与监控
- **设备接入**：水质在线监测（溶氧、水温、pH、氨氮、亚硝酸盐、浊度）、增氧机、投饵机、水泵、气象站、视频监控等；
- **一张图**：GIS 地图展示塘口分布、设备在线状态、实时水质；
- **远程控制**：手机远程启停增氧机/投饵机，支持定时策略和联动策略（如溶氧低于阈值自动开增氧）；
- **告警**：低氧、断电、设备离线、水质异常，通过小程序消息/电话/短信推送给合作户与管理人员；
- **设备资产**：设备台账、绑定塘口和合作户、巡检、维修保养记录，明确设备归属业主、使用归合作户的责任。

#### 5.6.2 AI 数据分析
| 能力 | 价值 |
|---|---|
| 溶氧/水质趋势预测 | 提前 2–6 小时预测夜间缺氧风险，自动建议开机 |
| 智能投喂建议 | 结合水温、天气、存塘量、摄食情况给出投喂量建议，降低饵料系数 |
| 病害识别 | 拍照/视频识别常见病害，给出防治建议 |
| 生长与产量预估 | 结合投喂、抽样数据预估规格和产量，辅助出塘与销售计划 |
| 养殖对标分析 | 不同合作户、塘口之间的饵料系数、成活率、亩产、亩效益对比 |
| AI 助手 | 自然语言查询数据（如“3 号塘本月饲料用量”），自动生成日报/周报 |

#### 5.6.3 养殖生产记录
- 塘口档案、放苗、投喂、用药、换水、巡塘、捕捞记录（小程序快捷填报，部分由设备自动生成）；
- 生产记录与出塘批次关联，形成从苗种到交易的**全程溯源**。

### 5.7 生产资料管理与合作户管理

#### 5.7.1 生产资料管理
- **物资档案**：苗种、饲料、渔药、动保产品、设备配件等；
- **采购入库**：供应商、采购单、入库验收；
- **申请—审批—领用**：合作户在小程序提交申请（品种、数量、用途、塘口），按金额/品类走审批流，审批通过后到仓库扫码领用、签字确认；
- **库存管理**：库存预警、盘点、批次与有效期管理（渔药尤其重要）；
- **用量核算**：按合作户/塘口统计领用量，与 AI 投喂建议、产量对比，识别异常领用。

#### 5.7.2 合作户管理与分成
- 合作户档案、合作协议（电子签约）、承包塘口、考核指标；
- **投入台账**：业主投入的设备折旧、生产资料、水电等成本自动归集到合作户；
- **产出核算**：合作户出塘交易数据自动汇总；
- **分成结算**：按协议规则（如利润分成/保底+分成/按产量计价【待确认具体模式】）自动计算，通过银行清分直接分账给合作户；
- 合作户小程序可实时查看自己的投入、产出、预计收益，提升积极性与信任度。

### 5.8 质量追溯
- 一批一码：从塘口（生产记录）→ 快检报告 → 过磅交易 → 暂养/冷库 → 出场，全链路可追溯；
- 采购方/终端消费者扫码查看产地、品种、规格、检测报告；
- 预留对接国家/省级农产品质量安全追溯平台接口。

### 5.9 数据驾驶舱
- 交易大屏：当日交易量/额、品种价格、到货排队、成交实时滚动；
- 养殖大屏：塘口一张图、设备状态、水质告警、AI 预测；
- 经营看板：收入、成本、利润、资金流水、合作户排行。

### 5.10 系统管理
- 组织机构、角色权限（按角色/数据范围）、操作日志、字典配置（品种、规格、检测项目、费率）、消息模板、数据备份。

## 七、关键业务流程

**流程一：农户送货交易**
1. 农户小程序预约 → 2. 到场扫码签到 → 3. 抽样快检、上传报告（不合格拦截）→ 4. 分级过磅、自动开单 → 5. 采购方小程序确认并付款 → 6. 银行清分：货款到农户、服务费到平台 → 7. 打印小票与溯源标签、出场核验 → 8. 自动生成财务凭证。

**流程二：业主收购后暂养/冷藏再销售**
1. 过磅收购（与流程一相同，采购方为业主）→ 2. 入暂养池/冷鲜库 → 3. 池存/库存管理、损耗登记 → 4. 销售出池/出库过磅 → 5. 采购方付款、清分 → 6. 成本与毛利核算。

**流程三：核心区合作户生产**
1. 签订合作协议、分配塘口与设备 → 2. 物资申请—审批—领用 → 3. 日常生产记录 + 设备自动监测、AI 建议 → 4. 出塘进入交易流程 → 5. 投入产出自动核算 → 6. 按协议分成并清分到合作户账户。

## 九、数据安全与合规
- 等保二级（建议）设计，数据加密传输与存储，敏感信息（身份证、银行卡）脱敏；
- 资金结算由银行完成，平台仅传递指令，满足支付结算合规要求；
- 电子秤需符合计量法规，过磅数据不可篡改并留存日志；
- 交易单、协议采用电子签章，具备法律效力；
- 数据异地备份，过磅现场具备断网续用能力。

## 十、实施计划（建议）

| 阶段 | 周期 | 内容 |
|---|---|---|
| 一期：交易集散 + 结算闭环 | 约 3–4 个月 | 用户主体、预约签到、快检上传、电子秤过磅开单、采购支付、银行清分结算、暂养池/冷库基础出入库、基础报表、小程序与管理平台 |
| 二期：智慧养殖 + 生产资料 | 约 3 个月 | 450 亩核心区设备接入与监控、远程控制与告警、生产记录、生产资料申请领用、合作户投入产出与分成 |
| 三期：AI 与业财深化 | 约 2–3 个月 | AI 预测与识别、AI 助手、业财凭证对接、数据驾驶舱、追溯平台对接、供应链金融 |

> 需求调研与现场勘察建议在一期开始前完成（约 2–4 周），银行结算方案需尽早启动，审批周期往往是项目关键路径。
