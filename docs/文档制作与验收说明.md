# 未央文档制作与验收

这套能力把制作方案、真实文件生成、定点修改和验收分开。它增强工具与流程，不是更换底层模型，也不承诺任何文件都能一次通过。

## 使用方式

- 直接提出用途、受众、资料和输出格式，例如“用这份月度台账做经营汇报PPT，突出目标差异和行动”。
- 要看方案时可说“先列结构”；信息足够且没有要求停下来时直接制作，不额外索取一次确认。
- 可说“列出文档模板”，查看12套场景配方；它们是内容结构和制作规则，不是12份已经填好的企业品牌文件。
- `plan_document`不调用模型，返回适用方案、章节、内容骨架、资料边界与检查步骤；`create_document.template_id`可指定方案。显式theme、cover、toc优先于方案默认值。
- 不指定配方时按要求关键词选择。选择是启发式，不代表模型评估了所有场景；复杂任务仍需结合资料判断。

## 本批12套场景

| 格式 | 配方 |
|---|---|
| PPT | 项目方案与决策汇报、工作复盘与进度汇报、经营分析与行动决策、产品与技术方案 |
| Word | 正式报告与分析方案、通知与正式公文、项目建议书、证据型研究简报 |
| Excel | 预算与投资测算、任务与项目跟踪表、工作任务考核表、经营数据与差异分析 |

配方包含不同的章节、资料约束、表格骨架和检查规则。PPT沿用既有卡片、对比、流程、图表等内容驱动版式；Word研究简报使用独立的紧凑版心、字号、行距和标题线，项目建议书默认封面，显式配方的短文档默认不另占目录页（可用toc覆盖），公文沿用正式公文路径；Excel根据业务口径组织表头、公式与工作表。

主题配色仍是另一层，不能把配色数量当成模板数量。没有把其他平台的私有模板或内部系统提示复制到未央。

## 企业模板边界

现有Word上传模板可沿用样式定义，不等于完整保留原模板封面、页眉图片、所有域和页结构。不指定路径且只有一份Word模板时沿用；多份时必须明确选定路径，防止自动拿错公司的模板；`template: "none"`不使用上传模板。

本批没有实现任意企业PPT母版或任意Excel模板的新建套版。已有PPT/Excel的指定内容修改可以保留未改部件，和“套企业模板重新生成整份文件”是两回事。

## 生成与检查

1. 保留既有生成前内容检查、生成后公式/布局检查的一轮修正，以及配置了看图模型时的PPT生成器预览审查。不增加无界审稿重试。
2. 对真实Office包检查结构并读回有效内容；Excel重新从实际工作簿静态检查公式和错误值。公式静态检查不等于求值，未知函数也可能需要实际Office核实。
3. 可用时由运行端LibreOffice转换为真实PDF；逐页检查可提取文字及可疑页面边界。图片页、旋转文本、重叠、遮挡和美观仍需要打开预览或进一步视觉审稿。
4. 旁边保存`文件名.扩展名.检查.json`，含格式、字节数、检查状态、最多40条短问题、实际预览路径等；不存正文、密钥或用户画像。报告是交付物，不放进对话记录、检查点或localStorage。
5. `check_document`可独立复查已有文件，返回短报告，不重写原文件、不创建副本、不自动转换。

结构通过、有效读回、静态公式检查、PDF转换、PDF页面检查、生成器看图、事实核实、真实视觉审稿分别标记。不能由“文件存在”推断全部合格。

渲染失败保留可编辑文件；渲染开始前先记录已保存文件的短验收回执。停止或检索预算信号仍上抛；不把中断当作整个任务从未生成过文件。报告保存失败会明确报错，不宣称全部交付成功。

## 精确修改

- Word/PPT：`edit_office_document`保留原有文字替换方式。PPT可用`slides`指定实际页码（从1起，包含封面），只改选中页的可见文字，不改备注。按presentation关系取真实顺序，不把slide文件编号当页码。
- `expected_count`校验整批文字匹配总次数，不符不保存。改完重新检查真实产物；不把其他页面一并重新生成。
- Excel：`edit_spreadsheet`指定工作表、已有格、value或formula，可用`expected`核对旧值。一批内任一冲突，整批不保存。样式、图表等非目标部件不经ExcelJS全量重写。
- 修改输入后清理公式缓存和旧计算链，让Office重新计算；不捏造新结果。明确的新公式错误拒绝保存。已有静态检查未发现的函数行为仍需实际重算。
- 此次未实现任意Word章节重排、PPT单页重设计、Excel新增复杂行列。大范围改版仍应另存新文件。

本地连接文件夹沿用“同名另存”的保护，不绕过既有备份策略；回执和预览按实际保存路径关联。

## 资源与验证

外来Office压缩包20MB、展开80MB、3000部件；工作簿50张表、5万非空格、累计20万格使用范围；一批最多100处文字/格修改；PDF30MB、120页、每页1万文字项。超限明确失败，不无限处理。

`e2e/document-quality.mjs <输出目录>`使用明确标为合成测试的经营PPT、项目建议书Word、考核Excel，实际生成/读回/转PDF/检查页面，验证PPT局部修改、其他页保留和Excel输入变化后Office实际重算。真实用户资料和商业模型语义质量仍需另行验收。

旧的PPT副封面合并曾误把“带日期的实质正文页”移入封面；现在仅整行是日期或已知封面原文才允许合并，保留原封面去重测试并增加正文保留回归。

实际页面复查另修复：Excel显式求和公式沿用同列百分比格式，避免权重合计100%显示为1；数值右侧增加内距，避免与下一列文字贴在一起。
