# 第2批第三项：上传Word重排时保留原件结构

上一项3659531的完整功能门禁通过后单独实施。解决原文只在Word文件里、需要重新排版时不能依赖模型重抄正文的问题。仅覆盖样式重排，不把实际页数协调或任意字体参数应用算作已完成。

## 实现

- `source_path`绑定工作区DOCX；可绑定本轮明确路径、最新上传或本段对话实际生成回执。助手正文口头提文件名不构成回执。较新的粘贴正文优先，旧文件名的前缀/被否定版本不能冒充目标，明确后续更正优先。
- `documentFileSource`只读来源；`docxRestyle`只更新`word/styles.xml`，按样式名称匹配标准样式，保留原样式编号和自定义样式，合并命名空间声明并拒绝冲突。
- 新文件打包后重新解包：非目录部件清单必须一致；除样式部件外，正文、表格、图片、编号、关系、页眉页脚等全部部件逐字节比较。未通过先报错，尚未写入目标。
- 保留直接格式及原有封面/目录；新增封面/目录不能冒充已有样式重排。输出与来源同名（含`./`等别名）时另存`_排版.docx`，保留原件。
- 每次重新读取原件并记录原文件SHA256，不新增会话正文副本，不缓存文件快照。排版在本地代码中完成，不调用模型改写。
- “按偏好重新做一版/重新排版”进入来源保留；明确重写仍走写作入口。显式绑定是单次工具的保文契约，允许先套版再用编辑工具改文字；编辑后重新验收，不继承先前保文结论。来源绑定参数不能在其他格式中被静默忽略；PDF从同份Word真实转换。

## 范围与验证

- 原文件最多20MB；沿用Office包最多3000部件/80MB展开；样式XML最多200万字符；附件和明确路径引用最多32项、所选路径400字符；会话文件索引沿用12条、每条12路径。大小超限不截断冒充全文。
- 新8项单测：实际Word所有非样式部件和图片保持、中文数字标题ID/自定义样式、真实工具绑定/不改写、旧来源与最新正文、实际回执/停止、源文件更新/同名另存、命名空间/上限/格式契约、否定和更正。
- 定向5文件31项与lint通过；新增真实`e2e/document-file-source.mjs`本地通过，使用合成Word和真实渲染PNG；Office生成PDF后核对文字，并读取真实PDF绘图指令确认图像仍存在。原件不改，最终Word与PDF保存在临时验收目录。原测试不删不跳不松。
- 最终固定源码仍须原完整CI验证；本段定向结果不冒充全量通过。未使用客户原文件、真实付费模型或安卓/Windows真机验收。
- 样式定义与直接格式分开处理；当前不会为了“统一主题”重写原件内的直接格式、重建图片或列表。复杂字体角色/精确页数仍按后续项处理。
