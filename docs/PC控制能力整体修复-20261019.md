# PC控制能力整体修复

2026-10-19（北京时间）。基线67931a69 / 正式版1.0.183。用户要求修复的范围是电脑操作整体能力，不只为某一个文件名写特例。

## 已定位的问题

- 用户原话“帮我打开天合云商2026年9月重点工作任务考核表-冷链 这个文档”在旧needsComputer中实际返回false：旧规则只看“打开”后十字及少数词。服务器模式会交给没有PC工具的服务器执行器。
- 本机computer_search被延迟加载，通用工作方式又优先引导find_files，模型容易把虚拟工作区当成整台电脑。
- 本机模型配置与服务器配置分离：即使正确分到PC，本机只有演示模型时仍不能使用服务器已配置的真实模型控制电脑。
- GUI反复看屏、按同一快捷键会被通用重复调用规则拦截；模型同一批连续动作又可能没有真正看过中间截图。
- 看屏隐藏主窗口后，后续确认卡没有恢复窗口的专用路径；输入失败可能未恢复文字剪贴板；隐藏等待期间停止后仍可能继续动作。
- 直接拼HOME/Desktop等路径不支持系统重定向；多屏捕获直接取第一项可能与主屏坐标不一致；搜索范围受限未明确报告；不存在的文档路径可能被当成程序启动。

以上是代码定位，不能断言用户这次实际运行的版本、设备形态或每个模型调用经过了所有这些问题。

## 实现

1. 本机任务识别覆盖长文件名、常见文件操作、程序启动、窗口/鼠标/输入/快捷键。明确工作区、附件、生成文件保留原来源；截图内容分析不会自动变成控制PC。紧邻上一条PC操作的“继续”等短指令保留本机上下文，普通新闻聊天不受影响。
2. computer_capabilities与computer_search常驻；未指定搜索目录时查系统实际桌面/文档/下载。完整名称或关键词搜索，返回路径与范围；不存在、无权访问、深度/数量/时间预算受限如实说明。系统常用路径由Electron app.getPath取得。
3. 服务器模式PC任务：客户端运行runAgent及本机工具，服务器仅代理已配置模型推理。新认证接口/api/server/pc-model不执行工具、不接受客户端任意上游URL/密钥；有并发与输入上限、取消、SSE等待检测、错误密钥隐藏及无输出时的备用模型。客户端配置可以仍是演示，服务器必须是真实模型；旧服务器明确要求更新，不偷偷退回演示。
4. GUI任务优先配置的看图模型，按需主动加载GUI工具。先看屏、每步返回新截图；同一模型回复中得到新截图后，不再盲目连续执行下一GUI动作。截图/状态相关工具不套用“相同参数结果不会变”的规则，仍受步数与失败控制。GUI任务不按普通聊天60秒截断。
5. GUI动作失败即失效旧截图；输入/快捷键也先确认画面。初始化失败可以重新开始。模型上下文只保留最近两张工具屏幕图及全部文字结果，不删除用户附件。
6. 需要确认时先恢复主窗口，保持紧急停止可用；动作开始再隐藏。停止会在等待后再次检查；输入失败恢复文字剪贴板，用户同时复制的新文字不被覆盖。截图选择匹配主屏ID。
7. 打开返回“请求已提交、显示结果未核验”，不把操作系统接受请求冒充界面已核对。原有文件备份、危险命令拦截和确认规则保留。

## 验收

- pcControl单测覆盖用户原话、其他PC任务、来源排除、短指令续接、工具加载、真实临时文件搜索打开、系统目录重定向、搜索范围、初始化恢复、旧截图失效、反复看屏、同批盲操作、文字剪贴板和停止。
- pcModelBridge单测走实际HTTP：认证、服务器配置、看图路由、工具只返回不执行、取消、并发限制、半截断线、旧版提示、密钥隐藏、备用模型和心跳。
- 新增真实Electron端到端：本机不配真实模型、服务器配可控模型，通过真实HTTP桥与真实PC IPC查找/打开原话文件；再用真实截图、剪贴板、原生键盘在临时测试窗口输入并核对，检查隐藏后的确认卡可见和窗口恢复。
- 推理模型是可控测试模型，不代表真实模型能看懂任意软件。Linux/Electron验证不等于Windows真机验证，更不证明WPS、微信、所有网站或多屏硬件配置均已通过。
- 本批不实现手机远程接管PC，不承诺管理员权限界面、锁屏/验证码、任意软件100%成功，也不是隔离项目开发沙箱或任意进程精确续跑。

## 更新与使用

需要PC安装版；服务器模式还需“立即更新服务器”，两端都更新后才能使用模型桥。服务器已有的真实模型和密钥直接复用；看屏需在服务器模型分工配置支持图片的模型。文件查找和打开不强制发送截图。

先测试普通文档搜索打开，再测试在临时记事本中输入；看屏/输入保留原有确认。可用Ctrl+Alt+Q或鼠标移到左上角停止。多个同名候选应确认路径；常用位置未找到会询问所在盘/目录，不等于已搜遍全盘。

文件名和必要截图会随任务发给用户所配置的模型服务，操作仍在本机执行。关闭/断网/崩溃后的精确恢复、云端任务中途迁移到PC和任意软件视觉理解仍需后续专项，不以已有工具名冒充完整能力。

补充：同一任务使用可用备用模型后继续复用；文件任务收到截图后自动转到服务器看图分工，先前文字模型偏好不能覆盖新的看图需求。
