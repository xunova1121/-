## 已实现的流程

设置 → 管理手机操控 → 打开系统无障碍设置 → 本人开启“未央手机操控” → 返回选择本次允许操作的应用 → 开启15分钟。不开启时不能读取或操作。支持24及以上安卓版本的页面节点、点击、输入、滑动、返回/桌面；截图需要Android 11及以上且系统允许。系统保护屏幕会明确失败。

动作包含打开应用、设置闹钟、打开导航/拨号/分享页。系统请求发出只报告“已请求”，不虚构闹钟已创建、电话已拨出或消息已发送。其余工作复用现有智能体：phone_devices确定本人设备，phone_action取得真实屏幕，每次核对回执后再发下一步；缺节点时可截图交现有看图路径。一次模型响应最多执行一个手机动作，不连续盲点。验证码和密码输入由本人完成；发送、删除、付款及无法判断用途的点击，在手机可见控制条确认，模型没有跳过确认的接口。

云端注册通过原有账号鉴权；一个账号最多5台、全局250台临时设备，每台只有一个在途命令。设备凭据仅驻内存、服务器只保存摘要，不能访问会话/文件等API；不写注册记录、配置、对话和日志。设备主动以HTTPS轮询，无需开放手机端口；HTTP仅允许本机开发地址。登录撤销、账号停用、15分钟到期均撤销连接。用户切账号、手机锁屏、停止或连续断网都会停止，停止后的旧轮询和迟到回调不能干扰新连接。

命令一次领取，动作前再次验证任务仍有效；45秒回执超时显示结果未知，不自动重放。旧屏幕编号、页面版本变化、节点内容/位置变化均拒绝点击。屏幕节点最多160个；截图遮住密码/验证码输入及当前应用之外的区域，页面遍历不完整则拒绝截图。未央自己的设置页不交给读屏工具。每次重新读屏销毁旧节点；模型输入保留最近两屏/两张截图，进度和恢复检查点不保存屏幕正文。模型最终文字回答仍会像普通对话一样保存。
