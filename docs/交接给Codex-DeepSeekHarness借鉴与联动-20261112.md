## 二、dsh 是什么（Claude 已读源码核实）

- 官方仓库：https://github.com/deepseek-ai/deepseek-harness ，读的是 `main` 分支 `e8f7b93a`（2026-11-11）。LICENSE 为 MIT（Copyright 2026 DeepSeek）。
- Node / TypeScript，内核是 Cordis 插件树：模型适配器、工具注册表、会话日志、agent 主循环都是插件。
- 入口：`npx @deepseek-ai/dsh web`（本机 3080 端口网页版）、`headless`、`sdk`（按行分帧的 JSON-RPC over stdio，有 TS 和 Python 客户端）、`acp`（标准 Agent Client Protocol，可挂载标准 MCP 服务）。另有 Electron 桌面版。
- 状态：README 明写“开发者预览，**将出现破坏兼容性的变更**”。不要把它当稳定依赖硬绑。
- 相关文档（仓库内）：`docs/architecture.zh.md`、`docs/capability-seams.zh.md`、`docs/api-gateway.zh.md`、`docs/deepseek-llm-api-wire-extensions.zh.md`，以及 `packages/{guard,compaction,spill,goal,deliverables,sdk,acp,mcp}/README.zh.md`。
- **网上流传的“日活 154 万、第三方插件 3.49 万、94.7% 插件高危权限”等数字，Claude 在官方仓库和文档里都没找到，不能当事实引用。** star 数各第三方站点说法不一，也不要引用。

### 隐私：联动前必须知道

`docs/deepseek-llm-api-wire-extensions.zh.md` 写明：dsh 用 DeepSeek 官方接口（`deepseek-official` 适配器）时，请求体里的 `dsh_session_log` 扩展**默认启用**，会把会话日志后缀随请求发给 DeepSeek，可能包含工作目录、系统提示词快照、用户与助手内容、工具结果。文档说可以通过组合配置禁用。任何联动方案、给用户的使用说明，都必须先说明并关掉这个上传。

## 五、联动方案

- **推荐：未央把自己的工具开放成 MCP 服务。** 天气、赛程、公文体检、生成 Word/PPT 等以 MCP 服务形式暴露，dsh（ACP/Web 都能挂标准 MCP）及其他 MCP 客户端可直接调用。数据留在用户自己的服务器上。需要：访问鉴权（沿用服务器访问密码或单独令牌）、每个工具的权限声明与最小授权、用户/会话隔离沿用现有做法、输出有界。预估改动中。
- 不推荐现在做：
  - 让未央当 dsh 的“OpenAI 兼容模型端点”：dsh 只能把未央当转发模型的通道，未央自己的工具用不上，价值低。
  - 电脑版未央以子进程方式驱动 dsh 跑编码任务（sdk/acp）：安卓用不了；dsh 还在不兼容地改版，接上容易被它更新弄坏；体积大。
  - 把未央工具写成 dsh 专用 Cordis 插件：有 MCP 这条标准路就不需要绑定它的私有插件格式。
