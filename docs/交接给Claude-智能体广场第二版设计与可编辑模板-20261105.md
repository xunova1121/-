## 视觉规则

- 白色主底；仅标题介绍区使用淡蓝到淡紫渐变。减少整屏彩色底、大圆角卡片叠套和重复吉祥物。
- 手机页边距 20px；标题栏 66px；正文 14–16px，辅助信息 12–13px。模板两列，作品保持完整比例，封面标题不能裁切。控件高度至少 44px。
- 广场采用作品推荐 + 紧凑能力列表；PPT 与海报用预览展示能力；健康/研究用简短介绍和三条起始问题。
- 手机继续单行输入，模型默认隐藏；不新增底部导航。创作页底部只固定一个主操作；必须为底部按钮、软键盘和安全区留出空间。
- 桌面保留侧栏，内容居中；不是把手机卡片无上限拉宽。夜间沿用同一层级，模板预览保持真实颜色。
- 图标和原型海报为原创视觉示意，不使用参考应用的品牌、截图、作品素材。

## 模块行为

| 页面 | 本稿设计 | 正式接入要求 |
|---|---|---|
| 广场 | 搜索、分类、作品推荐、能力列表、我的智能体 | 接现有注册表；保留返回后的筛选；真实加载/空/失败状态 |
| PPT | 主题、资料、页数/场景/语言、样板预览 | 保留所有表单；选样板不自动发任务；支持原生文件导入 |
| 模板预览 | 全部页缩略图与来源说明 | 直接用本次真实 JPG；不要用原型海报/示意图顶替 |
| 公文 | 文种网格、润色工具、写作要求 | 复用现有 Word 工具和文种规则，原型不得绕开资料核对 |
| 海报 | 灵感作品、创作表单、风格和尺寸 | 展示有权使用的真实素材；配置缺失与生成失败明确可见 |
| 图片处理 | 前后效果示意、上传、输出范围 | 先实现已配置能力；没上传不能开始；原文件保留 |
| 健康/研究/天气/行情 | 专属介绍、三条建议、单行输入 | 推荐只填输入框；复用真实查询及来源/时间回执 |
| 图片转文字 | 上传、输出目标 | 复用现有 OCR；先核对结果再导出 |
| 我的智能体 | 名称、步骤、排序、保存 | 继续原计划步骤6/7，接现有任务/定时系统，不另造执行器 |

原型中的分类、风格切换和部分上传按钮仅是交互示意；有文字提示，不伪装为生成成功。用户新增的两套 PPT 已在真实模板库接入，不只存在于设计稿中。

两套用户参考版不复制原始公司标识、正文、真实数据、地图、照片、视频或链接；图片区域是可替换原生占位框。它们不是原 PDF 的无损转换，也不宣称素材获得 MIT 授权。原上传文件未进入仓库。用户附件另提供 PPTX/POTX/全页 PDF 和填写示例。

四套开源适配参考 `hugohe3/ppt-master` 固定提交 `f3633771fe699d327f02ae86393831bbcf5169f7` 的通用布局；保留 MIT 许可到 UI 与每页备注。没有复制其品牌文件夹。网上其他模板站和来源不明的 WPS 模板未打包。

新资源入口由 `pptSourceGallery.js` 提供；`pptSourceImport.js` 负责导入。云模式上传到捕获的本人客户端，失败不落到本机；本地模式使用工作区返回的实际文件名。导入前后校验会话、服务器连接和身份；切换后不改新对话草稿。导入仅填草稿，不发模型请求。用户补充要求后发送，原生文件编辑能力复用已有文档工具。
