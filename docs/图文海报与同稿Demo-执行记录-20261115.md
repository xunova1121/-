# 图文海报与同稿高清 Demo

2026-11-15，北京时间。用户已批准完整方案并明确要求“开发，发版”。以已发布 1.0.437、d5b6f4f 为基线，fetch 后远端没有新增提交。发布结果在完成后补记，不把开发完成写成已上线。

## 已实现

- 新稿使用 `make_poster.design` / `create_visual_demo.design`。按内容起稿（编辑新闻、温暖纪念、数据看板）或 `layout=free` 完全自由安排最多160个文字、形状、图片、矢量图标、折线图层。起稿输出即普通可编辑图层，没有锁定模板槽位；横版重新构图，手机不缩小整张4K图。
- 同一份 `.design.json` 编译 PNG、自包含 SVG、PPTX；补 Demo 复用同一源稿并输出离线 HTML、ZIP。文字/卡片/图表线段为原生 Office 对象，图标为独立矢量图片，照片独立；不能声称所有对象都可在 Office 中逐路径编辑。字体不嵌入，其他设备替代字体可能改变显示。
- 文案原样保存，黑体/宋体使用真实中文字体。保守换行和字号适配不省略文字、不横压字形；溢出在出文件前拒绝。逐项检查源文案与实际 SVG、文字边界与重叠、中文字体实际字形、PNG真实像素、无字背景渲染后的实际像素对比度。
- 有既有 `visionLlm` 配置时，对实际 PNG 只核验一次；先扣模型预算，禁止联网和自动重试。只允许完整布尔回执认定通过；看不清、服务失败或未配置为 `not_checked`，有疑点为 `failed` 并保留候选。没有独立OCR结果，不把程序排字称为OCR通过，也不承诺文案事实或错别字绝对正确。
- 图像模型仍沿现有 `generate_image` 配置生成需要的无字视觉素材；原图优先。用户明确要求 GPT 直接画整张带字海报仍保留图片路线，不冒称生成文字必定正确。不自动为改字重新付费画图、切模型或放大。
- 素材读一次，使用同一份原字节做摘要、格式/尺寸核验和编译；源文件和图片保留，编辑/重新构图另存。源图同路径或路径别名换过字节不能假复用。ZIP中的源稿使用相对 `assets/` 路径，摘要与真实原件对应。
- `changes` 按稳定图层ID改字、坐标或颜色；`source_path+design` 可重新构图，默认提取原栏目/素材；不能只手改SVG后遗漏PNG、PPTX和JSON。换画幅同时指定构图，防止简单拉伸旧稿。改过的字不被旧数据快照悄悄恢复。
- Demo实际支持关键词、分类、详情、图片图层开关、用户明确提供的最多4组数据快照、初始PNG原字节下载、当前SVG/源稿下载。手机将内容与图表重排为可读卡片，正文至少16 CSS像素；不把看板图烘焙成唯一背景后伪造按钮。
- 原metrics/series/alerts可转换为明确的独立图层；混传两份内容会拒绝而非静默漏掉。没有数据就明确示例；provided要求来源说明，仍不等于已联网核实。地理边界/坐标不擅自生成，旧气象地图合规路线保留。
- 4K仅表示核对过的3840×2160画布。每张素材单独记录原始像素、缩放倍率及是否放大，不把1536素材放大称为原生4K细节。没有更改原件分享、图片编辑、声音、账号或更新签名。

## 边界与兼容

新模块均在 `jarvis/src/agent/layeredDesign*.js`，没有新依赖或插件架构、Python运行时、jarvis.env、数据目录或app ID变更。旧 `.poster.json`、`.visual.json`、实色/渐变海报和大屏接口保持原实现。工具Schema仍按制图任务加载，不把长Schema加进普通聊天。

新源稿最多180KB，文字最多12000字，素材最多4份/累计10MB/2500万像素；画布最长4096且不超过1600万像素。原SVG静态白名单、6000元素和真实图片解码边界不放宽。HTML最多60MB、ZIP最多80MB；超限保留已生成格式并返回部分交付。所有文件写后逐字节读回，停止与费用预算异常继续向上传递。
