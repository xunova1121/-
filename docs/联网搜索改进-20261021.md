# 第2项：免费搜索与官网原文读取

基线：16e13791c3c7c95f1cf8880a83e470f6d3427e30。只处理搜索，不修改回答风格、模型分工和文档流水线，不新增依赖或付费搜索接口。

## 请求和证据

- 中文查询首轮并发必应RSS和百度；即使RSS有4条也合并百度。结果不足再补必应网页及地区内备用源，合并网址、去掉追踪参数，同址去重，已识别官网优先。
- 同一个查询词换搜索源不重复消耗逻辑搜索次数；增加`site:`限定是新搜索词，在请求前扣预算。物理HTTP请求数仍可能比逻辑搜索数多，不能把逻辑预算当费用或网络请求计数。
- 机构、政策类请求最多增加3个不同的官网限定查询；已有`site:`不再递归。支持政府域名、已登记机构域名和7个省市的限定词映射，未登记的协会或企业官网不会仅凭标题得到官方认证。
- 单源8秒（包括正文和一次可取消的网络重试）；同一搜索器最多4个源在途、64个排队，单次查询内2路并发。取消的排队请求不会后来偷偷发出。
- `fetch_url`直接读取20秒；正文最多8MiB，网页正文6万字，缓存仍60条。返回最多30条栏目/详情/附件链接，明确链接内容尚未读取；长正文给链接预留位置。
- PDF复用现有解析器，网络PDF最多80页/6万字，扫描件没有文本时明确失败，不把页码当正文，不宣称OCR。用户主动读取的工作区PDF仍沿用原规则。
- `fact_check`只有实际读取的正文（不含链接列表）中能找到引用，且域名被识别为官方，才允许单源标“已核实（官方原文）”。摘要、伪装域名、编造引用和存在冲突的来源不能得到该状态；其他来源仍沿用双站规则。
- 证据只在EvidenceStore保存有界片段与`original`布尔标志；旧记录缺标志不升级成原文。仍按任务sessionId隔离、1秒合并写盘，不把网页正文放入对话或检查点。
- 明确逐项核验/查原文使用3分钟、20次逻辑搜索、16次读取；普通查询仍45秒，普通对话总截止60秒，普通研究/文档仍8分钟。时间从首次联网算起；这些是可用上限，不要求耗尽。核验无结果前安排至少3种不同搜法，预算或停止中断会向上抛出，不能假称已穷尽搜索。

## 验证和限制

测试覆盖中文并行合并、网址去重/官网排序、site前置预算、排队取消、响应字节上限/取消、链接数量与保留、真实PDF提取和空白PDF、单官方正文/摘要/伪装域名/冲突/编造引用分级、原文标志写盘读回、普通与核验预算区分。

既有测试的变动仅对应新行为：中文调用顺序改为RSS+百度后再补其他源；RSS四条不再只请求一次；失败提示不再鼓励购买博查；直接读取的假时钟从8.5秒改到20.5秒；预算测试名称不再把逐项核验称为8分钟。结果内容和停止信号断言保留，没有删除或跳过测试。

本环境公开网络观察：经配置的代理跟随跳转，必应和百度最终均HTTP200；必应返回搜索首页（0个RSS item），百度返回“百度安全验证”。这不是成功取得机构原文，也不代表国内服务器表现。直接Node fetch未使用代理时ECONNREFUSED是本环境网络路径限制，不记成网站故障。

尚无服务器登录会话，未运行用户配置的真实DeepSeek模型；不填造30题提速、通过率或gov题改善数据。必须在服务器包含第1、2项后，由宝塔执行同一题集并逐检查点复核。也未进行鸿蒙/Windows真机测试。自动CI和本环境公开网络观测均不能替代这两项验收。

## 下一步的真实对照

仍使用baseline-30-v1固定题面和baseline-rules-v2规则，匹配同一服务商/型号/执行位置与评测隔离方式。先核对服务器已包含本次代码与第1项的评测写隔离能力，再执行30题。重点复核baseline-05~10的具体日期、文章原文、比分/股价和机构职责/公开指南，不能拿“返回了链接”代替答案正确。

报告只比较同规则、同评测执行方式的数据；旧报告缺字符和辅助调用指标时留空。准确率必须逐题完成语义审查后再算。若出现已经通过的题目退步，先修回归，不继续第3项。第3项再单独处理提示词和工具说明精简、普通问答去验收、文档重复润色调用合并，避免搜索变化和提示词变化无法归因。
