# 未央全息陪伴

用户已批准 PC/手机概念图开发及自主推送发布。沿用当前数据、模型配置、Windows 与 Android 包名；不新增依赖。

- 共用 `hologramScene` 二维角色场景，最新蓝金色角色、远山湖面背景、摸头光圈、连续点击害羞、比心、45 秒闲置打盹、文字动作指令与聊天。用户文字通过 textContent 展示；角色与输入区分开布局，键盘出现缩小角色。
- 应用内：点击未央头像 → 全息陪伴。保留原表情/语音面板；完整对话回到主对话。模型回复和历史记录沿用主智能体，不开第二套模型会话。关闭场景不打断任务，停用场景动画与观察器。
- PC 桌面：开启设置中的“全息陪伴桌面”，静态远景挂桌面图标后，透明角色窗口接受点击、文字输入。空白区域通过主进程命中区域轮询穿透；不强制置顶。拖动顶部可移动窗口，设置可改角色大小。锁屏/休眠隐藏，恢复重新显示。跨窗口文字请求带 ID，完成后同步回卡片；错误可见，主窗口已有任务时拒绝新请求而不打断。
- Android：全息陪伴右上角设置 → 设为手机动态壁纸 → 系统预览确认。原生 WallpaperService 使用已有角色图集绘制，不启动 WebView、不联网、不朗读、不使用麦克风；不可见停帧，闲置/兼容模式降帧。触摸角色回应，“聊一会”打开应用内全息聊天（不是系统桌面浮窗输入）。不要求悬浮窗权限。
- 没有连接用户 Windows/HarmonyOS 4.2 真机；Windows WorkerW 图层、透明命中和鸿蒙启动器是否向壁纸转发触摸，需要实机验证。系统不开放动态壁纸预览时保留应用内陪伴并显示解释。

验证要求：新增命中区域/生命周期单测、原生绘制策略单测、手机实际移动构建与键盘检查、真实 Electron 跨窗口聊天检查；保留全部既有测试。发布由完整验证任务、Android 与 Windows 构建全部通过后执行。
