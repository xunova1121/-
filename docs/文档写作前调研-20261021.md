# 第4项第一批：重要文档先调研再写

基线bdc71809e77bd8f1a08d9b8da33432c9c3c3c1d8。仅增加专业文档的前置调研和证据引用；审查模型分工、写作偏好、新模板与界面不在本批。

## 工作流

专业文档expert且尚未生成底稿时：保存待调研阶段 → 免费检索 → 读取实际原文并存EvidenceStore → 保存来源清单 → 底稿/推演 → 起草 → 审查/修订。

- 最多两轮，每轮两个主题查询、读取最多三篇；共六篇。主题只由任务抽取前80字，去掉常见密钥/密码/令牌、邮箱、网址及长编号；不上传参考文件正文，不保存查询正文。它是常见凭据清理，不宣称能识别所有敏感信息。
- 只复用现有免费搜索和网页/PDF读取，不使用已配置的博查/Tavily付费接口，不增加模型调用。搜索源内的官网限定仍按新的逻辑词计预算。
- 包含证据缓存读取在内，调研总时限180秒，内部最多16次逻辑搜索/12次读取（包含重试）。两路原文并行、原搜索队列上限保留。请求前扣父任务预算；父RETRIEVAL_BUDGET和AbortError必须抛出。局部调研限时或限次则保留已取得资料继续写，不绕过父任务预算。
- 结束时向在途工作传递取消信号；忽略停止信号的迟到读取也不能再发业务请求、追加清单或写正文。旧网络地区探测不接收signal、单独最多等待3.5秒；不能宣称所有平台传输都瞬时终止，真机传输取消未测。
- 搜索摘要不是资料原文。成功读到的正文去掉页面链接列表后，存进原EvidenceStore（每篇6000字、每会话12篇等原上限）。流程状态只保存编号、网址、标题、采集时间、次数和用时，检查点只记阶段文件路径。
- 收集器用文档流程id为key、用这一轮sessionId隔离，恢复时可复用已有证据。来源URL≤2000字、标题≤300字，每次给模型最多六篇各1800字的片段；不会把整页或参考文件重复塞进对话。
- 原文片段放在模型的资料输入，明确不是指令/用户事实/已核实结论；底稿、起草、审查、定点修订均可用。要求正文就近标注来源编号与链接，数字和接口能力不能超出证据支持范围；缺资料说明影响的判断，建议标前提。
- 读取原文时还核对original标志、URL与文档key；同址缓存被其他工具覆盖成摘要或其他文档资料时不冒充原文。缓存过期/丢失时不伪造原文；没有资料照样可写用户事实与明确标注前提的建议。没有网络适配器不暗中改用不受控的直连；结果说明调研not_run或unavailable。简单任务不启动调研；新增research布尔参数，research=false不调用网络适配器；常见离线措辞也会被拦截。用户明确不要联网或仅依据附件材料时，自动调研必须跳过，不能扩大授权。
- 阶段timings保留最多20次模型调用+1个调研阶段，清单另有elapsedMs和counts，不能把这些逻辑计数当实际HTTP数或费用。
