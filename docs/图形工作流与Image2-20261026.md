# 图形工作流与GPT Image 2（2026-10-26）

## 能力边界

本轮强化精确分层架构图、已有SVG的渲染和检查、创意图片生成与原图编辑的API通路。不声称已经实现时序图、ER图、任意拓扑的专用排版，亦未实现原生PPT图形导出或自动消除所有交叉连线。分层图仍交付原生SVG；PNG用于查看与复核。识别模型、画图模型来自用户当前运行位置的配置，未迁移任何私有模型权重。

## 文件与渲染

- imageFormat按文件头识别PNG/JPEG/WebP及SVG，写文本工具不能伪造位图，SVG不能只改.jpg后缀。旧误标文件保留，复核、服务器read_file及浏览器附件准备能从真实内容转换。
- svgPreview验证自包含静态子集：最多2MB/10000标签、原画布2500万像素；禁止脚本、事件、外链、实体、动画等。浏览器使用Image与Canvas，最长15秒，预览最长边2048，PNG输出12MB以内。复杂SVG超出子集会明确失败，不声称支持所有SVG。
- 云端固定参数依次使用已有rsvg-convert、ffmpeg；两者缺失/不可用时复用原部署已提供的LibreOffice。无新npm依赖、无新收费接口、无另装浏览器。系统组件皆不可用时仍交源图，明确渲染未完成，不把展示SVG当视觉验收。
- 新render_diagram只读取模型明确传入的工作区路径，不自动挑最新文件，另存真实PNG；inspect_image也可直接对SVG或误标JPG执行渲染后检查。回执带sourcePath/sourceHash/previewPath，检查期间源图变化则旧预览不能作为新版验收。
- 用户明确给出文件路径时拦截明显换文件；“先前那个”有多候选仍依赖对话定位与必要追问，不声称程序能自动完整消歧。模型收到的任务提示要求先定位版本，不能因新旧文件名称相似擅自替换。

## 架构图布局

保留最多8层/60节点/100输入边、原生文字与形状、底层支撑在下及核心强调。改为层级标签在左、卡片内容在右，标题与层级副标题分开，按真实行数收紧高度，中文末行不孤留一两个字。相邻行在行间走线，远距离连线占右侧独立通道（最多16条，超出明确要求拆图），重复关系去重；不再统一绕左侧x=44。不传节点级边时，只表达层间支撑，不自动生成全连接网。

diagramReview复用新旧图预览流程：真PNG格式→写入→字节读回→最多一次已配置视觉模型审查。检查结构、渲染、视觉、业务状态分离；摘录匹配仍不等于业务全核实。发现问题交还主调度按指定文件修改再复核，未新增一轮独立自动重画，更不通过反复收费生成补状态。

## 创意图片与GPT Image 2

用户在“模型→能力→画图”选服务商及完整型号gpt-image-2；本机和云端仍各自配置，未强制替换原模型。画质/格式/背景参数在电脑能力表、手机折叠“画图参数”中，留空不发新参数。高画质可能增加耗时和费用，不自动开启。

生成使用/images/generations，原图编辑使用真实multipart /images/edits。支持auto或标准尺寸；GPT Image 2支持16倍数、宽高比1:3至3:1内的自定义尺寸，本程序限制最长边3840且总像素不超过3840×2160。支持low/medium/high画质、PNG/JPEG/WebP、透明/不透明背景；透明与JPEG互斥。未向Image2发送input_fidelity或旧response_format。其他型号不默认塞GPT专用参数。

API响应40MB、图片20MB上限，下载不带服务商凭据，服务器沿publicFetch防护。实际图片头优先决定MIME及保存后缀，SVG/HTML不能冒充位图。一轮请求与下载最多4分钟；预算在请求前扣，停止/预算上抛。只有明确拒绝的生成才可沿原备用配置尝试一次；超时、5xx、结果未知、下载失败不重提。编辑仍只提交一次，不退化文字重画。

接口参数依据核对于2026-10-26：

- [GPT Image 2模型说明](https://developers.openai.com/api/docs/models/gpt-image-2)
- [生成API](https://developers.openai.com/api/reference/resources/images/methods/generate)
- [编辑API](https://developers.openai.com/api/reference/resources/images/methods/edit)

接口参数和付费服务的实际可用性不同。尚未用用户真实密钥调用Image2、视觉审查或OCR；不能把假接口协议测试当实际画质或识别准确率验证。

## 验证与兼容

新diagramQuality/image2单元测试覆盖格式、真PNG、旧图路径、源图并发变更、失败留存、控制信号、预算前置、参数及不重复生成。新增diagram-render真实浏览器像素与服务器PNG检查；Office旧E2E增加SVG真实转PNG；模型工作台增加本机/云端画图参数隔离，不移除旧断言。

旧diagram测试的渲染假数据原为字面fixture，无法满足新增的PNG文件头校验；改成真实一像素PNG的Base64，并保留“模型收到同一数据”、视觉失败留存、调用一次等原断言，未放松门槛。模型E2E新增测试曾误将本机提示中“任务在云服务器上做”当云端配置选择，已改核对实际aria-pressed，且等待保存后的旧节点脱离，不改原生产切换规则或旧断言。

完整冻结回归与CI结果见交接文档。真实付费模型、鸿蒙/Windows真机、生产服务器未验证。用户原图和对照图不提交公开仓库。
