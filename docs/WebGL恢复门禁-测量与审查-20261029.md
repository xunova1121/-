## 改动与边界

- `stage.js`：尺寸相同不重分配 canvas；恢复后立即绘制真实当前场景，前三帧不等帧率限额，随后恢复原上限；隐藏或离屏仍不画，保留恢复代次取消保护。
- `orbitHud.js`：复用最多 8 个卫星节点，状态变化才重建；锚点未变不重复布局，不重写相同文字。
- `callouts.js`：先读高度再布局，相同输入不重复写 SVG。
- `styles.css`：恢复期暂停舞台标注动画，第三帧后恢复；工作台顶栏和输入框的背景已是不透明白色，移除两处没有可见贡献的 backdrop-filter。半透明舞台标注的原模糊保留。
- `e2e/webgl-recovery.mjs`：20 次逐次断言，没有重试取最好值；增加 8 次真实工具执行、卫星节点复用、恢复期动画、恢复后省电帧率和隐藏恢复检查。capture 计时从 Three 之前开始，防止同步首帧移出计时。
- `jarvis-unit.yml`：手动 `webgl_only=true` 只做测试、权限 contents:read，无安装包或发布任务；保留原 smoke 全部断言，并额外跑连续恢复。

不改点数、点尺寸、绘图分辨率、正常 FPS 和画质设置。不改架构图、搜索、表达、持仓和提醒。无稳定收益的 context 参数更改、颜色计算更改、HUD 强制合成层与恢复期 JS 冻结均已撤回。
