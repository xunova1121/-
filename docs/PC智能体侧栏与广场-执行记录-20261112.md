# PC智能体侧栏与广场（2026-11-12）

用户在招投标自动更新开发收尾时要求：PC智能体移到左边栏，重新整理UI。本项与招投标资源中心同批发布，手机广场不改。

## 设计与实现

- 智能体成为左栏一级入口，位于新建对话之后；顶栏保留对话/工作室原切换，广场打开时显示位置提示。
- PC广场从遮住侧栏的居中浮层改为右侧主内容页；左栏仍可切换文件、技能、历史与设置，页面与折叠宽度同步。
- 白色内容区、浅灰蓝侧栏、蓝色选中态，原创统一线性图标。顶部标题、搜索、分类；大屏四列卡片，中窗三列，窄桌面双列。卡片保留实际能力状态与收藏，个人创建、作品、模板、团队、品牌和流程入口继续可达。
- 手机仍使用原布局和原组件；PC只调整组装与样式。进入广场/文件空间不卸载原对话，不清空输入草稿；返回保留原搜索和分类。
- 600px高窗口压缩导航间距，四条最近对话、查看更多与设置均可见；标题栏区域与更新按钮保持独立，不被内容页遮住。

- Vite实际预览五组60/60：1440×900、1280×820、1024×600、760×700、1280×720标题栏布局；覆盖侧栏归属、选中状态、换页草稿、搜索保留、折叠、选智能体、程序入口、更新按钮与页面错误。
- 标题栏检查为浏览器布局模拟，不是Windows真机。新增e2e/pc-agent-navigation.mjs接入原发布工作流，旧测试未删改。

- 实际渲染：[1440宽桌面](screenshots/pc-agents-20261112/agents-1440-900.png)、[1024×600小窗口](screenshots/pc-agents-20261112/agents-1024-600.png)。人工查看了侧栏、四条历史与查看更多、卡片层级、标题栏间距。
