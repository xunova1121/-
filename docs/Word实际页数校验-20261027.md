# Word实际页数校验（第2批后续，未发版）

在原件保留931a0e1的完整CI通过后实施。目标是避免生成Word就声称页数达标，尚不是自动分页排版器。

## 行为

- 从本轮明确Word/docx要求识别总页数、最多/至少、范围，支持常用中文数字。页码引用、近似页数、混合PPT/Excel以及正文另加封面的歧义不强行猜总数。正文标题后的数字不作为排版指令。
- 以Office实际转换PDF后解析的页数核对，包含整份文件的封面和目录。不以DOCX缓存页数、字数或标题数代替。
- 不符合时保留文件与原文，报告实际/目标页数并记错误；无有效PDF时独立记为not_checked。两种情况均不缓存成功或输出“不必再核对”。
- 短文、长文、专业文档、原件套版以及编辑入口共用交付检查。编辑后重新核对当前要求。未增加模型调用或盲目重试，也不靠删文缩字凑页数。
- 尚不覆盖复杂“正文若干页另加封面”的合成约束；不宣称自动满足任意页数和字体要求。

## 验证与原测试修正理由

新增4项单测覆盖页数解析、有效PDF页数不符/不能复用成功缓存、无渲染状态、实际PDF范围/用户要求优先和编辑后重新检查。原PPT六项测试保持全部断言，特别五页PPT和六页PDF的不一致门槛不改。

实际e2e/document-file-source.mjs额外要求Word总共1页并断言真实PDF页数通过，原有非样式ZIP部件逐字节保持、原件不改、PDF文字与图片断言全部保留。真实Office本地通过，lint通过。定向最终结果及完整CI另记。

309暴露原sportsScores测试用“当前时间+1小时”的假比赛，在北京时间23点后落到明天，与问题“今天”冲突。只把测试Date固定在原有NOW日期，真实定时器照常运行，所有原断言保留；不是调整生产时间或放宽测试。
