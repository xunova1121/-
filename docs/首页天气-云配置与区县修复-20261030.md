# 首页天气修复（2026-10-30）

用户确认反馈来自安卓客户端，未确认当前版本。此前 1.0.339 的缓存视觉测试不能证明云配置连接正确。

## 已核实原因

首页 `createWeatherClient` 只读取本机 `loadConfig`，没有跟随 `app.server`；天气 Key 仅在服务器时就选成 Open-Meteo。系统定位插件只取城市、取不到写“附近”，没有区县信息。已有“把云 Key 复制本机”的补丁会破坏配置隔离，且不能解决其他设备上的已有 Key，因此移除该同步。

## 改动

- 从 `src/app/homeWeather.js` 接线，云端用现有服务器登录凭据请求天气与 Geo；本机模式仍按本机设置。服务器补天气接口 CORS，原 `/api/*` 登录门禁保持。
- 缓存按服务器地址隔离，忽略旧本机回退缓存；服务器代理按和风配置指纹隔离。保存 Key/Host 发出刷新通知，Key 不跨配置位置复制。
- 首页显示区县，详情保留“城市 · 区县”；旧“附近”先改“当前位置”，等待真实区县解析。保留粗略定位；Android 系统返回优先，和风坐标查询补齐，四秒结束，换城市取消旧解析。未解析不编造区名。
- 无配置仍显示真实基础天气，但注明来源和缺项、提供进入当前运行位置模型中心的入口。登录失败/云端天气失败给出明确提示。
- 不改首页短屏尺寸和原有门禁，不新增依赖。
