## 交给 Codex 的事项

1. **改到哪个文件就格式化哪个**：运行 `npx prettier --ignore-path /dev/null --write <文件>`，并把它加进 `jarvis/.prettierignore` 白名单和 `npm run lint` 的 prettier 列表。不要一次性格式化全部（会和进行中的改动大面积冲突）。
2. **`npm run lint` 现在覆盖全部源码**：新写的代码会被查“没定义的变量、未用变量、重复定义”等，提交前务必跑。
3. **`CLAUDE.md` 开头规则**：发版后只更新那 4～5 行“当前状态”，详细记录写 docs。
4. 可选：`make_poster`、`create_visual_demo` 的参数说明偏长，若要精简，必须先有对照测试证明模型调用质量不下降。
5. 节奏建议：5 天发了 25 个版本、海报来回返工十几次。一次只做一件事，先在本机跑 `node scripts/release-gate.mjs` 再发。
