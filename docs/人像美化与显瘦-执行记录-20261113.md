# 人像美化与显瘦（2026-11-13，开发及验收中）

用户追加要求：给未央图片智能体增加人像美化、P瘦/显瘦能力，并保障修图质量。1.0.432候选因企业首屏原验收被拦，未发布；本功能先在独立工作区开发，最后与首屏修复合并统一验收发下一版。

## 原因与改动

- 界面原来有“人像优化”，`process_image` 实际只有抠图、证件照、修复和清晰化四种任务；不能靠改一句提示就宣称已能美颜。现在增加 `portrait_retouch`（自然美颜）和 `portrait_slim`（显瘦），由现有已配置的 `/images/edits` 原图编辑接口执行，不调用文生图代替，不改变现有密钥与服务商。
- 默认自然力度，可按用户明确要求选择适度/增强并指定部位。保留五官外观、年龄特征、服装、姿势、背景和构图；不自行减龄、换脸、瘦脸。编辑使用工作区原片字节，结果用独立随机文件名另存，保存后逐字节读回，报告实际像素/格式，不把请求4K当实际4K，不通过压缩或自动重生成冒充成功。
- 有看图配置时，原片与结果最多进行一次25秒视觉对照，禁用联网及辅助模型内部重试。检查外观、皮肤、人体比例、背景衣物伪影及请求变化是否实际可见；字段缺失、未知、错误、回执过长不算通过。没有能力/对照失败/有问题均保留候选并如实标注，不自动再次调用收费修图。模型视觉检查不是身份鉴定或绝对保真证明。
- 复核时遇停止/评测额度/检索预算仍向上抛控制信号；已保存的付费候选保留，预算回执附有界路径和像素信息，不丢结果后重画。
- “图片处理”选择人像操作时只留相关操作与原片入口，不要求海报文案、尺寸和风格。表单默认值不夹进修图要求；明确的P瘦原话优先于旧海报设置。仍要做海报的复合任务保留海报参数。
- 补充原片追问、创作意图及长任务判定，修图不误套普通查询的60秒/三次辅助调用；`process_image` 作为产出工具，联网结束后仍可做本地交付。原搜索读取预算、普通问答、取消和照片四种旧处理保持。

## 验证与边界

- 阶段定向54项已过，另有原片multipart编辑适配器与自然语言智能体完整链路通过。新增“默认参数不过度传入”和手机全流程继续验收中，最终门禁结果另记。
- 图片夹具由真实PNG压缩像素与CRC生成，视觉/图片服务返回为明确替身；验证数据链路、预算与交付，不冒充真人效果。旧图片处理和智能体断言保持（包括未知任务仍拒绝），不新增依赖。
- 原片支持PNG/JPEG/WebP且不超过10MB；双图合计超过20MB时不压缩后冒充原图核验。具体编辑能力和分辨率仍取决于当前服务商。没有使用用户真实Key或真人原片，尚未真机与付费模型验收。
