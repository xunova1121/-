# 渔政执法 AI Agent 演示页

`agent-demo-offline.html` —— 单文件，双击浏览器打开即可演示。

- **图标、图表、实景图全部内嵌**，页面对外零静态资源请求，断网可跑完整演示
- **对话接入阿里云百炼**（DashScope，OpenAI 兼容模式，`qwen-plus`，流式输出）
- **接不通时自动回落**到内置离线剧本，演示不会卡住；头部状态胶囊会显示当前模式
- **全流程语音播报**：从发现预警到闭环总结共 9 个节点，带提示音与底部字幕

---

## ⚠️ 关于 API Key

演示页里 `AI_CONFIG.apiKey` 是**明文写死在前端的**。这意味着：

> 任何拿到这个 HTML 文件的人，都能直接读出密钥并拿去跑你的账单。

这么写只是为了让单文件演示能直接双击运行。**对外发放或部署前，请务必改走代理**
（见下节），把密钥留在服务端。如果这个 key 已经外发过，建议在百炼控制台轮换一次。

## 用法一：直连（内部演示）

双击 `agent-demo-offline.html` 即可。

浏览器直连 `dashscope.aliyuncs.com` 是否放行跨域，取决于阿里云当时的 CORS 策略；
用 `file://` 打开时请求头里的 `Origin` 是 `null`，被拒的概率更高。**如果头部胶囊显示
"离线演示模式"，鼠标悬停能看到具体原因**，多半就是 CORS，改用下面的代理即可。

## 用法二：走本地代理（推荐，且密钥不落前端）

```bash
export DASHSCOPE_API_KEY=sk-xxxx
node proxy.mjs                     # Node 18+，零依赖
```

再把页面里的配置改两行：

```js
const AI_CONFIG = {
  apiKey : 'unused',                                    // 密钥已收回服务端
  baseUrl: 'http://127.0.0.1:8787/v1/chat/completions',
  ...
};
```

代理是流式透传的，逐字输出的效果不受影响。

## 对话是怎么工作的

不是把问题直接甩给大模型，而是先在本地做一次检索再送进去：

```
用户提问
  → retrieveContext()   在本地法规库(6 条)/案例库(4 条)里按关键词打分召回
  → buildSystemPrompt() 把召回结果 + 今日态势数据拼进 system prompt，
                        并明确要求"只能引用检索结果里的条文，不得杜撰法条"
  → streamBailian()     SSE 流式生成，逐字渲染
  → renderRagCards()    召回的法规/案例渲染成带相关度的卡片
```

这样模型编不出不存在的法条，页面上"RAG + LLM"的说法也名副其实。
调不通时 `offlineReply()` 接手，本地检索照跑，只是回答换成内置文本。

多轮上下文保留最近 6 轮，点"重置"或"新建对话"清空。

## 语音播报

用浏览器自带的 `SpeechSynthesis`：零延迟、不联网、不需要额外的密钥或音频文件。
播报的同时底部会显示字幕条 —— 会议室音箱不给力时，至少字幕能看清。

播报节点（共 9 处）：

| # | 触发时机 | 内容 |
|---|---|---|
| 1 | 发现预警 | 注意，太湖东区二号摄像头发现违规垂钓预警，置信度…（带提示音） |
| 2 | 进入摄像头 | 已接入太湖东区二号摄像头，开始目标识别。 |
| 3 | 锁定目标 | 已锁定目标，违规垂钓，一人。 |
| 4 | 拍照取证 | 正在自动拍照取证。 |
| 5 | RAG 研判 | 正在进行法规研判，匹配渔业法第三十八条… |
| 6 | GIS 调度 | 就近调度苏渔政零零一号执法艇，距离一点二公里… |
| 7 | 派发工单 | 工单已派发。 |
| 8 | 电话调度 | 正在呼叫苏渔政零零一号，船员三人。 |
| 9 | **预警总结/闭环** | 执法闭环完成。本次处置共耗时 N 秒…（带提示音） |

- 对话框头部的喇叭按钮可随时开关；关闭会立即掐断正在播的那条
- 每条 AI 回复下方有「朗读」按钮，可单独播放
- 提示音是 WebAudio 合成的两声"叮咚"，不依赖音频文件

**几个环境上的注意点：**

- 语音需要用户先与页面交互过（浏览器的自动播放限制）。正常演示流程是先点
  「启动演示」，已经满足；如果用控制台直接调函数可能不出声。
- 中文发音质量取决于**操作系统装了哪些语音包**。Windows 10/11 与 macOS 自带中文
  语音；部分精简版 Linux 没有，届时只有字幕条没有声音。
- Safari 对 `speechSynthesis` 的支持较旧，建议用 Chrome / Edge 演示。
