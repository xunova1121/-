# V1.8 GitHub 产品研究与落地记录

本轮调研日期：2026-08-27。目标是学习公开项目的产品流程与工程经验，不复制第三方实现。

## 重点项目

- Alibaba LumenX（MIT）：Pipeline-first Studio 与独立 Playground；实时模型目录、并发任务、Prompt 历史、画廊视图。
- ArcReel（AGPL-3.0 + NOTICE）：可审核、可恢复、可回滚的生产流水线；成本追踪、单素材重做、剪映草稿交付。仅学习产品流程，不复制代码。
- MoneyPrinterTurbo（MIT）：主题到文案、素材、字幕、配音、合成的一键短视频链路。
- NarratoAI（许可按仓库声明）：视频理解、脚本重构、素材匹配与解说成片。
- VideoLingo（Apache-2.0）：步骤级暂停、恢复、停止；详细进度日志；服务商模型搜索与自动拉取。
- Toonflow（Apache-2.0）：资产、画布与生产节点统一组织，多平台桌面交付。

## 对当前产品的判断

本项目后端已经具备持久化任务、租约、指数退避、取消、重试和崩溃恢复，短板主要是桌面端没有充分暴露这些能力。继续增加后台概念的收益低于把现有能力做成用户可见、可操作、可诊断的工作台。

## 本轮已落地

1. AI 生成服务商切换后，实时读取该服务商与当前能力匹配的模型目录；仍允许手工填写 Endpoint ID。
2. 模型读取与提交过程均有明确反馈，旧请求不会覆盖较新的选择。
3. 生成任务每两秒刷新，可取消排队/运行任务，可直接重试失败或取消任务。
4. 已完成任务可从生成中心直接打开结果文件。
5. 保留原有持久化队列、失败恢复、一致性资产门禁与结果自动回写。

## 后续优先级

1. 生成结果画廊与 A/B 候选对比。
2. 生成前费用和调用次数预估，付费任务二次确认。
3. Prompt 模板、收藏和历史版本。
4. 分镜卡片按场景分组及批量审片。
5. 剪映草稿或通用 OTIO/EDL 可继续编辑交付。
