# V1.5.2 自主可用性审计

本轮不依赖用户逐项指出问题，按真实用户路径主动审计 WPF 客户端。

## 已修复

- 所有窗口启动时自动限制到 Windows 工作区，降低 1366×768 等屏幕上底部操作被裁切的风险。
- ComboBox、下拉项、ListBox、DataGrid 行/单元格全部使用显式深色高对比模板，不再依赖系统白色主题。
- 正文基准 16px；显式辅助文字不得低于 15px。
- 模型岗位的拉取、选择、待绑定摘要、绑定、解除和反馈操作固定可见。
- 岗位绑定保存真实模型 ID，并自动测试关闭窗口后重新打开仍能恢复。
- 一键生产移除与岗位绑定冲突的第二套图片/视频模型输入，只读展示关键帧、视频、转场、配音和质检岗位；关键岗位不可用时阻止启动。
- 移除主窗口没有事件处理的伪时间线播放控件；真实预览只保留在剪辑工作台。
- Windows CI 保存首页、模型拉取选择、绑定成功三张屏幕截图，供交付前人工视觉复核。

## 自动验收

- XAML 全量结构解析。
- 全部窗口中不存在无 Click/Command 的可见按钮。
- 全部显式 TextBlock 字号不低于 15px。
- 44 项后端和真实媒体测试。
- Windows WPF Release 编译和桌面启动。
- UI Automation：拉取 → 自动选择 → 绑定 → 关闭 → 重开恢复 → 解除。
- 首页与模型路由中心截图复核。
