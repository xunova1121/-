# V0.8 镜头绑定空间预演

V0.8 将 V0.7 的场景布局从独立参考资料升级为可验证的镜头生产契约。

## 用户闭环

1. 在空间预演台选择一个真实镜头。
2. 布置机位、拍摄目标、焦段、人物站位/朝向/姿态与光向。
3. 点击“保存新版本并绑定镜头”。
4. 绑定记录冻结布局 ID、版本与 SHA-256 指纹；后续新建场景版本不会暗中改变旧镜头。
5. 图片或视频生产任务必须携带镜头 ID；没有有效绑定时服务返回 409，避免付费盲生成。
6. 任务创建时，服务将冻结的空间约束自动附加到提示词与结构化 `previz` 载荷。
7. 用户可明确改绑历史版本或解除绑定；解除后生产门禁立即恢复。

## 验收要点

- 镜头与布局必须属于同一项目。
- 绑定指纹与布局当前指纹不一致时状态为 `stale`。
- 生成载荷保存完整布局、版本、指纹和人类可读约束。
- 保存新布局不自动漂移既有绑定；只有显式改绑才改变镜头生产合同。
- WPF 提供镜头选择、绑定状态、保存并绑定、绑定历史版本和解除绑定操作。
