# V1.6.0 全量分镜审阅锁定门禁

## 产品依据

本轮借鉴成熟 AI 短剧平台的“自动化与人工控制并存”思路，但不复制第三方界面或代码：

- 生产被拆为可审阅的阶段，创作者在付费生成前拥有最终控制权。
- 人物、场景、分镜和连续性必须成为一个可追溯的版本合同。
- 长篇生产不能用已过期的分镜继续批量消耗模型额度。

## 用户闭环

1. 按集查看、搜索和编辑全量分镜。
2. 保存后执行标题、画面/动作/对白、时长、人物设定完整性和连续性阻断检查。
3. 通过后冻结当前设定，并锁定为带修订号与 SHA-256 指纹的生产版本。
4. 锁定后分镜只读；显式解除锁定才可修改。
5. 剧本、分镜、设定、连续性合同或模型价值路由发生变化时，锁定状态自动显示为“已失效”。
6. 自动生产预检与启动接口都拒绝未锁定或已失效版本，且不会创建付费任务。

## 数据安全

- 解锁不会删除分镜、素材或历史锁定快照。
- 重新锁定只增加修订号，并保存新的规范化快照。
- 生成过程中的临时状态不参与内容指纹，避免任务进度使锁定误失效。
