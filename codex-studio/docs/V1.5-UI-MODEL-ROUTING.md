# V1.5 首页、导航状态与模型路由中心

V1.5 集中解决两个可用性问题：暗色界面文字和下拉框不可读，以及“服务商配置了一个模型，但不同生产环节无法选择具体模型”。

## 界面行为

- 首次启动直接进入首页，不弹出新建项目窗口。
- 首页、顶栏和工作区导航均有持久的紫色选中状态。
- 点击剧本、分镜、制作、剪辑等入口后，顶层业务阶段与二级工作区同时显示当前位置。
- 全局正文、次要文字、输入框、密码框、下拉列表、表格和列表统一使用高对比度暗色样式。

## 模型发现

- OpenAI：账户 `GET /v1/models`。
- Anthropic：`GET /v1/models`，自动按游标取完分页。
- DeepSeek：OpenAI 兼容 `GET /models`。
- 阿里云百炼 Qwen / Wan：`GET /api/v1/models`，按提供商和模态筛选并自动翻页。
- 火山方舟：明确使用 Endpoint ID，不伪装成推理端模型枚举。
- 秘塔 MiniMax H3：当前使用已验证接入目录；无稳定公开枚举协议时明确显示目录来源。

实时请求失败时，界面会显示失败原因并回退到内置兼容目录，不会把回退结果标成服务商实时返回。

## 功能岗位

模型路由中心覆盖剧本诊断、剧本改写、拆场、拆镜头、全量分镜导演、提示词优化、一致性审核、关键帧、参考图编辑、正式视频、首尾帧桥接、角色配音和成片终检。

当前生产闭环会直接读取以下绑定：全量分镜导演、关键帧、参考图编辑、正式视频、连续镜头/首尾帧、角色配音、人物场景一致性审核和成片终检。绑定可覆盖、清除，并在执行前做能力校验。
