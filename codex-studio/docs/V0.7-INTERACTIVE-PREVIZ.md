# V0.7 可操作空间预演台

本轮把原有仅能通过 API 保存一组坐标的预演底座，升级为可由创作者直接操作的 WPF 工作台。

## 用户闭环

1. 从主工作区打开“空间预演”。
2. 输入场景键，加载该场景全部历史版本。
3. 在画布上拖拽机位、拍摄目标和多个人物。
4. 编辑人物朝向、姿态、焦段和光向。
5. 画布实时显示镜头视锥、拍摄方向和人物轴线。
6. 保存为新的不可变场景版本。
7. 服务端将新机位与同场景上一版本比较，检测画外人物和疑似越轴。
8. 保存的空间状态和指纹可被后续镜头生成与连续性流程复用。

## 开源边界

- 参考 Wonder Unit Shot Generator 的“角色/物体/灯光/相机同台布置”产品思路；其模型仓库采用 MIT 许可证。
- 参考 Blender Storypencil 的故事板与机位预演工作流；Blender 为 GPL，因此本项目不复制其代码，也不引入运行时依赖。
- 本功能由 WPF、FastAPI 和 SQLite 独立实现。
