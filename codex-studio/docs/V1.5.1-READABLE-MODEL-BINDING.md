# V1.5.1 可读模型岗位绑定

本修订针对 V1.5 模型路由中心的用户验收缺陷，不增加假入口。

## 用户闭环

1. 选择服务商，保存 Base URL、默认模型和加密密钥。
2. 实时拉取账户可用模型；不支持枚举的服务商明确显示兼容目录或 Endpoint ID 提示。
3. 选择剧本、拆场、拆镜头、分镜、生成、配音或质检岗位。
4. 选择该岗位支持的服务商并拉取按能力过滤的候选模型。
5. 在高对比度下拉框中选择具体模型，页面显示“准备绑定”摘要。
6. 点击固定在底部、不会被滚动区域裁掉的“绑定并保存”。
7. 后端持久化精确模型 ID，关闭并重新打开后仍显示已绑定状态。
8. 可用“解除当前绑定”清除路由。

## 回归保护

- 全局 ComboBox、ComboBoxItem、ListBox 和 ListBoxItem 使用显式深色模板，不再依赖 Windows 默认白色主题。
- 保存服务商默认模型与岗位模型时，从拉取结果对象读取真实 `id`，避免保存“显示名 · ID”。
- 跨平台 UI 契约测试检查可读模板、按钮文案、自动化标识及按钮不位于滚动区。
- Windows CI 使用本地 OpenAI-compatible 模型目录，真实自动点击“模型 → 拉取候选模型 → 绑定并保存 → 后端持久化 → 解除绑定”。
