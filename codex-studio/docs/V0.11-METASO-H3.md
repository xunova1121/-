# V0.11 秘塔 MiniMax H3 视频闭环

## 用户路径

1. 在模型设置中选择“秘塔 metaso · MiniMax H3 视频”，填写 API Key 并加密保存。
2. 在空间预演台为目标镜头保存并绑定布局版本。
3. 打开“视频生成”，选择镜头；软件自动核验预演契约。
4. 设置提示词、首帧、尾帧、参考图、时长、分辨率和画面比例，提交真实任务。
5. 后台向秘塔创建异步任务，持续轮询；任务队列支持取消，长轮询期间持续更新租约。
6. 成功后立即下载视频，复制到项目托管目录，计算 SHA-256，登记资产并将镜头标为“已生成”。

## 门禁与安全

- 非测试任务没有 API Key 时拒绝入队。
- 首尾帧和参考图合计最多 9 张，本地单图最大 12 MB。
- 时长限制 4–15 秒，分辨率限制为 480p、512p、768P、2K。
- 本地参考图编码后随 HTTPS 请求发送；API Key 仍由 Windows DPAPI 加密保存且不回显。
- 外部媒体下载域名不会收到秘塔 Authorization 请求头。
- 完成视频必须是非空文件，否则任务不会伪装成成功。

## 验证边界

自动化测试模拟了完整供应商协议：创建任务、处理中、成功、跨域下载、参考图与尾帧参数、HTTP 200 错误体，以及密钥不进入异常文本。Windows CI 另外验证服务封装、模型目录、WPF 编译、桌面启动和单文件交付。付费账户的线上额度、并发限制与返回字段变更仍需使用用户自己的秘塔 Key 做验收。
