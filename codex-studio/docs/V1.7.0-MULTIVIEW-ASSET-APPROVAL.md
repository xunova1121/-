# V1.7.0 多视图一致性资产审批

## 产品依据

- LumenX（MIT）把角色三视图、场景定调图和道具参考图放在“剧本 → 分镜 → 资产 → 视频”正式生产链中。
- ArcReel（AGPL-3.0 + NOTICE）强调可检查、可恢复、人工审核关键阶段和复用参考资产。
- Toonflow（Apache-2.0）把人物设定、图片和生产节点放入统一工作台。

本版本只吸收产品流程和验收思想，代码为本项目独立实现；未复制 AGPL 项目代码。

## 已实现闭环

1. 剧本解析产生人物、场景、道具 Story Bible 实体。
2. 每个实体拥有独立候选视图板：人物至少正面、侧面、全身；场景至少全景、反向；道具至少正面、细节。
3. 同一视图可以保留多个候选，批准时默认采用每类最新候选，也可以明确选择候选。
4. 批准动作冻结对应 Bible 版本，并把批准图片写入正式参考资产列表。
5. 批准快照记录 Bible 版本、Bible 指纹、资产 ID、视图角色、文件大小和修改时间。
6. 修改 Bible、删除或替换批准文件会使审批状态变为 `stale`。
7. 分镜锁定快照包含一致性资产审批；未批准或失效的资产阻止锁定与自动生产。
8. 关键帧和视频生成只读取当前批准的参考图，不再读取未审核候选。

## 用户验收路径

1. 导入并解析剧本。
2. 打开“资产 → 多视图审批”。
3. 选择人物/场景/道具，按视图类型导入图片。
4. 点击“批准当前多视图”，看到 `已批准 · R1`。
5. 打开分镜工作台，完成审阅并锁定本集。
6. 进入自动生产，预检显示一致性资产批准数量。
7. 修改 Story Bible 或删除批准图片，审批与分镜锁应立即失效，且不得创建付费生成任务。
