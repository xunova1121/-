# V0.10 托管产物闭环

本版本关闭“任务显示完成，但成品没有进入项目”的缺口。

1. 后台执行器只接受真实存在且非空的输出文件。
2. 输出复制到应用托管的项目目录，避免供应商临时文件失效。
3. 以流式 SHA-256、文件大小、原任务和供应商元数据登记产物。
4. 产物同时关联项目、任务和可选镜头；有关联镜头时自动回写“已生成”。
5. 项目产物可按镜头查询，任务中心可通过受控接口下载文件。
6. 下载只允许托管目录中的登记产物；外部路径不能借接口读取。

边界：本版本完善的是供应商完成后的产物生命周期。图片/视频供应商各自的异步提交、轮询和下载协议仍需逐家实现，未把测试适配器冒充真实生成服务。
