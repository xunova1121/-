# 手机端界面稿

这几个 `.dc.html` 是**设计稿的源文件**，一个文件一块画板，`canvas.json` 管它们
在画布上怎么摆。改稿子就改这里，然后重新拼一份画布出来（拼出来的那个
2MB 大文件不入库 —— 它是产物，每次都能从这些源文件重新生成）。

画板：

| 文件 | 画的是 |
| --- | --- |
| `Notes.dc.html` | 改了什么、为什么、沿用了哪些 token |
| `Main.dc.html` | 分镜列表（筛选条、问题条、一个主按钮） |
| `ShotActions.dc.html` | 卡片上那个「⋯」推上来的动作面板 |
| `ShotEdit.dc.html` | 单镜编辑（整屏、四组） |
| `Pipeline.dc.html` | 流水线（进度条、正在跑的那一步） |
| `Film.dc.html` | 成片页（体检分数 + 素材） |

配色、字号、圆角、44px 触控目标全部照抄 `ui/m/m.css` 里现有的 token ——
稿子和代码用同一套值，改稿的时候才不会顺手发明一个新绿色出来。
