# 综合态势「一张图」GIS 覆盖层

`江苏渔业指挥平台_V10.6_政府汇报版.html` 里综合态势那块地图的源码。
原来是几个绝对定位的 div 拼出来的示意图，现在换成按经纬度投影绘制的矢量海图，
航线会动。

## 文件

| 文件 | 作用 |
| --- | --- |
| `gis-data.js` | 地理数据：海岸线、长江口、岛屿、水系、湖泊、城市、禁捕区、航道、目标船、执法船艇、渔船、风场（均为 WGS84 经纬度） |
| `gis-core.js` | 投影、Catmull-Rom 平滑、标注避让、SVG defs、底图（海陆、河湖）、城市标注 |
| `gis-layers.js` | 禁捕区、航道、气象、航线、目标船雷达、渔船、执法船艇 |
| `gis-onemap.js` | 平台一张图：总览数据、版面、进出工作区 |
| `gis-onemap.css` | 平台一张图样式 |
| `gis-radar.js` | 雷达态势视图：极坐标目标数据、雷达盘、双光通道、扫描动画 |
| `gis-radar.css` | 雷达视图样式 |
| `gen-channels.py` | 从页面内嵌实拍图生成两路光电通道画面 |
| `gis-mount.js` | 控件、视图切换、渲染入口、动画循环、交互、挂载与重绘 |
| `gis.css` | 全部样式与关键帧 |
| `build.py` | 把上面几个文件拼成 `<style>` + `<script>` 注入到单页 HTML |

## 构建

```bash
# 保留页面自带的一张图，只追加雷达态势（当前成品用的就是这个）
python3 src/gis/build.py 输入.html 输出.html --keep-map

# 用重制版地图替换掉自带的一张图
python3 src/gis/build.py 输入.html 输出.html
```

**`--keep-map` 是现在的默认做法。** 页面自带的 `v10x-real-gis-*` 覆盖层原样保留，
只追加一个 `fishery-radar-*` 区块（雷达视图 + 视图切换 + 苏盐渔卡开关 + 风速胶囊）。
重制版地图（`gis-data/core/layers/mount`）的代码仍在仓库里，但**不进成品**。

脚本认三种 id：V10.5 / V10.6 自带的 `v10x-real-gis-*` 覆盖层，以及本脚本自己写过的
`fishery-gis-*`；都没有就追加到 `</body>` 前。可以反复对同一个文件跑，不会叠加。

仓库里两个成品的 GIS 代码完全一致，差别只在页面主题：
`V10.6_政府汇报版` 带「稳重深蓝、低炫光」的汇报主题，`V10.5_GIS增强版` 是原始亮色主题。

## 投影

`VIEW = { latTop, latSpan, anchorLon, stretch }`。纬度范围固定，经度范围按容器
宽高比算出来，所以换分辨率不会把船和字拉变形——**所有图元的位置在 JS 里算成像素**，
SVG 的 viewBox 跟容器实际像素一一对应，图标和文字始终按屏幕像素绘制。

`stretch` 是横向压缩系数（1.0 = 不失真）。江苏海岸线南北长、地图卡片却是扁的，
1.55 是在「少一点空白洋面」和「海岸线别太胖」之间取的折中值。

## 标注避让

`place()` / `placeBlock()` 拿一组候选偏移，逐个测试是否和已放置的标注、
控件预留区（工具条、右侧面板、底部图例）相撞，撞了就换下一个，全撞就不画。
生成顺序即优先级：目标船 → 执法船 → 禁捕区 → 城市。
目标船和执法船传 `force=true`，宁可轻微重叠也不能没有标注。

渔船落点用射线法 `inLand()` 判断，压到陆地上的直接丢弃，改数据时不用手动核对。

## 动画

- **流动虚线**：CSS 动 `stroke-dashoffset`，常开
- **流光包**：`.rg-comet` 复制同一条路径，`dasharray = "段长 全长"`，rAF 推 offset，
  配合 `getPointAtLength()` 定位头部光点
- **航线推演**：点「航线推演」后执法船沿航线驶向目标船，`getPointAtLength()`
  取位置、取切线定船艏朝向，右侧面板 ETA 同步递减

只有一个 rAF 循环，`anim.flow` / `anim.playing` 两个开关控制。
`prefers-reduced-motion` 下关掉所有动画。

## 与页面原有交互的关系

覆盖层不接管业务逻辑。点船艇会去 `.click()` 页面里原本隐藏的 `.ship.sN` 按钮，
「实时视频」去点原来的 `.popup button`，所以船舶详情抽屉、视频墙这些
React 状态照旧走原来的路径。图层分段器（渔船/气象/围栏/航道/执法力量）
通过 `.map[data-layer]` 联动，样式全在 CSS 里。

## 信息密度

第一版把渔港、经纬网、AIS 轨迹、22 个渔船点、13 条支流、500 个陆地灯点全铺上了，
太满。现在按「默认视图只留读图必需的东西」收敛：

- 默认（渔船图层）＝ 底图 + 城市名 + 两片禁捕区 + 目标船 + 5 艘执法船和航线
- 其余信息按需出现：航速/ETA 在悬停浮窗和右侧面板，风场进气象图层，
  主航道进航道图层，辖区覆盖圈进执法力量图层
- 渔船只标 2 艘告警船（带光晕）、2 艘关注船，正常船退成暗点当环境底噪
- 工具条压到两个开关，图例压到三项

想把某层加回来：`ports` / `tracks` 填回数据即可（渲染代码还在），
经纬网把 `graticule()` 开头那行 `return ''` 删掉，
陆地灯点在 git 历史里（`basemap()` 中的 `rg-settle` 一段）。

## 风速

四个地方都能看到，各管一段：

| 位置 | 内容 |
| --- | --- |
| 工具条风速胶囊 | 实况风速 + 风向箭头 + 风力等级，常驻；点一下切到气象图层 |
| 信息板展开后 | 风向、风速、阵风、浪高，以及每艘执法船所在海域的风速 |
| 气象图层 | 每条风场流线末端标风速与等级；大风区标阵风，涌浪区标浪高 |
| 悬停浮窗 | 目标船和执法船各自的风速 |

数据在 `GEO.windNow`（实况）、`GEO.wind[].spd/lvl`（流线）、
`GEO.wxBlobs`（大风区/涌浪区）、`GEO.patrol[].wind`（各船海域）。
风向箭头按 `dir + 180` 旋转——气象上的风向指风从哪来，箭头要指风往哪去。

## 信息板

默认只显示一个「执法力量 5」的小条，点一下展开。展开态跨重绘保持（`panelOpen`），
所以调窗口大小不会把它收回去。

收起时外层 `width:0` 裁掉内容，内容自己固定 212px 不回流——
否则展开动画过程中文字会一直换行抖动。标注避让按收起态的尺寸预留，
展开后浮在图上属正常的下拉行为。

## 目标船闪烁

`rgBlink` 让核心和高亮环在 1.15s 周期内在全亮和 15% 之间切换，
外面再套一圈 `rgFlash` 同相位扩散的光环。三者同相位，读起来是一次「跳动」而不是三层各闪各的。
`prefers-reduced-motion` 下全部静止，光环 opacity 归零。

## 雷达态势视图

地图卡片左上角有「一张图 / 雷达态势」切换，雷达模式下左下角还有「放大全屏」。
全屏是 `position:fixed` 覆盖层，Esc 或右上角 × 关闭，按参考图的完整布局排
（左栏遥测/目标信息/系统状态、中间雷达盘、底部波形、右栏双光通道 + 锁定目标详情）。

### 坐标系

雷达数据是**极坐标原生**的（`brg` 方位 / `rng` 距离 nm），不是从经纬度投影来的。
雷达操作员看到的本来就是方位距离，硬做投影只会引入没有意义的精度。
两个视图共用目标编号（T001、I002…），讲的是同一件事，但不假装互为投影。

量程 48 nm，距离环 12/24/36/48。29 个目标：1 告警（T001，锁定）、6 关注（带尾迹）、
4 执法力量、18 正常。

### 扫描余辉

`startRadar()` 里一个 rAF 循环，4.2 秒一圈。每个目标按「扫描线扫过它方位后过了多久」
算亮度——刚扫过最亮，之后按 `1 - (Δ角/360)^0.62 * 0.86` 衰减到 24%。
这是真实 PPI 的余辉行为，也是这个视图最像雷达的一个细节。

### 双光通道

两路画面都来自页面里本来就内嵌的那张海上作业渔船实拍图（`gen-channels.py` 预处理）：

- **可见光**：压暗 + 偏蓝 + 噪点，做成低照度夜视的观感
- **热成像**：**模拟渲染，不是真红外数据**。日间可见光的亮度分布和红外正好相反
  （海面亮、船体暗），直接把亮度映射成温度会得到「海面滚烫、船体冰冷」的错误结果。
  所以热度按船体区域合成，用实拍的边缘细节做纹理调制，再叠机舱高温和尾流余温，
  最后过 ironbow 伪彩表。

两路是同一张裁剪图，所以跟踪框位置一致，锁定目标 → 可见光 → 热成像的引出线
（`linkLines()`，按元素实际位置算，随重绘更新）连起来才成立。

重新生成通道画面：

```bash
python3 src/gis/gen-channels.py 源单页.html
```

## 两条路线

仓库里同时有两套一张图，成品当前走第二套：

| | 重制版地图 | 页面自带覆盖层（当前成品） |
| --- | --- | --- |
| 文件 | `gis-data.js` `gis-core.js` `gis-layers.js` `gis-mount.js` `gis.css` | 页面里的 `v10x-real-gis-*`，本仓库不改 |
| 构建 | `build.py 入 出` | `build.py 入 出 --keep-map` |
| 特性 | 经纬度投影、标注避让、航线推演、风速四处联动、信息板折叠、禁捕区重绘 | 自带的海岸/航线/禁捕区 |

切到自带覆盖层后，重制版里这些**不再进成品**：航线推演、标注避让、
禁捕区与海岸线重绘、信息板折叠、气象图层的风速标注。
其中两项已单独移植到自带覆盖层上（见下），其余要用需改回不带 `--keep-map` 的构建。

## 对自带覆盖层的三处改动

都在 `gis-radar-mount.js` 里，不修改自带覆盖层本身的代码：

1. **苏盐渔卡改成点击才出现** —— `.gis-vessel-card` 默认 `display:none`，
   在目标船位置插一个透明的 `.rd-card-hit`（r=30，自带的 `.target-core` 只有 r=8，
   直接点太难命中），点它切换卡片；卡片右上角补一个 ×；点空白收起。
   卡内两个按钮（实时视频 / 船舶详情）走自带的 `data-gis-action` 逻辑，没动。
2. **实况风速胶囊** —— 追加到自带的 `.gis-toolbar`，沿用它自己的 `.gis-chip` 样式，
   点击切到气象图层。
3. **目标船闪烁** —— 覆盖自带的 `gisCore` 缓慢脉动，换成 1.15s 的明确闪烁。

踩过两次的同一个坑：自带覆盖层和重制版都有
`svg{position:absolute;inset:0;width:100%;height:100%}` 这类给底图 svg 用的规则，
会把控件里的小图标（风向箭头）也铺满整个胶囊。加控件图标时必须显式压回
`position:static;width:13px`。

### 两个坑

**一、不能用语义标签。** 页面自身的 CSS 对 `header` / `aside` / `main` / `section` / `h1` / `h3`
有**全局**规则（`aside` 是它的侧边栏、`header` 是它的顶栏），覆盖层一用这些标签就被套进去，
版面直接崩掉。一张图内部全部用 `div` + 类名。

**二、隔离样式要用 `:where()` 压特指度。** 写成 `.om-wrap div{...}` 是 (0,1,1)，
会盖过下面所有单类名规则 (0,1,0)，等于把自己的样式全清了。
正确写法是 `:where(.om-wrap) :where(div,span,...)`，特指度 0，任何类名规则都能覆盖。

### 一屏不滚

`.om-root` 必须是 `height:100%` 而不是 `min-height:100%`——后者高度仍由内容驱动，
`flex:1` 没有可分配的余量，`.om-body` 会一直保持 min-content 高度压不下去。
配合 `.om-body{grid-template-rows:minmax(0,1fr)}` 与
`.om-mods{grid-auto-rows:minmax(0,1fr)}`（`1fr` 的行不会缩到 min-content 以下），
1280×720 至 2560×1440 全部一屏无滚动条。矮屏另有 `@media(max-height:830px)` 压缩版。
